Rollout算法 Rollout算法是基于模拟轨迹的蒙特卡洛控制的决策时规划算法。在当前环境状态下开始，通过从每个可能的动作开始，然后遵循给定策略的许多模拟轨迹的回报来估计给定策略的行动价值。当 核心直觉与策略梯度基础 必考 对于随机策略，应当降低带来较低价值/奖励的动作出现的概率，提高带来较高价值/奖励的动作出现的概率。 策略的价值期望 起始状态为 $s \sim d(s)$，策略的价值期望可以写成： $$J(\theta) = \mathbb{E}_{\pi_{\theta}}[r] = \sum_{s \in S} d(s) \sum_{a \in A} \pi_{\theta}(a|s)r_{sa}$$ 似然比（Likelihood Ratio） 似然比利用下列特性： $$\frac{\partial \pi_{\theta}(a|s)}{\partial \theta} = \pi_{\theta}(a|s) \frac{1}{\pi_{\theta}(a|s)} \frac{\partial \pi_{\theta}(a|s)}{\partial \theta} = \pi_{\theta}(a|s) \frac{\partial \log \pi_{\theta}(a|s)}{\partial \theta}$$ 对策略的价值期望求导并代入似然比特性： $$\frac{\partial J(\theta)}{\partial \theta} = \sum_{s \in S} d(s) \sum_{a \in A} \pi_{\theta}(a|s) \frac{\partial \log \pi_{\theta}(a|s)}{\partial \theta} r_{sa} = \mathbb{E}_{\pi_{\theta}} \left[ \frac{\partial \log \pi_{\theta}(a|s)}{\partial \theta} r_{sa} \right]$$ 这一结果可以通过从 $d(s)$ 中采样状态 $s$ 和从 $\pi_{\theta}$ 中采样动作 $a$ 来近似估计，这是策略梯度方法的基石。 Softmax随机策略与MC策略梯度 重点 Softmax策略 Softmax策略是一种非常常用的随机策略： $$\pi_{\theta}(s,a) = \frac{\exp(f_{\theta}(s,a))}{\sum_{a'} \exp(f_{\theta}(s,a'))}$$ 其中，$f_{\theta}(s,a)$ 是用 $\theta$ 参数化的状态-动作对得分函数，可以预先定义。 其对数似然的梯度为： $$\nabla_{\theta}\log \pi_{\theta}(s,a) = \nabla_{\theta}f_{\theta}(s,a) - \mathbb{E}_{a' \sim \pi_{\theta}}[\nabla_{\theta}f_{\theta}(s,a')]$$ 举线性得分函数 $f_{\theta}(s,a) = \theta^T x(s,a)$ 为例，则有： $$\nabla_{\theta}\log \pi_{\theta}(s,a) = x(s,a) - \mathbb{E}_{a' \sim \pi_{\theta}}[x(s,a')]$$ 蒙特卡洛策略梯度（REINFORCE） 策略梯度公式： $$\nabla_{\theta}J(\theta) = \mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(s,a) \cdot G_t]$$ 随机梯度上升更新参数： $$\theta \leftarrow \theta + \alpha \nabla_{\theta}\log \pi_{\theta}(s,a) \cdot G_t$$ 其中，利用累计奖励值 $G_t$ 作为 $Q(s_t, a_t)$ 的无偏采样。 REINFORCE算法通过生成完整轨迹，计算累计折扣奖励 $G_t$，并以此进行策略参数的更新。可通过多次 roll-out 的 $G_t$ 平均值来逼近 $Q(s_t, a_t)$。 易错：REINFORCE必须基于片段式数据，需要等待完整回合结束才能计算 $G_t$，且具有高训练方差的缺陷。 近似带Baseline的MC策略梯度 高频 策略梯度方法常用 baseline 来降低方差，让收敛更快。Baseline 是一个函数 $b(s)$，它不依赖于动作 $a$。 带baseline的策略梯度公式 $$\nabla_{\theta}J(\theta) = \mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(s,a) \cdot (Q^{\pi_{\theta}}(s,a) - b(s))]$$ 带 baseline 的策略梯度更新公式： $$\theta \leftarrow \theta + \alpha \nabla_{\theta}\log \pi_{\theta}(s,a) \cdot (G_t - b(s))$$ 一般采用 $b = V^{\pi}(s_t)$ 作为 baseline。选择 $V^{\pi}(s_t)$ 的原因在于其值接近 $Q^{\pi}(s_t, 一、基本概念

1. 强化学习与机器学习 重点

强化学习（Reinforcement Learning, RL），又称再励学习、评价学习或增强学习，是机器学习的范式和方法论之一，用于描述和解决智能体在与环境的交互过程中通过学习策略以达成回报最大化或实现特定目标。

机器学习的分类：

预测性任务：从静态数据中获得模型。包括有监督学习（如回归、分类等，根据数据预测输出，数据含标签）和无监督学习（如聚类等，生成数据实例，数据不含标签）。

决策型任务：从动态环境的交互中学习策略。即强化学习，在动态环境中采取行动。

2. 强化学习的分类 高频

基于环境模型（转移概率是否已知）：

Model-Based：用一个模型来模拟环境，通过模拟环境来得到反馈（如 MCTS）。

Model-Free：直接与环境交互，并探索得到样本提升其策略性能，包含值迭代和策略迭代（如 Q-Learning）。

基于迭代方式：

基于价值的方法：评估状态或状态动作的价值，选择价值高的动作（SARSA，期望SARSA，Q-learning，Double Q-learning）。

基于策略的方法：直接评估下一步动作的概率，根据概率来选取动作。

3. 马尔科夫决策过程（MDP） 必考

3.1 随机过程与马尔科夫性

随机过程：是一个或多个事件、随机系统或者随机现象随时间发生演变的过程，研究动态随机现象的统计规律，如布朗运动、天气变化、股市变化。

马尔科夫性：当处于状态 $S_t$ 时，下一时刻的状态 $S_{t+1}$ 可以由当前状态决定，而不需要考虑历史状态。未来独立于过去，仅仅与现在有关，当前状态是未来的充分统计量。公式表示：$P[S_{t+1}|S_t] = P[S_{t+1}|S_1, ..., S_t]$

马尔科夫性的核心是“未来独立于过去，仅仅与现在有关”，当前状态是未来的充分统计量。

3.2 马尔科夫过程

马尔科夫过程（Markov Process, MP）也称为马尔科夫链，具有马尔可夫性质的随机过程。可以由元组 $(S, P)$ 表示：

$S$ 是一个有限的状态集合。

$P$ 是状态转移概率矩阵，$P_{ss'} = P[S_{t+1} = s' | S_t = s]$。

3.3 马尔科夫决策过程

马尔科夫决策过程（Markov Decision Process, MDP）提供了一套为在结果部分随机、部分在决策者的控制下的决策过程建模的数学框架，形式化地描述了一种强化学习的环境，环境完全可观测。可以由五元组 $(S, A, P, R, \gamma)$ 表示：

$S$：有限的状态集合。

$A$：有限的动作集合。

$P$：状态转移概率矩阵，$P_{ss'}^a = P[S_{t+1} = s' | S_t = s, A_t = a]$。

$R$：奖励函数，$R_s^a = E[R_{t+1} | S_t = s, A_t = a]$。

$\gamma$：折扣因子，$\gamma \in [0, 1]$，体现了未来的奖励在当前时刻的价值比例。

3.4 总回报与MDP动态过程

MDP的动态过程：从状态 $s_0$ 开始，智能体选择动作 $a_0 \in A$，得到奖励 $r(s_0, a_0)$，MDP随机转移到下一个状态 $s_1 = P_{s_0, s_1}^{a_0}$。过程不断进行直到终止状态或无止境进行。

智能体的总回报 $G$ 为：$G = R(s_0, a_0) + \gamma R(s_1, a_1) + \gamma^2 R(s_2, a_2) + ...$

3.5 学生上课示例 了解

假设下午只有三节课，Sleep是一个最终状态。通过不同状态链计算总回报（如 $\gamma = 0.5$ 时的计算），展示折扣因子对未来奖励的影响。

4. 强化学习基本概念 重点

历史：是观察、行动和奖励的序列。

状态：是一种用于确定接下来会发生的事情（行动、观察、奖励）的信息。

策略：是学习智能体在特定时间的行为方式，是从状态到行动的映射。确定性策略：$a = \pi(s)$；随机策略：$\pi(a|s) = P(A_t = a | S_t = s)$。

易错：策略仅与当前状态有关，与历史状态无关；同时某一策略是静态的，与时间无关，但个体可以随着时间更新来更新策略。

奖励：$R(s, a)$。

累计奖励：在马尔可夫奖励链上，从时间步 $t$ 时刻开始，往后所能获得的所有折扣奖励之和：$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$。

状态值函数 $v_\pi(s)$：表示在 MDP 中，从当前状态 $s$ 开始，遵循策略 $\pi$ 所能获得的期望回报。

动作值函数 $q_\pi(s, a)$：表示依据策略 $\pi$ 时，在给定状态 $s$ 下，采取某一具体的行为 $a$，所能获得的期望回报。

二、贝尔曼方程

1. 贝尔曼方程简介 高频

贝尔曼方程，又叫动态规划方程，表示动态规划问题中相邻状态关系的方程。某一阶段最优决策的问题，通过贝尔曼方程转化为下一阶段最优决策的子问题，从而初始状态的最优决策可以由终状态的最优决策问题逐步迭代求解。

存在某种形式的贝尔曼方程，是动态规划方法能得到最优解的必要条件。

2. 价值函数的贝尔曼方程

$V^{\pi}(s) = \mathbb{E}\left[R_{t+1} + \gamma R(S_{t+1}) + \gamma^2 R(S_{t+2}) + \cdots \mid S_t = s, \pi\right] = \mathbb{E}^{\pi}\left[R_{t+1} + \gamma V^{\pi}(S_{t+1})\right] = \mathbb{E}\left[R_{t+1} + \gamma \sum_{s'} p(s' \mid s, \pi(s)) V^{\pi}(s')\right]$

3. 状态与动作的期望关系

从 state 到 action：按照状态价值函数定义为 $\pi(a|s) q_\pi(s, a)$ 对 $a$ 的累加和。

从 action 到 state：采取一个动作，首先会获得一个 reward，然后从状态 $s$ 转移到状态 $s'$。

从 state 到 state：$V^{\pi}(s) = \sum_{a} \pi(a \mid s) q_{\pi}(s, a) = \sum_{a} \pi(a \mid s) \sum_{s'} p(s' \mid s, a) \left[ r(s, a, s') + \gamma V^{\pi}(s') \right]$

从 action 到 action：$q_{\pi}(s, a) = \mathbb{E}_{\pi}\left[ R_{t+1} + \gamma V^{\pi}(S_{t+1}) \mid S_t = s, A_t = a \right] = \mathbb{E}\left[ R_{t+1} + \gamma \sum_{s'} p(s' \mid s, a) \sum_{a'} \pi(a' \mid s') q_{\pi}(s', a') \mid S_t = s, A_t = a \right]$

4. Bellman 期望方程 重点

$V^{\pi}(s) = \sum_{a} \pi(a \mid s) q_{\pi}(s, a)$

$q_{\pi}(s, a) = \mathbb{E}_{\pi}\left[ R_{t+1} + \gamma V^{\pi}(S_{t+1}) \mid S_t = s, A_t = a \right] = \mathbb{E}\left[ R_{t+1} + \gamma \sum_{s'} p(s' \mid s, a) V^{\pi}(s') \mid S_t = s, A_t = a \right]$

贝尔曼方程的作用是什么？
参考答案贝尔曼方程将某一阶段最优决策的问题转化为下一阶段最优决策的子问题，从而初始状态的最优决策可以由终状态的最优决策问题逐步迭代求解。它是动态规划方法能得到最优解的必要条件。

三、多臂老虎机

多臂老虎机是一种基于概率分布的决策问题，通常被用来描述在不确定性环境下的最优决策问题。多臂老虎机可以被看成是无状态的强化学习。没有状态信息，只有动作。

1. 探索与利用 必考

序列决策任务中的一个基本问题：基于目前策略获取已知最优收益还是尝试不同的决策。

利用：执行能够获得已知最优收益的决策。

探索：尝试更多可能的决策，不一定会是最优收益。

2. 常见算法

贪婪算法（greedy）：始终选择当前最优。$A_{t} \triangleq \operatorname{argmax}_{a} Q_{t}(a)$

ε-贪婪算法（ε-greedy）：以 $\epsilon$ 的概率随机探索，以 $1-\epsilon$ 的概率利用当前最优。

衰减 ε-贪婪算法：ε 随着时间衰减。$\epsilon_{t}=\min \left\{1, \frac{c \ln t}{d t}\right\}$

乐观初始化（Optimistic Initialization）：有偏估计，但随着采样增加，偏差带来的影响会越来越小，然而仍可能陷入局部最优。

上置信界（Upper-Confidence-Bound, UCB）：不确定性越大，越具有探索的价值。基于 Hoeffding 不等式。$A_{t}=\arg \max _{a}\left[\hat{Q}_{t}(a)+c \sqrt{\frac{\ln t}{N_{t}(a)}}\right]$。UCB 不需要额外参数，但不适用于状态空间较大的问题。

Hoeffding 不等式：$\mathbb{P}\left[\bar{X}_{t}-\mu_{i} \geq u\right] \leq e^{-2 t u^{2}} \text{ for } u \in[0,1]$

Thompson Sampling 方法：根据每个动作成为最优的概率来选择动作。根据当前每个动作 $a$ 的价值概率分布 $p\left(\theta_{a}\right)$ 来采样到其价值 $Q(a)$，选择价值最大的动作。

易错：UCB策略中，$N(a)$ 大，$\beta(a)$ 小；$N(a)$ 小，$\beta(a)$ 大。不确定性越大的动作越具有探索价值。

四、表格解决方法

1. 动态规划 重点

价值迭代（Value Iteration）

策略迭代（Policy Iteration）：包含策略评估和策略改进。

易错：对于空间较小的 MDP，策略迭代通常更快收敛；而对于空间较大的价值迭代效率更高。

2. 蒙特卡洛方法（MC） 高频

蒙特卡洛方法（Monte-Carlo methods）：依赖于重复随机抽样来获得数值结果。使用经验均值累计奖励而不是期望累计奖励。需要大量的片段数据，且片段都有终止状态。

模型无关的强化学习：直接从经验中学习价值和策略，而无需构建马尔可夫决策过程模型。

MC 状态值函数评估：首次蒙特卡罗（First-Visit）只考虑第一次访问；每次蒙特卡罗（Every-Visit）考虑每次访问。

MC 动作值函数评估：需要保证所有状态-动作对都会被访问到无限次，这种假设称为探索开端（exploring starts）。

在线策略（on-policy）：生成采样数据的策略和用于 evaluate、improve 的策略是同一个策略。

离线策略（off-policy）：用于采样的策略和用于 evaluate、improve 的策略是两个不同的策略（目标策略和行为策略）。拥有更大的方差，依赖重要性采样。

离线策略的优势：平衡探索和利用；通过观察人类或其他智能体学习策略；重用旧策略所产生的经验；遵循探索策略时学习最优策略；遵循一个策略时学习多个策略。

重要性采样（Importance Sampling）：原始重要性采样（无偏估计，方差大）；加权重要性采样（有偏估计，偏差渐进趋于零，方差小）。

3. 时序差分学习（TD） 必考

时序差分（Temporal-Difference, TD）算法：在时间 $t+1$ 立即形成目标并使用观察到的奖励 $R_{t+1}$ 进行更新。模型无关，从不完整的片段中学习。具有低方差、有偏差。

时序差分与蒙特卡洛的区别：

学习时机：TD 能够在知道最后结果之前进行学习；MC 必须等待片段结束。

工作环境：TD 在连续（无终止的）环境下工作；MC 只能在片段化的环境下工作。

方差/偏差：TD 低方差，有偏差；MC 高方差，无偏差。

效率：TD 通常比 MC 更加高效；MC 收敛性质良好。

初始值敏感性：TD 对初始值更加敏感；MC 对初始值不敏感。

多步时序差分学习：$n=1$ 就是 TD；$n=\infty$ 就是 MC。$TD(\lambda)$ 算法中 $\lambda=0$ 相当于单步 TD，$\lambda=1$ 相当于 MC。

时序差分（TD）与蒙特卡洛（MC）的主要区别是什么？
参考答案1. 学习时机：TD可以在每一步之后在线学习，MC必须等待片段结束；2. 工作环境：TD适用于连续无终止环境，MC适用于片段化环境；3. 方差与偏差：TD低方差有偏差，MC高方差无偏差；4. 初始值敏感性：TD对初始值敏感，MC不敏感。

4. SARSA —— 在线策略TD控制算法 重点

SARSA：在线策略时序差分控制，使用当前策略进行动作采样。算法中的两个"A"都是由当前策略选择的。

预期 SARSA 算法：off-policy，动作概率替换为期望值，不需要重要性采样。

5. Q-Learning —— 离线策略TD控制算法 必考

Q-learning 是离线策略方法，使用行为策略采样数据，用目标策略更新。SARSA 是在线策略方法，采样和更新使用同一策略。

6. Double Q-Learning 高频

问题：Q-learning 算法采用 $\max_a Q(s_{t+1}, a)$ 来更新动作价值，会导致最大化偏差（maximization bias），使得估计的动作价值偏大。

解决方案：Double Q-Learning 使用两个 Q 函数。随机选择一个 Q 函数更新值，使用另一个 Q 函数计算下一个状态的最优动作，避免过度估计。

7. 基于重要性采样的多步离线学习法 了解

多步离线策略学习（n-step Off-policy Learning）：基于重要性采样。

多步树回溯算法（n-step Tree Backup Algorithm）：将期望 SARSA 算法扩展到 n 步。

五、模型与规划

1. 基本概念 了解

模型（Model）：给定一个状态和动作，模型能够预测下一个状态和奖励的分布。

分布模型（distribution model）：描述了轨迹的所有可能性及其概率。

样本模型（sample model）：根据概率进行采样，只产生一条可能的轨迹。

规划（Planning）：输入一个模型，输出一个策略的搜索过程。

状态空间的规划（state-space planning）：在状态空间搜索最佳策略。

规划与学习

规划空间的规划

重点 规划空间的规划是指在规划空间搜索最佳策略，包括遗传算法和偏序规划。一个规划就是一个动作集合以及动作顺序的约束。

规划与学习的区别与联系

高频 规划利用模型产生的模拟经验；学习利用环境产生的真实经验。两者的相同点在于：通过回溯更新值函数的估计；统一来看，学习的方法可以用在模拟经验上。

规划使用模拟经验，学习使用真实经验，两者都通过回溯更新值函数。

Dyna —— 基于模型的算法

了解 规划之优先级采样：设置优先级更新队列，根据值改变的幅度定义优先级。

规划之采样方法

重点 期望更新：需要分布模型，需要更大的计算量，没有偏差更准确。

采样更新：按照策略进行采样，只需要采样模型，计算量需求更低，受到采样误差影响。

轨迹采样：状态转移和奖励由模型决定，动作由当前的策略决定。在一个持续的任务中，从任何地方开始，不断模拟。模型给出样本状态转换和奖励，当前策略给出样本动作。模拟明确的单独轨迹，并在沿途遇到的状态或状态-动作对上执行更新。

易错：轨迹采样不需要知道当前策略下状态的分布，计算量少，简单有效；缺点是不断重复更新已经被访问的状态。
轨迹采样的优缺点是什么？
参考答案优点是不需要知道当前策略下状态的分布，计算量少，简单有效；缺点是不断重复更新已经被访问的状态。

蒙特卡洛树搜索

必考 实时动态规划（RTDP）：在当前状态下实施实时的轨迹采样后，只更新轨迹访问的状态值。优势：能够跳过策略无关的状态；在解决状态集合规模大的问题上具有优势；满足一定条件下可以以概率 1 收敛到最优策略。

蒙特卡洛树搜索（MCTS）包含两种规划方式：

1. 背景规划：规划不关注于当前状态，基于从模型获得的模拟经验，使用规划逐步改进策略或价值函数，规划是为了更新很多状态值供后续动作的选择（如动态规划、Dyna）。

2. 决策时规划：通过比较每个动作的模型预测的下一个状态的价值来选择一个动作，只着眼于当前状态的动作选择。在不需要快速反应的应用中很有效（如棋类游戏）。

MCTS算法主要包括四步：

1. 选择：根据树策略（动作值函数）遍历树到一个叶节点。

2. 扩展：从选择的叶节点出发选择未探索过的动作到达新的状态。

3. 模拟：从新的状态出发按照策略进行轨迹模拟。

4. 回溯：得到的回报回溯更新树策略，访问的状态值不会被保存。

近似解决方法

价值函数近似

重点 状态值函数近似：用参数 θ 近似 $v(s) \approx \hat{v}(s, \theta)$。

状态-动作值函数近似：用参数 θ 近似 $q(s, a) \approx \hat{q}(s, a, \theta)$。

参数化策略（REINFORCE）

参数化策略：直接用参数化的策略 $\pi(a|s, \theta)$ 逼近最优策略，通过策略梯度方法进行优化。

Softmax 随机策略与 MC 策略梯度：使用 Softmax 函数将策略参数化为概率分布，结合蒙特卡洛采样估计策略梯度。

近似带 baseline 的 MC 策略梯度

通过在策略梯度中引入 baseline（基线），可以减小方差，加速收敛。

Actor-Critic 网络（AC）

必考 Actor-Critic 网络包含两个部分：

- 演员：学会采取使评论家满意的动作。

- 评论家：学会准确估计当前演员策略的动作价值。

A3C（Asynchronous Advantage Actor Critic）：

- 异步：算法涉及并行执行一组环境。

- 优势：策略梯度的更新使用优势函数。

- 优势函数：$A(s,a) = Q(s,a) - V(s)$，表示当前动作相对于平均水平的优势。

深度强化学习分类

高频 深度强化学习主要分为以下几类：

- 基于价值的方法：深度 Q 网络（DQN）及其扩展。

- 基于随机策略的方法：使用神经网络的策略梯度，自然策略梯度，信任区域策略优化（TRPO），近端策略优化（PPO），A3C。

- 基于确定性策略的方法：确定性策略梯度（DPG），DDPG。

DQN（深度Q网络）

深度Q网络（DQN）：将深度神经网络与 Q-learning 结合，使用神经网络近似 Q 函数，通过经验回放和目标网络等技术使训练更加稳定。核心机制包括：一次输入多个行动 Q 值输出、目标网络、随机采样经验。

DQN 相关改进

重点 Double DQN：核心思想是解耦合行动选择和价值估计，解决 DQN 过高估计问题。使用两个神经网络来估计 Q 值，一个用于选择动作，另一个用于估计目标 Q 值。

Dueling DQN：核心思想是精细捕捉价值和行动的细微关联、多种 advantage 函数建模。将 Q 函数分解为状态值函数和优势函数，更好地学习状态价值和动作优势，适合处理动作空间较大的问题。

优先经验回放（PER）：核心思想是差值越大，被选中的概率越大。

DDPG（Deep Deterministic Policy Gradient）

DDPG：核心思想是确定性策略梯度（DPG）。结合了 DQN 和 DPG，DQN 用于高维输入离散动作空间，DPG 用于低维输入连续动作空间，是一个离线策略算法。

强化学习的基本概念

强化学习与机器学习

强化学习（RL）是机器学习的范式之一，用于描述和解决智能体在与环境的交互过程中通过学习策略以达成回报最大化或实现特定目标。基本交互过程为：agent从状态 $s$ 采取动作 $a$，environment给出奖励 $R$ 并转移到新状态 $s'$。

机器学习分支：预测性任务（从静态数据中获得模型）包含有监督学习和无监督学习；决策型任务（从动态环境中交互中学习策略）为强化学习。

强化学习分类：

1. 根据环境模型分类：Model-Based（基于模型）（如MCTS）；Model-Free（无模型）（如Q-Learning）。

2. 根据迭代方式分类：Value-Based（基于价值）；Policy-Based（基于策略）；Actor Critic（演员-评论家）。

马尔可夫决策过程（MDP）

随机过程是研究动态随机现象统计规律的过程。

马尔科夫性：当处于状态 $S_t$ 时，下一时刻的状态 $S_{t+1}$ 可以由当前状态决定，而不需要考虑历史状态。未来独立于过去，仅仅与现在有关。

马尔科夫过程（MP）：也称为马尔科夫链，是具有马尔可夫性质的随机过程，是一个元组 $\langle \mathcal{S}, \mathcal{P} \rangle$。

必考 马尔科夫决策过程（MDP）：提供了一套为在结果部分随机、部分在决策者的控制下的决策过程建模的数学框架。是一个五元组 $\langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle$：

- $S$：状态的集合。

- $A$：动作的集合。

- $P$：状态转移概率矩阵。

- $R$：奖励函数。

- $\gamma$：折扣因子，$\gamma \in [0, 1]$。

MDP由五元组 $(S, A, P, R, \gamma)$ 表示，环境完全可观测，满足马尔可夫性质。

强化学习概述

智能体通过观察/感知、行动、奖励/目标三个要素与环境进行交互。强化学习的关键要素包括：环境、奖励、动作和状态。目标是得到一个最优的策略，使得回报最大。

交互过程：智能体获得观察 $O_t$、奖励 $R_t$，执行动作 $A_t$；环境获得动作 $A_t$，给出下一个观察 $S_{t+1}$ 和奖励 $R_{t+1}$。

强化学习系统要素

历史：观察、行动和奖励的序列。

状态：用于确定接下来会发生的事情的信息。

策略：学习智能体在特定时间的行为方式，是从状态到行动的映射。策略仅与当前状态有关，与历史状态无关；某一策略是静态的。分为确定性策略 $a = \pi(s)$ 和随机策略 $\pi(a|s)$。

奖励：定义强化学习目标的标量。 回报：从时间步 $t$ 时刻开始，往后所能获得的所有折扣奖励之和 $G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$。

环境的模型：用于模拟环境的行为，预测下一个状态和奖励。

重点 价值函数：状态值函数 $v_{\pi}(s)$ 表示从当前状态 $s$ 开始，遵循策略 $\pi$ 所能获得的期望回报；动作值函数 $q_{\pi}(s, a)$ 表示在给定状态 $s$ 下，采取某一具体的行为 $a$，所能获得的期望回报。

最优策略 $\pi^*$：使得状态值函数或动作值函数达到最大值的策略。

贝尔曼方程

高频 贝尔曼方程又叫动态规划方程，表示动态规划问题中相邻状态关系的方程。核心思想是将某一阶段最优决策的问题，转化为下一阶段最优决策的子问题。

价值函数的贝尔曼方程：

从 state 到 state：$v_\pi(s) = \sum_{a \in A} \pi(a|s) \left( R_s^a + \gamma \sum_{s' \in S} P_{ss'}^a v_\pi(s') \right)$

从 action 到 action：$q_\pi(s, a) = R_s^a + \gamma \sum_{s' \in S} P_{ss'}^a \sum_{a' \in A} \pi(a'|s') q_\pi(s', a')$

Bellman 期望方程：$v_\pi(s) = \mathbb{E}_\pi [R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s]$

易错：存在某种形式的贝尔曼方程，是动态规划方法能得到最优解的必要条件。

多臂老虎机

多臂老虎机可以被看成是无状态强化学习，是研究探索与利用技术理论的最佳环境。问题定义为最大化累积时间的收益：$\max \sum_{t=1}^{T} r_t$。

动作价值的估计：通过将在时间 $t$ 前选择动作 $a$ 所获得的总体奖励除以这个动作被选择的次数来估算 $Q_t(a)$ 的值。

多臂老虎机基础 必考

动作价值与增量式求解

多臂老虎机问题中，动作集合为 $a^i \in \mathcal{A}, \quad i = 1, ..., K$，收益函数分布为 $\mathcal{R}(r \mid a^i) = \mathbb{P}(r \mid a^i)$，目标是最大化累积时间的收益 $\max \sum_{t=1}^T r_t$。

一种简单的基于动作价值的方法是估算 $Q_t(a)$ 的值，即在时间 $t$ 前选择动作 $a$ 所获得的总体奖励除以这个动作被选择的次数：

$$Q_t(a) = \frac{\text{在时间 } t \text{ 前选择动作 } a \text{ 所获得的总奖励}}{\text{动作 } a \text{ 被选择的次数}} = \frac{\sum_{i=1}^{t-1} R_i \cdot \mathbb{1}(A_i = a)}{\sum_{i=1}^{t-1} \mathbb{1}(A_i = a)}$$

其中 $\mathbb{1}(x)$ 的值在 $x$ 为真时为 1，否则为 0。

每次更新的空间复杂度是 $O(1)$，采用增量式求解：

$$Q_{n+1} = Q_n + \alpha [R_n - Q_n]$$

其中，$(1-\alpha)^n + \sum_{i=1}^n \alpha (1-\alpha)^{n-i} = 1$，且 $1 - \alpha < 1$。而如果每次重新计算均值，空间复杂度为 $O(n)$。

期望收益和采样次数的关系：随着采样次数的增加，$Q_t(a)$ 逐渐收敛到真实的动作价值 $q_*(a)$。
易错：增量式更新中步长 $\alpha$ 的引入使得历史奖励呈指数衰减，若每次重算均值则空间复杂度为 $O(n)$，而增量式仅为 $O(1)$。

贪婪策略与伪代码

一种贪心的策略可以写成：$$A_t = \arg\max_a Q_t(a)$$

多臂老虎机伪代码（A simple bandit algorithm）：

初始化：对于 a = 1 到 k：Q(a) ← 0, N(a) ← 0
循环（对每个回合）：
A ← argmax_a Q(a) （若使用 ε-greedy，则 ε 概率随机选择）
R ← 拉取动作 A 获得的奖励
N(A) ← N(A) + 1
Q(A) ← Q(A) + (1/N(A)) * (R - Q(A))

探索与利用 重点

基本概念

序列决策任务中的一个基本问题：基于目前策略获取已知最优收益还是尝试不同的决策。

利用：执行能够获得已知最优收益的决策。

探索：尝试更多可能的决策，不一定会是最优收益。

当前策略 $\pi \neq \pi^*$（最优策略）。

贪婪算法及其变种

贪婪算法：总是选择当前 $Q(a)$ 最大的动作。$$ A_t \doteq \arg \max_a Q_t(a) $$

ε-贪婪算法（ε-greedy）：以 $1-\epsilon$ 的概率选择贪心动作，以 $\epsilon$ 的概率随机探索。

$$ A_t = \begin{cases} \arg \max_a Q_t(a), & \text{以概率 } 1 - \epsilon \\ a' \text{（不同于 } \arg \max_a Q_t(a) \text{）}, & \text{以概率 } \epsilon \end{cases} $$

衰减ε-贪婪算法：ε-greedy 的变种，ε 随着时间衰减：$$ c \ge 0, \quad d = \min_{a | \Delta_a > 0} \Delta_a, \quad \epsilon_t = \min \left\{ 1, \frac{c|\mathcal{A}|}{d^2 t} \right\} $$

乐观初始化 高频

给 $Q(a^i)$ 一个较高的初始化值，然后增量式更新：$$ Q(a^i) := Q(a^i) + \frac{1}{N(a^i)} (r_t - Q(a^i)) $$

这是一种有偏估计，但随着采样增加，偏差带来的影响会越来越小，不过仍然可能陷入局部最优。

实验对比数据：算法1（Optimistic, greedy：$Q_1 = 5, \epsilon = 0$）与算法2（Realistic, ε-greedy：$Q_1 = 0, \epsilon = 0.1$）的对比。

上置信界（UCB） 重点

不同动作的 $Q(a^i)$ 存在不同分布，不确定性越大的 $Q(a^i)$，越具有探索的价值，有可能会是最好的策略。

经验性指导：策略 $\pi: a = \arg \max_{a \in \mathcal{A}} \hat{Q}(a) + \hat{U}(a)$。$N(a)$ 大，$U(a)$ 小；$N(a)$ 小，$U(a)$ 大。

依据 Hoeffding 不等式：$$ \mathbb{P}[\mathbb{E}[x] > \bar{x}_t + u] \leq e^{-2tu^2} \quad \text{其中 } x \in [0,1] $$

为每个动作收益估值估计一个上置信界 $\hat{U}(a)$，显然有：$Q_t(a) \leq \hat{Q}_t(a) + \hat{U}_t(a)$ 以高概率 $p$ 成立。

UCB 公式推导：$$ e^{-2N_t(a)U_t(a)^2} = p \Rightarrow \hat{U}_t(a) = \sqrt{-\frac{\log p}{2N_t(a)}} \Rightarrow A_t = \arg \max_a \left[ Q_t(a) + c\sqrt{\frac{\ln t}{N_t(a)}} \right] $$

其中 $\ln(t)$ 表示时间 $t$ 的自然对数，$N_t(a)$ 表示从开始到 $t$ 时刻内选择动作 $a$ 的次数，$c > 0$ 用于控制探索率。

易错：UCB 的局限性包括：1. 解决不确定性问题比较难；2. 不适用于状态空间较大的问题，尤其是使用逼近函数的问题中。与 ε-greedy 相比，UCB 不容易扩展到一般强化学习中。

Thompson Sampling 方法 了解

根据每个动作成为最优的概率来选择动作：$$ p(a) = \int \mathbb{I}\left[\mathbb{E}_{p(Q(a))} [Q(a; \theta)] = \max_{a' \in \mathcal{A}} \mathbb{E}_{p(Q(a'))} (Q(a'; \theta))\right] d\theta $$

根据当前每个动作 $a$ 的价值概率分布 $p(Q(a))$ 采样得到其价值 $Q(a)$，选择价值最大的动作。

算法流程：1. D = ∅；2. for t = 1, ..., T do；3. Receive context x_t；4. Draw θ^t according to P(θ|D)；5. Select a_t = arg max_a E_r(r|x_t, a, θ^t)；6. Observe reward r_t；7. D = D ∪ {(x_t, a_t, r_t)}；8. end for

贝尔曼方程 必考

价值函数的贝尔曼方程

贝尔曼方程又叫动态规划方程，表示动态规划问题中相邻状态关系的方程。某一阶段最优决策的问题，通过贝尔曼方程转化为下一阶段最优决策的子问题，从而初始状态的最优决策可以由终状态的最优决策问题逐步迭代求解。

$$V^{\pi}(s) = \mathbb{E}[R(s_0) + \gamma R(s_1) + \gamma^2 R(s_2) + \cdots | s_0 = s, \pi]$$

$$V^{\pi}(s) = R(s) + \gamma \sum_{s' \in S} P_{s\pi(s)}(s')V^{\pi}(s')$$

其中包含了立即奖励、状态转移、时间折扣以及下一个状态的价值。

贝尔曼期望方程的分解

从 state 到 action：从当前 state 按照策略 $\pi$ 选取一个 action 会产生一个动作值函数 $q_{\pi}(s, a)$，策略表示选择每个 action 的概率，所以当前状态值函数为 $\pi(a|s)q_{\pi}(s, a)$ 对 $a$ 的累加和：$$v_{\pi}(s) = \sum_{a \in A} \pi(a|s)q_{\pi}(s, a)$$

从 action 到 state：采取一个动作，首先会获得一个 reward，然后从状态 $s$ 转移到状态 $s'$：$$q_{\pi}(s, a) = \mathcal{R}_s^a + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}_{ss'}^a v_{\pi}(s')$$

从 state 到 state：从一个 state 经过一个 action 到另一个 state，价值函数间的关系可以表示如下：$$v_{\pi}(s) = \sum_{a \in A} \pi(a|s) \left( \mathcal{R}_s^a + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}_{ss'}^a v_{\pi}(s') \right)$$

从 action 到 action：从一个 action 到另一个 action 的价值函数关系：$$q_{\pi}(s, a) = \mathcal{R}_s^a + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}_{ss'}^a \sum_{a' \in A} \pi(a'|s')q_{\pi}(s', a')$$

贝尔曼期望方程汇总：上述四个公式构成了强化学习中状态值函数与动作值函数相互转化的基础。

蒙特卡洛 重点

离线策略增量式MC策略评估

状态值函数的期望，采用加权重要性采样：$$ V_n \doteq \frac{\sum_{k=1}^{n-1} W_k G_k}{\sum_{k=1}^{n-1} W_k} $$ 其中 $W_i = \rho_{t_i:T(t_i)-1}$。

采用增量式MC：$$ V_{n+1} \doteq V_n + \frac{W_n}{C_n} [G_n - V_n], \quad n \ge 1 $$ 其中 $C$ 为累计权重：$C_{n+1} \doteq C_n + W_{n+1}$。

离线策略MC预测（策略评估）伪代码：输入任意目标策略 $\pi$。初始化 $Q(s, a)$ 和 $C(s, a) \leftarrow 0$。循环每个回合：生成行为策略 $b$ 的轨迹，$G \leftarrow 0, W \leftarrow 1$。逆序遍历轨迹：$G \leftarrow \gamma G + R_{t+1}$，更新 $C$ 和 $Q$，更新 $W \leftarrow W \cdot [\pi(A_t|S_t) / b(A_t|S_t)]$。

离线策略增量式MC策略控制

用于产生行为的策略（行为策略）与要评估和提升的策略（目标策略）是无关的。目标策略可以是确定性的（贪心的），同时行为策略能持续访问所有的动作。

需要行为策略选择所有动作的概率是非零的（覆盖）。为了保证 $\pi$ 能收敛到最优策略，对每对状态动作对，都需要收集无限次的回报，这可以通过选择 $b$ 是 $\epsilon$-soft 来保证。

离线策略MC控制伪代码：初始化 $Q(s, a)$ 和 $C(s, a) \leftarrow 0$，$\pi(s) \leftarrow \arg\max_a Q(s, a)$。循环每个回合：生成软策略 $b$ 的轨迹，$G \leftarrow 0, W \leftarrow 1$。逆序遍历：$G \leftarrow \gamma G + R_{t+1}$，更新 $C$ 和 $Q$，更新 $\pi(S_t)$。如果 $A_t \neq \pi(S_t)$ 则退出内循环，否则 $W \leftarrow W \cdot [1 / b(A_t|S_t)]$。

易错：在离线策略MC控制中，如果行为策略选择的动作不等于目标策略的贪心动作，则直接退出当前回合的更新循环。

值函数与最优策略

状态值函数公式：$$V^{\pi}(s)=\mathbb{E}\left[R\left(s_{0}\right)+\gamma R\left(s_{1}\right)+\gamma^{2} R\left(s_{2}\right)+\cdots \mid s_{0}=s, \pi\right]$$

贝尔曼方程：$$V^{\pi}(s)=R(s)+\gamma \sum_{s^{\prime} \in S} P_{s \pi(s)}\left(s^{\prime}\right) V^{\pi}\left(s^{\prime}\right)$$

最优值函数：$$V^{*}(s)=R(s)+\max _{a \in A} \gamma \sum_{s^{\prime} \in S} P_{s a}\left(s^{\prime}\right) V^{*}\left(s^{\prime}\right)$$

最优值函数也可表示为：$v^*(s) = \max_\pi v_\pi(s)$

最优策略

$$\pi^{*}(s)=\arg \max _{a \in A} \sum_{s^{\prime} \in S} P_{s a}\left(s^{\prime}\right) V^{*}\left(s^{\prime}\right)$$

最优策略也可表示为：$\pi^* = \arg\max_\pi v_\pi(s), \forall s$

模型无关的强化学习直接从经验中学习值和策略，而无需构建马尔可夫决策过程模型（MDP）。在未知马尔可夫决策过程的状态转移/奖励的场景下如何评估？

蒙特卡洛算法需要大量的片段数据，且片段都有终止状态，在很多场景下无法满足。

时序差分 必考

时间差分算法是在时间 $t+1$ 立即形成目标并使用观察到的奖励 $R_{t+1}$ 进行更新。

时序差分是模型无关的，不需要预先获取马尔可夫决策过程的状态转移/奖励，从不完整的片段中学习。时序差分更新当前预测值使之接近估计累计奖励（非真实值），具有低方差、有偏差的特点。

易错：时序差分是有偏估计，而蒙特卡洛是无偏估计；时序差分方差低，蒙特卡洛方差高。

3. n步累计奖励定义
多步时序差分学习是对1-step TD和Monte Carlo（$\infty$-step TD）的推广。考虑下列 $n$ 步累计奖励：

  • $n = 1$ (TD): $G_t^{(1)} = R_{t+1} + \gamma V(S_{t+1})$
  • $n = 2$: $G_t^{(2)} = R_{t+1} + \gamma R_{t+2} + \gamma^2 V(S_{t+2})$
  • $\vdots$
  • $n = \infty$ (MC): $G_t^{(\infty)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-1} R_T$

一般定义：$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$$

或等价地写作：$$G_{t:t+n} = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n V_{t+n-1}(S_{t+n})$$

4. n步时序差分学习更新

更新公式：$$V(S_t) \leftarrow V(S_t) + \alpha(G_t^{(n)} - V(S_t))$$

5. 随机游走的例子
实验设置：19个状态的随机行走任务，每一时刻均有均等的概率向左走或向右走。如果走到最右侧，得到的奖励为1；如果走到最左侧，得到的奖励为0。

结论：中间值的 $n$ 步方法效果最好。这说明了TD和蒙特卡罗方法对 $n$ 步方法的推广能够比两种极端方法中的任何一种方法表现更好。

二、平均n步累计奖励的TD(λ)算法 重点

可以进一步对不同 $n$ 下的 $n$ 步累计奖励求平均值，结合所有不同时间步长的信息。

1. TD(λ) 的权重分配
TD(λ) 结合了所有 $n$ 步累计奖励 $G_t^{(n)}$，使用权重 $(1 - \lambda)\lambda^{n-1}$。由于 $1 + \lambda + \lambda^2 + \cdots = \frac{1}{1 - \lambda}$，且 $\sum_{t=0}^{\infty} (1 - \lambda)\lambda^t = 1$，权重总和为1。

  • 1-step (TD) 权重：$1 - \lambda$
  • 2-step 权重：$(1 - \lambda)\lambda$
  • 3-step 权重：$(1 - \lambda)\lambda^2$
  • n-step 权重：$(1 - \lambda)\lambda^{n-1}$
  • 实际最终回报权重：$\lambda^{T-t-1}$

2. λ-累计奖励公式

定义：$$G_t^\lambda = (1 - \lambda) \sum_{n=1}^{T-t-1} \lambda^{n-1} G_t^{(n)} + \lambda^{T-t-1} G_t$$

易错：当 $\lambda = 1$ 时，$G_t^\lambda = G_t$（完整回报），相当于蒙特卡洛方法；当 $\lambda = 0$ 时，$G_t^\lambda = G_t^{(1)}$（单步回报），相当于单步时序差分方法。

3. 实验结果
在随机游走的例子中，对比不同 $n$ 值和 $\lambda$ 值的RMSE表现。在使用最佳的 $\alpha$ 与 $\lambda$ 值时，离线 $\lambda$-累计奖励算法具有稍好一些的实验结果。

三、SARSA：在线策略TD控制算法 必考

1. 基本SARSA算法
SARSA针对当前策略执行的每个（状态-动作-奖励-状态-动作）5元组 $(s, a, r, s', a')$ 进行更新：

  1. 状态 $s$，执行动作 $a$
  2. 观测到奖励 $r$
  3. 转移到下一个状态 $s'$
  4. 状态 $s'$，执行动作 $a'$

更新公式：$$Q(s, a) \leftarrow Q(s, a) + \alpha(r + \gamma Q(s', a') - Q(s, a))$$

由于更新一次值函数需要用到5个量 $(s, a, r, s', a')$，所以该算法被称为SARSA算法。

关键特征：在线策略时序差分控制使用当前策略进行动作采样。即，SARSA算法中的两个"A"都是由当前策略选择的。

2. 多步SARSA（n-step SARSA）
将 $n$ 步的思想用在控制上，应用在SARSA上，得到了 $n$ 步SARSA算法。类似于 $n$ 步TD，其 $n$ 步累计奖励定义为：$$G_{t:t+n} \doteq R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n Q_{t+n-1}(S_{t+n}, A_{t+n})$$

更新公式：$$Q_{t+n}(S_t, A_t) \doteq Q_{t+n-1}(S_t, A_t) + \alpha[G_{t:t+n} - Q_{t+n-1}(S_t, A_t)]$$

3. 期望SARSA算法
考虑与Q-learning类似的学习算法，区别在于其考虑到当前策略下每个动作的可能性，使用期望值而不是最大化下一个状态-动作对。

算法更新方式
SARSA$Q(S,A) \leftarrow Q(S,A) + \alpha[R + \gamma Q(S',A') - Q(S,A)]$
Q-learning$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha[r_{t+1} + \gamma \max_{a'_{t+1}} Q(s_{t+1}, a'_{t+1}) - Q(s_t, a_t)]$
期望SARSA$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \mathbb{E}_\pi [Q(S_{t+1}, A_{t+1}) \mid S_{t+1}] - Q(S_t, A_t) \right]$

其中期望SARSA的期望项可展开为：$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \sum_a \pi(a|S_{t+1}) Q(S_{t+1}, a) - Q(S_t, A_t) \right]$$

特点：期望SARSA是一种Off-policy算法，与Q-learning的模式相似，更新目标从Q-learning中的选择Q最大的动作，变成了期望的形式。该算法消除了由于随机选 $A_{t+1}$ 而导致的差异，一般会表现略好于SARSA。

四、Q-learning：离线策略TD控制算法 必考

1. 什么是离线策略学习
离线策略学习用于采样的策略和用于评估、改进的策略是两个不同的策略。

  • 目标策略 $\pi(a|s)$：进行值函数评估 $V_\pi(s)$ 或 $Q_\pi(s,a)$
  • 行为策略 $\mu(a|s)$：收集数据 $\{s_1, a_1, r_2, s_2, a_2, \ldots, s_T\} \sim \mu$

离线策略的优势：平衡探索和利用；通过观察人类或其他智能体学习策略；重用旧策略所产生的经验；遵循探索策略时学习最优策略；遵循一个策略时学习多个策略。

2. Q-learning更新方式
Q-learning使用了状态-动作值函数而不是状态值函数，因此不需要重要性采样算法。目标策略是greedy策略，行为策略是ε-greedy策略，两者不一样。

更新公式：$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$$

3. 悬崖行走的例子
实验设置：所有移动奖励 = -1，踏入悬崖区域会产生-100奖励并将智能体送回开始处。

实验结果：Q-learning会学习最优策略的价值，沿着悬崖边缘行进，但由于"ε-贪婪动作选择"，偶尔从悬崖上掉下来。SARSA将动作选择考虑在内，并学习通过网格上部的更长但更安全的路径。

五、Double Q-Learning 高频

1. 最大化偏差
最大估计值被隐含地用作最大值的估计值，这可能导致显著的正偏差。估计的 $Q(s,a)$ 是不确定的，真实的 $Q(s,a)$ 的最大值为0，但估计的 $Q(s,a)$ 的最大值是正值，这导致了最大化偏差。

2. Double Q-Learning算法
核心思想：将估计与选择分离，使用两个独立的估计器。

  1. 将采样数据分为两组，分别产生独立的估计值 $Q_1(s,a)$ 和 $Q_2(s,a)$
  2. 使用其中一个估计 $Q_1(s,a)$ 来决定最优动作：$A^* = \arg\max_a Q_1(s,a)$
  3. 另一个估计用来估计 $A^*$ 的值：$Q_2(s, A^*) \leftarrow Q_2(s, \arg\max_a Q_1(s,a))$，这种估计方式是无偏估计，即 $E[Q_2(A^*)] = q(A^*)$
  4. 交换两个估计的角色重复这一过程得到 $Q_1(A^*) = Q_1(\arg\max_a Q_2(a))$

Double Q-learning更新方式：$$Q_1(s,a) \leftarrow Q_1(s,a) + \alpha \left[ r + \gamma Q_2\left(s', \arg\max_{a'} Q_1(s',a')\right) - Q_1(s,a) \right]$$

$Q_1(s,a)$ 和 $Q_2(s,a)$ 每次以随机概率更新一个，保持另一个不变。

六、基于重要性采样的多步离线学习法 重点

1. 重要性采样
针对离线策略学习，由于收集数据的行为策略和需要实际优化的目标策略并不是同一个策略，则需要加上一项修正。

对于状态值函数V：$$V(s) \leftarrow V(s) + \alpha \left[ \rho_{t:t+n-1} G_{t:t+n} - V(s) \right]$$

对于动作值函数Q：$$Q(s,a) \leftarrow Q(s,a) + \alpha \left[ \rho_{t+1:t+n} G_{t:t+n} - Q(s,a) \right]$$

其中重要性采样比：$$\rho_{t:h} = \prod_{k=t}^{h} \frac{\pi(A_k | S_k)}{b(A_k | S_k)}$$

2. 离线学习场景中的两个策略

  • 目标策略 $\pi$：通常是对于目前的动作值估计函数的一个贪婪策略（也有可能是一个随机策略）
  • 行为策略 $b$：用来收集数据的，更有探索性的一个策略（常用ε-greedy来实现）

最大估计值被隐含地用作最大值的估计值，这可能导致显著的正偏差。估计的 $Q(s, a)$ 是不确定的，可能大于0，也可能小于0。真实的 $Q(s, a)$ 的最大值为0，但估计的 $Q(s, a)$ 的最大值是正值，这导致了最大化偏差。重点

最大化偏差例子

  • 初始点A
  • A向左或向右，$R=0$
  • A向右可终止
  • A向左后，状态到B
  • B向左后，存在多个动作，且 $R$ 服从 $N(-0.1, 1)$ 的分布

从A开始的任何向左轨迹的预期回报是 -0.1，因此在状态A中向左移动总是错误的。然而，控制方法可能倾向于左动作，因为最大化偏差使B看起来具有正值。

Double Q-Learning算法

  1. 将采样数据分为两组，分别产生独立的估计值 $Q_1(s, a)$ 和 $Q_2(s, a)$。
  2. 使用其中一个估计 $Q_1(s, a)$ 来决定最优动作：$$A^* = \arg\max_a Q_1(s, a)$$
  3. 另一个估计用来估计 $A^*$ 的值：$Q_2(s, A^*) \leftarrow Q_2(s, \arg\max_a Q_1(s, a))$。这种估计方式是无偏估计，即 $E[Q_2(A^*)] = q(A^*)$。
  4. 交换两个估计的角色重复这一过程得到 $Q_1(A^*) = Q_1(\arg\max_a Q_2(a))$。

重要性采样

在离线学习的场景下，会有两个策略：高频

  • 目标策略 $\pi$：通常是对于目前的动作值估计函数的一个贪婪策略（也有可能是一个随机策略）
  • 行为策略 $b$：用来收集数据的、更有探索性的策略（常用ε-greedy来实现）

针对离线策略学习，由于收集数据的行为策略和需要实际优化的目标策略并不是同一个策略，需要加上一项修正（以值函数为例）：

$$\Delta V' = \frac{\pi(a_t|s_t)}{b(a_t|s_t)} \Delta V$$

对于状态值函数 V

$$V_{t+n}(S_t) \doteq V_{t+n-1}(S_t) + \alpha \rho_{t:t+n-1} [G_{t:t+n} - V_{t+n-1}(S_t)]$$

$$\rho_{t:h} \doteq \prod_{k=t}^{\min(h,T-1)} \frac{\pi(A_k|S_k)}{b(A_k|S_k)}$$

对于动作值函数 Q

$$Q_{t+n}(S_t, A_t) \doteq Q_{t+n-1}(S_t, A_t) + \alpha \rho_{t+1:t+n} [G_{t:t+n} - Q_{t+n-1}(S_t, A_t)]$$

$$\rho_{t:h} \doteq \prod_{k=t}^{\min(h,T-1)} \frac{\pi(A_k|S_k)}{b(A_k|S_k)}$$

  • 对所有的 $s \in \mathcal{S}, a \in \mathcal{A}$，任意初始化 $Q(s, a)$
  • 初始化 $\pi$ 为关于 $Q$ 的贪婪策略，或作为一个固定的给定策略
  • Algorithm parameters: 步长 $\alpha \in (0, 1]$，正整数 $n$
  • 所有存储和访问操作（对于 $S_t, A_t$ 和 $R_t$）可以使用它们的索引对 $n+1$ 取模

    Initialize and store S₀ ≠ terminal
    Select and store an action A₀ ~ b(·|S₀)
    T ← ∞

    Loop for t = 0, 1, 2, ...:
        If t < T, then:
            Take action A_t
            Observe and store the next reward as R_{t+1} and the next state as S_{t+1}
            If S_{t+1} is terminal, then:
                T ← t + 1

            If τ + n < T, then:
                G ← G + γ^n Q(S_{τ+n}, A_{τ+n})
            Q(S_τ, A_τ) ← Q(S_τ, A_τ) + α ρ [G - Q(S_τ, A_τ)]
            If π is being learned, then ensure that π(·|S_τ) is greedy with respect to Q
    Until τ = T - 1

多步树回溯算法 (n-step Tree Backup Algorithm)

Q： Q-learning 和预期 SARSA 算法都是离线策略算法，且不需要重要性采样，是否还存在其他算法？

A： 多步树回溯算法可以将期望 SARSA 算法扩展到 n 步。以 n=3 为例，其更新结构如下：

  • $\pi(a|S_{t+1})$
  • $\pi(A_{t+1}|S_{t+1}) \ \pi(a'|S_{t+2})$
  • $\pi(A_{t+1}|S_{t+1}) \ \pi(A_{t+2}|S_{t+2}) \ \pi(a''|S_{t+3})$

更新路径为：

$S_t, A_t \to R_{t+1}, S_{t+1} \to R_{t+2}, A_{t+1}, S_{t+2} \to R_{t+3}, A_{t+2}, S_{t+3}$（3步树回溯更新）

悬挂在每个状态两侧的是未选择的行动。由于没有未选择动作的样本，需要使用它们的值估计来形成更新目标。

n步目标计算

  • 对于 n=1，就是期望 SARSA： $$G_{t:t+1} \doteq R_{t+1} + \gamma \sum_a \pi(a|S_{t+1}) Q_t(S_{t+1}, a)$$
  • 对于 n=2： $$G_{t:t+2} \doteq R_{t+1} + \gamma \sum_{a \neq A_{t+1}} \pi(a|S_{t+1}) Q_{t+1}(S_{t+1}, a) + \gamma \pi(A_{t+1}|S_{t+1}) \Big( R_{t+2} + \gamma \sum_a \pi(a|S_{t+2}) Q_{t+1}(S_{t+2}, a) \Big)$$ $$= R_{t+1} + \gamma \sum_{a \neq A_{t+1}} \pi(a|S_{t+1}) Q_{t+1}(S_{t+1}, a) + \gamma \pi(A_{t+1}|S_{t+1}) G_{t+1:t+2}$$
  • 对于一般 n，以此类推： $$G_{t:t+n} \doteq R_{t+1} + \gamma \sum_{a \neq A_{t+1}} \pi(a|S_{t+1}) Q_{t+n-1}(S_{t+1}, a) + \gamma \pi(A_{t+1}|S_{t+1}) G_{t+1:t+n}$$

算法伪代码

n-step Tree Backup for estimating $Q \approx q_*$ 或 $q_\pi$

Initialize Q(s, a) arbitrarily, for all s ∈ S, a ∈ A
Initialize π to be greedy with respect to Q, or as a fixed given policy
Algorithm parameters: step size α ∈ (0, 1], a positive integer n
All store and access operations can take their index mod n + 1

Loop for each episode:
    Initialize and store S0 ≠ terminal
    Choose an action A0 arbitrarily as a function of S0; Store A0
    T ← ∞
    Loop for t = 0, 1, 2, ...:
        If t < T:
            Take action At; observe and store the next reward and state as R_{t+1}, S_{t+1}
            If S_{t+1} is terminal:
                T ← t + 1
            else:
                Choose an action A_{t+1} arbitrarily as a function of S_{t+1}; Store A_{t+1}
        
        τ ← t + 1 - n (τ is the time whose estimate is being updated)
        If τ ≥ 0:
            If t + 1 ≥ T:
                G ← R_T
            else:
                G ← R_{t+1} + γ ∑_a π(a|S_{t+1}) Q(S_{t+1}, a)
            
            Loop for k = min(t, T - 1) down through τ + 1:
                G ← R_k + γ ∑_{a ≠ A_k} π(a|S_k) Q(S_k, a) + γ π(A_k|S_k) G
            
            Q(S_τ, A_τ) ← Q(S_τ, A_τ) + α [G - Q(S_τ, A_τ)]
            
            If π is being learned, then ensure that π(·|S_τ) is greedy with respect to Q
            
    Until τ = T - 1

模型与规划

模型

给定一个状态和动作，模型能够预测下一个状态和奖励的分布，即：

$$p(s', r \mid s, a)$$

  • $s, a$：给定的状态和动作
  • $s', r$：下一个状态和奖励

模型的分类

  • 分布模型：描述了轨迹的所有可能性及其概率。
  • 样本模型：根据概率进行采样，只产生一条可能的轨迹。

掷骰子（例子）

  • 分布模型：得到骰子数字总和的所有可能性及其概率。
  • 样本模型：只采样得到一种骰子数字总和。

规划

规划：输入一个模型，输出一个策略的搜索过程。

模型 $\xrightarrow{\text{规划}}$ 策略

规划的分类

  • 状态空间的规划：在状态空间搜索最佳策略。
  • 规划空间的规划：在规划空间搜索最佳策略，包括遗传算法和偏序规划。一个规划就是一个动作集合以及动作顺序的约束。

规划在强化学习中的应用框架

通过模型采样得到模拟数据，利用模拟数据更新值函数从而改进策略：

模型 $\xrightarrow{\text{采样}}$ 模拟经验 $\xrightarrow{\text{回溯}}$ 值函数 $\xrightarrow{\text{规划}}$ 策略

如动态规划算法，搜索整个状态空间，生成所有的状态转移分布，状态转移分布回溯更新状态的值函数。RL使用规划的好处是，任何时间点可以被打断或者重定向，在复杂问题下，进行小而且增量式的时间步规划是很有效的。

Random-sample one-step tabular Q-planning

将Q-learning和planning结合：

Loop forever:
1. Select a state, S ∈ S, and an action, A ∈ A(S), at random
2. Send S, A to a sample model, and obtain a sample next reward, R, and a sample next state, S'
3. Apply one-step tabular Q-learning to S, A, R, S':
   Q(S, A) ← Q(S, A) + α [ R + γ max_a Q(S', a) - Q(S, A) ]

不同点

  • 规划：利用模型产生的模拟经验。
  • 学习：利用环境产生的真实经验。

相同点

通过回溯更新值函数的估计。统一来看，学习的方法可以用在模拟经验上。

Dyna

Dyna：集成规划、行动和学习。重点

工作原理：

  • 图左是 Agent 与环境交互产生真实经验，更新值函数和策略，这里称为直接强化学习。
  • 真实经验可以更新环境模型（模型学习）。
  • 基于模型随机采样得到模拟经验，只从以前得到的状态动作对随机采样。使用模拟经验做规划更新值函数和策略。

流程：

  1. 与环境交互的样本更新 Q
  2. 与环境交互的样本更新模型
  3. 模型产生新的模拟样本
  4. 模拟样本更新 Q

算法伪代码

Initialize Q(s, a) and Model(s, a) for all s ∈ S, a ∈ A

Loop forever:
    (a) S ← current (start) state
    (b) A ← ε-greedy(S, Q)
    (c) Execute action A; observe resultant reward, R, and state, S'

    (e) Model(S, A) ← R, S' (assuming deterministic environment)
    (f) Loop repeat n times:
        S ← random previously observed state
        A ← random action previously taken in S
        R, S' ← Model(S, A)
        Q(S, A) ← Q(S, A) + α [R + γ max_a Q(S', a) − Q(S, A)]

Dyna-Q+ 算法：增加了探索的概率。

奖励更改为：

$$r' = r + K\sqrt{\tau}$$

其中：

  • $r$：原来的奖励
  • $K$：小的权重参数
  • $\tau$：某个状态多久未到达过了

当环境变得比以前变得更好时，会出现更大的困难，但以前正确的策略并未显示出改善。在这些情况下，可能无法长时间检测到建模错误。

规划之优先级采样

如果模拟样本更新专注于特定的状态-动作对，则规划可以更加有效。

规划过程中的采样方法

后向聚焦：很多状态的值发生变化会带动前继状态的值发生变化。有的值改变很多，有的改变很少，因此需要根据紧急程度给这些更新设置优先度进行更新。

优先级采样：设置优先级更新队列，根据值改变的幅度定义优先级。

流程：

  1. 采用 ε-greedy 贪心算法
  2. 更新模型
  3. 计算优先级
  4. 根据优先级排序进队列
  5. 获取模型的模拟数据
  6. 模拟样本更新 Q
  7. 对于所有能够到达的 S/A：
    • 模型预测的 R
    • 计算优先级
    • 根据优先级排序进队列

迷宫的例子

  • 横轴代表格子世界的大小
  • 纵轴代表收敛到最优策略的更新次数

优先级采样收敛更快，优先扫描比未优先的 Dyna-Q 保持了决定性的优势。

优先级采样的限制之一是它使用期望更新，这在随机环境中可能会浪费大量的计算在低概率转换上。

杆操纵例子：优先级采样可以发现障碍，以及快速找到最短解决方案。

规划之采样方法

期望更新与采样更新

  • 值函数 V(S)
  • 动作值函数 Q(S, A)

期望更新：需要分布模型，计算量更大，但无偏差、更准确。

采样更新：按照 π 进行采样，只需要采样模型，计算量需求更低，但受采样误差影响。

不同分支因子下的表现

  • b 表示当前状态有 b 个后续或前序状态
  • 初始估计误差为 1
  • 下一个状态值假设估计正确
  • 分支因子越多，采样更新越接近期望更新；在大的随机分支和状态数量较多的情况下，采样更新更好

轨迹采样

状态转移和奖励由模型决定，动作由当前的策略决定。在一个持续的任务中，从任何地方开始，只是不断模拟。在任何一种情况下，模型都会给出样本状态转换和奖励，并且当前策略会给出样本动作。模拟明确的单独轨迹，并在沿途遇到的状态或状态-动作对上执行更新。

称这种产生经验并更新的方式为轨迹采样。

轨迹采样不需要知道当前策略下状态的分布，且计算量少，简单有效。但缺点是不断重复更新已经被访问的状态。

不同分支因子下的表现：在 b>1（非确定性）场景下，采用轨迹采样要优于 On-Policy 算法。

实时动态规划

实时动态规划：在当前状态下实施实时的轨迹采样后，只更新轨迹访问的状态值。

跑道问题

  • 环境：任务是从起点跑到终点。状态为二维坐标、二维速度。动作是每维速度的 +1、-1、不变。
  • 优势：
    • 能够跳过策略无关的状态
    • 在解决状态集合规模大的问题上具有优势
    • 满足一定条件下可以以概率 1 收敛到最优策略
  • 结果：可到达状态中，随机策略为 9115，最优策略为 599，更新次数少了一半。

蒙特卡洛树搜索 (Monte Carlo Tree Search, MCTS)

Rollout 算法

Rollout 算法是基于模拟轨迹的蒙特卡洛控制的决策时规划算法。在当前环境状态下开始，通过从每个可能的动作开始然后遵循给定策略的许多模拟轨迹的回报来估计给定策略的行动价值。当动作价值估计被认为足够准确时，执行具有最高估计值的动作，之后从所得到的下一状态重新执行该过程。

决策时规划

  • 背景规划：规划不关注于当前状态，基于从模型（样本或分布模型）获得的模拟经验，使用规划逐步改进策略或价值函数。规划是为了更新很多状态值供后续动作的选择，如动态规划、Dyna。
  • 决策时规划：通过比较每个动作的模型预测的下一个状态的价值来选择一个动作，只着眼于当前状态的动作选择。在不需快速反应的应用中很有效，如棋类游戏。

决策时规划从当前状态进行 rollout，类似于策略迭代和改进，寻找更优的策略。表现取决于蒙特卡洛方法估值的准确性。

Rollout 算法加速方法：并行、剪枝

  • 多个处理器并行采样
  • 轨迹截断，用存储的值估计代替回报
  • 剔除不可能成为最佳动作的动作

1.3 环境发生改变时的处理：Dyna-Q+

重点 如果环境中途发生改变怎么办？

Dyna-Q+算法：增加探索的概率。

  • 奖励改为：r + K√τ
  • r：原来的奖励
  • K：小的权重参数
  • τ：某个状态-动作对多久未被访问过

当环境变得比以前更好时，会出现更大的困难，因为以前正确的策略并未显示出改善。在这些情况下，可能无法长时间检测到建模错误。Dyna-Q+通过给予长期未访问的状态-动作对额外的奖励，鼓励Agent进行探索，从而更快适应环境的变化。在累积奖励的对比中，Dyna-Q+在环境变化后能比Dyna-Q更快地恢复并提升奖励获取。

易错：Dyna-Q+的奖励修改公式中，τ表示状态-动作对未被访问的时间，而不是状态本身。

2. 规划之优先级采样

2.1 优先级采样

优先级采样：规划过程中的采样方法，如果模拟样本更新专注于特定的状态-动作对，则规划可以更加有效。

  • 无用的更新示例：0 ← 0 + γ × 0
  • 有用的更新示例：1 ← 1 + γ × 0

后向聚焦：很多状态的值发生变化会带动其前继状态的值发生变化。有的值改变很多，有的改变很少，因此需要根据紧急程度，给这些更新设置优先级进行更新。

设置优先级更新队列，根据值改变的幅度定义优先级：P ← |R + γ max_a Q(S', a) - Q(S, A)|

2.2 确定性环境下的优先级扫描算法

Initialize Q(s, a), Model(s, a), for all s, a, and PQueue to empty
Loop forever:
(a) S ← current (nonterminal) state
(b) A ← policy(S, Q)           // 采用ε-greedy贪心算法
(c) Take action A; observe resultant reward, R, and state, S'
(d) Model(S, A) ← R, S'       // 更新模型
(e) P ← |R + γ maxa Q(S', a) - Q(S, A)|    // 计算优先级
(f) if P > θ, then insert S, A into PQueue with priority P  // 根据优先级排序进队列
(g) Loop repeat n times, while PQueue is not empty:
    S, A ← first(PQueue)
    R, S' ← Model(S, A)                       // 获取模型的模拟数据
    Q(S, A) ← Q(S, A) + α[R + γ maxa Q(S', a) - Q(S, A)]  // 用模拟样本更新Q
    Loop for all S, A predicted to lead to S:   // 对于所有能够到达S的前继状态
        R ← predicted reward for S, A, S      // 模型预测的R
        P ← |R + γ maxa Q(S, a) - Q(S, A)|    // 计算优先级
        if P > θ then insert S, A into PQueue with priority P  // 根据优先级排序进队列

3.2 轨迹采样

轨迹采样：状态转移和奖励由模型决定，动作由当前策略决定。在一个持续的任务中，从任何地方开始，只是不断模拟。模型给出样本状态转换和奖励，当前策略给出样本动作。模拟明确的单独轨迹，并在沿途遇到的状态或状态-动作对上执行更新。

  • 优点：轨迹采样不需要知道当前策略下状态的分布，且计算量少，简单有效。
  • 缺点：会不断重复更新已经被访问的状态。
核心要点：在 b>1（非确定性）场景下，采用轨迹采样要优于均匀采样。

4. 实时动态规划

实时动态规划（Real-Time Dynamic Programming, RTDP）：在当前状态下实施实时的轨迹采样后，只更新轨迹访问的状态值。

优势：

  • 能够跳过策略无关的状态
  • 在解决状态集合规模大的问题上具有优势
  • 满足一定条件时可以以概率1收敛到最优策略

决策时规划

背景规划：规划不关注于当前状态，基于从模型获得的模拟经验，使用规划逐步改进策略或价值函数。规划是为了更新很多状态值供后续动作的选择，如动态规划、Dyna。

核心直觉与策略梯度基础 必考

对于随机策略，应当降低带来较低价值/奖励的动作出现的概率，提高带来较高价值/奖励的动作出现的概率。

策略的价值期望

起始状态为 $s \sim d(s)$，策略的价值期望可以写成： $$J(\theta) = \mathbb{E}_{\pi_{\theta}}[r] = \sum_{s \in S} d(s) \sum_{a \in A} \pi_{\theta}(a|s)r_{sa}$$

似然比（Likelihood Ratio）

似然比利用下列特性： $$\frac{\partial \pi_{\theta}(a|s)}{\partial \theta} = \pi_{\theta}(a|s) \frac{1}{\pi_{\theta}(a|s)} \frac{\partial \pi_{\theta}(a|s)}{\partial \theta} = \pi_{\theta}(a|s) \frac{\partial \log \pi_{\theta}(a|s)}{\partial \theta}$$

对策略的价值期望求导并代入似然比特性： $$\frac{\partial J(\theta)}{\partial \theta} = \sum_{s \in S} d(s) \sum_{a \in A} \pi_{\theta}(a|s) \frac{\partial \log \pi_{\theta}(a|s)}{\partial \theta} r_{sa} = \mathbb{E}_{\pi_{\theta}} \left[ \frac{\partial \log \pi_{\theta}(a|s)}{\partial \theta} r_{sa} \right]$$

这一结果可以通过从 $d(s)$ 中采样状态 $s$ 和从 $\pi_{\theta}$ 中采样动作 $a$ 来近似估计，这是策略梯度方法的基石。

Softmax随机策略与MC策略梯度 重点

Softmax策略

Softmax策略是一种非常常用的随机策略： $$\pi_{\theta}(s,a) = \frac{\exp(f_{\theta}(s,a))}{\sum_{a'} \exp(f_{\theta}(s,a'))}$$ 其中，$f_{\theta}(s,a)$ 是用 $\theta$ 参数化的状态-动作对得分函数，可以预先定义。

其对数似然的梯度为： $$\nabla_{\theta}\log \pi_{\theta}(s,a) = \nabla_{\theta}f_{\theta}(s,a) - \mathbb{E}_{a' \sim \pi_{\theta}}[\nabla_{\theta}f_{\theta}(s,a')]$$

举线性得分函数 $f_{\theta}(s,a) = \theta^T x(s,a)$ 为例，则有： $$\nabla_{\theta}\log \pi_{\theta}(s,a) = x(s,a) - \mathbb{E}_{a' \sim \pi_{\theta}}[x(s,a')]$$

蒙特卡洛策略梯度（REINFORCE）

策略梯度公式： $$\nabla_{\theta}J(\theta) = \mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(s,a) \cdot G_t]$$

随机梯度上升更新参数： $$\theta \leftarrow \theta + \alpha \nabla_{\theta}\log \pi_{\theta}(s,a) \cdot G_t$$

其中，利用累计奖励值 $G_t$ 作为 $Q(s_t, a_t)$ 的无偏采样。

REINFORCE算法通过生成完整轨迹，计算累计折扣奖励 $G_t$，并以此进行策略参数的更新。可通过多次 roll-out 的 $G_t$ 平均值来逼近 $Q(s_t, a_t)$。
易错：REINFORCE必须基于片段式数据，需要等待完整回合结束才能计算 $G_t$，且具有高训练方差的缺陷。

近似带Baseline的MC策略梯度 高频

策略梯度方法常用 baseline 来降低方差，让收敛更快。Baseline 是一个函数 $b(s)$，它不依赖于动作 $a$。

带baseline的策略梯度公式

$$\nabla_{\theta}J(\theta) = \mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(s,a) \cdot (Q^{\pi_{\theta}}(s,a) - b(s))]$$

带 baseline 的策略梯度更新公式： $$\theta \leftarrow \theta + \alpha \nabla_{\theta}\log \pi_{\theta}(s,a) \cdot (G_t - b(s))$$

一般采用 $b = V^{\pi}(s_t)$ 作为 baseline。选择 $V^{\pi}(s_t)$ 的原因在于其值接近 $Q^{\pi}(s_t, A_t)$，能够有效地降低方差。当 $b = 0$ 时，相当于不使用 baseline，得到的是标准的策略梯度。

REINFORCE with baseline 伪代码

初始化策略参数 $\theta$ 和价值函数参数 $\theta_v$。对每个回合生成完整轨迹，计算 $G_t$ 和误差 $\delta = G_t - V_{\theta_v}(s_t)$，然后分别更新价值函数参数和策略参数： $$\theta_v \leftarrow \theta_v + \alpha_v \delta \nabla_{\theta_v} V_{\theta_v}(s_t)$$ $$\theta \leftarrow \theta + \alpha \gamma^t \delta \nabla_\theta \log \pi_\theta(s_t, a_t)$$

Actor-Critic网络（AC） 必考

REINFORCE 存在的问题

1. 基于片段式数据的任务：通常情况下，任务需要有终止状态，REINFORCE 才能直接计算累计折扣奖励。

2. 低数据利用效率：实际中，REINFORCE 需要大量的训练数据。

3. 高训练方差（最重要的缺陷）：从单个或多个片段中采样到的值函数具有很高的方差。

演员和评论家

REINFORCE 策略梯度方法使用蒙特卡洛采样直接估计 $Q(s_t, a_t)$ 的值 $G_t$。为什么不建立一个可训练的价值函数 $Q_{\phi}$ 来完成这个估计过程？

Actor-Critic 框架的核心思想： - 评论家：学会准确估计当前演员策略的动作价值 $Q_{\phi}(s,a)$。 - 演员：学会采取使 critic 满意的动作，即根据 critic 提供的价值信号更新策略参数。

Actor-Critic 训练

Actor-Critic 框架同时学习了价值函数和策略，通过价值函数 $Q$（或 Advantage）估计，以策略梯度的方式更新策略参数： $$\nabla_{\theta}J(\theta) = \mathbb{E}[\nabla_{\theta}\log \pi_{\theta}(s,a) \cdot Q_{\phi}(s,a)]$$

Critic 参数更新（以 TD 方式为例）： $$\phi \leftarrow \phi + \alpha_Q (r + \gamma Q_{\phi}(s',a') - Q_{\phi}(s,a)) \nabla_{\phi}Q_{\phi}(s,a)$$

Actor 参数更新： $$\theta \leftarrow \theta + \alpha_{\theta} Q_{\phi}(s,a) \nabla_{\theta}\log \pi_{\theta}(s,a)$$

One-step Actor-Critic 伪代码

初始化策略参数 $\theta$ 和状态值权重 $\mathbf{w}$。对每个episode，初始化状态 $S$ 和 $I \leftarrow 1$。当 $S$ 不是终止状态时循环：采样动作 $A$，执行并观察 $S', R$，计算 $\delta \leftarrow R + \gamma \hat{v}(S', \mathbf{w}) - \hat{v}(S, \mathbf{w})$，更新权重和策略参数，并更新 $I \leftarrow \gamma I$ 和 $S \leftarrow S'$。

A3C（Asynchronous Advantage Actor Critic） 重点

优势Actor-Critic（A2C）

通过Q函数减去一个基线函数来标准化评论家的打分，提供更多信息指导，降低较差动作的概率，提高较优动作的概率，进一步降低方差。

优势函数： $$A^{\pi}(s, a) = Q^{\pi}(s, a) - V^{\pi}(s)$$

A3C 简介

A3C 即异步优势动作评价，其名称包含以下三个核心概念：

1. 动作评价：这是一种 Actor-Critic 方法，它涉及一个在学得的状态值函数帮助下进行更新的策略。 $$\nabla_{\theta^{\prime}} \log \pi\left(a_{t} \mid s_{t} ; \theta^{\prime}\right) A\left(s_{t}, a_{t} ; \theta_{v}\right)$$ $$A\left(s_{t}, a_{t} ; \theta_{v}\right)=\sum_{i=0}^{k-1} \gamma^{i} r_{t+i}+\gamma^{k} V\left(s_{t+k} ; \theta_{v}\right)-V\left(s_{t} ; \theta_{v}\right)$$

2. 异步：算法涉及并行执行一组环境。

3. 优势：策略梯度的更新使用优势函数。

A3C: Asynchronous advantage actor-critic 重点

A3C（Asynchronous advantage actor-critic）算法的伪代码主要针对每个 actor-learner 线程。假设全局共享参数向量为 θ 和 θ_v，全局共享计数器 T = 0，线程特定参数向量为 θ' 和 θ_v'。

算法流程如下：

1. 初始化线程步数计数器 t ← 1。

2. 循环执行以下操作直到 T > T_max：

- 重置梯度：dθ ← 0 和 dθ_v ← 0。

- 同步线程特定参数：θ' = θ 和 θ_v' = θ_v。

- 设置 t_start = t，获取状态 s_t。

- 循环执行动作 a_t（根据策略 π(a_t | s_t ; θ')），接收奖励 r_t 和新状态 s_{t+1}，更新 t ← t + 1 和 T ← T + 1，直到达到终止状态 s_t 或 t - t_start == t_max。

- 计算 R：若为终止状态则为 0，若为非终止状态则从最后状态 Bootstrap，即 V(s_t, θ_v')。

- 对于 i ∈ {t-1, ..., t_start}，计算 R ← r_i + γR，累积关于 θ' 的梯度 dθ ← dθ + ∇_{θ'} log π(a_i | s_i ; θ') (R - V(s_i ; θ_v'))，并累积关于 θ_v' 的梯度 dθ_v ← dθ_v + ∂(R - V(s_i ; θ_v'))^2 / ∂θ_v'。

- 使用 dθ 和 dθ_v 异步更新 θ 和 θ_v。

深度Q网络（DQN） 必考

深度强化学习的分类

深度强化学习主要分为三类方法：

1. 基于价值的方法：深度Q网络（DQN）及其扩展。

2. 基于随机策略的方法：使用神经网络的策略梯度、自然策略梯度、信任区域策略优化（TRPO）、近端策略优化（PPO）、A3C。

3. 基于确定性策略的方法：确定性策略梯度（DPG）、DDPG。

DQN基础与相关迭代算法

DQN 通过最小化损失函数来更新网络参数：θ_t ← arg min_θ L(Q(S_t, A_t ; θ), R_t + γ Q(S_{t+1}, A_{t+1} ; θ))。

相关迭代算法包括：

- 拟合Q迭代（Fitted Q Iteration） (Riedmiller, 2005)：收集 D 份采样，设置目标 Y_i ← R_i + γ max_a Q(S_i', a ; θ)，通过最小化误差平方更新 θ。

- 在线Q迭代（Online Q Iteration）：与环境交互得到数据，设置 y ← r + γ max_{a'} Q(s', a' ; θ)，通过梯度下降更新 θ。

易错：拟合 Q 迭代和在线 Q 迭代都是离线策略算法。

DQN关键技术

近似学习状态-动作值函数的方法存在收敛不稳定性问题，DQN 通过以下关键技术解决：

1. 经验回放（Experience Replay）：存储训练过程中的每一步 e_t 于数据库 D 中，采样时服从均匀分布。经验回放将行为策略产生的历史数据存储进经验池，减弱数据相关性，一定程度平滑数据分布。在经验池均匀采样 Batch 样本训练。经验池更新遵循"先入先出"原则（FIFO 缓存）。

2. 双网络结构：包含评估网络（Evaluation Network）和目标网络（Target Network）。目标网络使用较旧的参数，记为 θ^-，每隔 C 步和训练网络的参数同步一次。第 i 次迭代的损失函数为：L_i(θ_i) = E[(r + γ max_{a'} Q(s', a'; θ_i^-) - Q(s, a; θ_i))^2]。

DQN的核心在于通过经验回放打破数据相关性，以及通过目标网络稳定训练过程，解决Q-learning在深度神经网络中收敛不稳定的问题。

DQN算法流程与伪代码

DQN算法流程如下：

1. 收集数据：使用 ε-greedy 策略进行探索，将得到的状态动作组 (s_t, a_t, s_{t+1}, r_t) 放入经验池。

2. 采样：从数据库中采样 k 个动作状态组。

3. 更新网络：用采样得到的数据计算 Loss，更新 Q 函数网络 θ。每 C 次迭代（更新 Q 函数网络后）更新一次目标网络 θ^-。

伪代码中，超参数包括回放缓存容量 N，奖励折扣因子 γ，延迟步长 C，ε-greedy 中的 ε。初始化空回放缓存 D 和参数 θ，并令 θ^ ← θ。在每个片段和每步中，通过 ε-greedy 选择动作，存储转移数据 (φ_t, A_t, R_t, D_t, φ_{t+1}) 到 D 中。从 D 中随机采样小批量数据，若 D_i = 0 则 Y_i = R_i + γ max_{a'} Q^(φ'_i, a'; θ^)，否则 Y_i = R_i。在 (Y_i - Q(φ_i, A_i; θ))^2 上对 θ 执行梯度下降，每 C 步同步目标网络。

DQN 的改进方法 高频

Q-learning 中的过估计问题与 Double DQN

在 Q-learning 中，Target 值 y_t = r_t + γ max_{a'} Q_θ(s_{t+1}, a')。max 操作使得 Q 函数的值越来越大，甚至高于真实值。Q函数的过高估计程度随着候选行动数量增大而变得更严重。

Double DQN 的核心思想是使用不同的网络来估值和决策，解耦合行动选择和价值估计，解决 DQN 过高估计问题。

DQN: y_t = r_t + γ Q_θ(s_{t+1}, arg max_{a'} Q_θ(s_{t+1}, a'))

Double DQN: y_t = r_t + γ Q_{θ'}(s_{t+1}, arg max_{a'} Q_θ(s_{t+1}, a'))

Dueling DQN

Advantage 函数定义为：A^π(s, a) = Q^π(s, a) - V^π(s)。

Dueling DQN 将Q函数分解为状态值函数和Advantage函数之和，有两种聚合形式：

1. Q(s, a; θ, α, β) = V(s; θ, β) + (A(s, a; θ, α) - max_{a' ∈ |A|} A(s, a'; θ, α))

2. Q(s, a; θ, α, β) = V(s; θ, β) + (A(s, a; θ, α) - (1/|A|) Σ_{a'} A(s, a'; θ, α))

其中包含三个主要部分：Q函数、状态值函数 (V)、Advantage函数 (A)。

优先经验回放（Prioritized Experience Replay，PER）

优先经验回放（PER）是一种将经验进行优先排序的技术，使重要的状态转移经验被更加频繁地回放。

衡量标准：以 Q 函数的值与 Target 值的差异（即TD误差 δ_i）来衡量学习的价值，即 |δ_i| 越大，该样本的学习价值越高。p_t = |r_t + γ max_{a'} Q_θ(s_{t+1}, a') - Q_θ(s_t, a_t)|。

选中的概率：为了使各样本都有机会被采样，样本 e_t 被选中的概率为 P(i) = p_i^α / Σ_k p_k^α。p_i 有两种变体：

- 比例优先：p_i = |δ_i| + ε

- 顺序优先：p_i = 1 / rank(i)，其中 rank(i) 是状态转移 i 基于 |δ_i| 的等级评定。

重要性采样权重：PER 使用了重要性采样权重来修正状态转移 i 的偏差，权重为 w_i = (N · P(i))^{-β} / max_j w_j。N 指回放缓存的容量大小，β 是训练过程中采用退火的超参数，随着训练增加，更新会趋近于无偏。

基于优先经验回放的 Double DQN 算法在每次采样时根据 P(j) 采样，计算重要性采样权重 w_j 和 TD-error δ_j，更新优先级 p_j ← |δ_j|，并累积权重变化更新网络参数。

多种强化学习算法的性能对比：Rainbow 了解

Rainbow 结合了众多 Value-based DRL 方法，大幅提升了性能。结合的方法包括：DQN、DDQN (Double DQN)、Prioritized DDQN、Dueling DDQN、A3C、Distributional DQN、Noisy DQN。在以人类标准化得分中位数为指标的对比中，Rainbow 展现了最优的综合性能。

深度确定性策略梯度（DDPG, Deep Deterministic Policy Gradient） 重点

随机策略与确定性策略

随机策略：

- 对于离散动作：π(a|s) 输出动作的概率分布，如 π(a|s; θ) = exp{Q_θ(s, a)} / Σ_{a'} exp{Q_θ(s, a')}。

- 对于连续动作：π(a|s) 输出动作的概率密度函数（如高斯分布的均值和方差），如 π(a|s; θ) ∝ exp{-(a - μ_θ(s))^2}。

确定性策略：

- 对于离散动作：a = μ(s) 直接输出唯一的动作，π(s; θ) = arg max_a Q_θ(s, a)（不可微）。

- 对于连续动作：a = μ(s) 直接输出确定性的动作值，a = π(s; θ)（可微）。

确定性策略梯度定理

用于估计状态-动作值的评论家模块：Q^w(s, a) ≃ Q^π(s, a)，损失函数 L(w) = E[(Q^w(s, a) - Q^π(s, a))^2]。

确定性策略梯度定理：定义了在确定性策略下，策略参数更新的梯度方向。J(π_θ) = E[Q^w(s, a)]，其梯度为 ∇_θ J(π_θ) = E[∇_θ π_θ(s) ∇_a Q^w(s, a)|_{a=π_θ(s)}]。

易错：确定性策略梯度定理利用链式法则，是在线策略的。但在实际应用中，带有神经函数近似器的 Actor-Critic 方法是不稳定的。

DDPG的改进与模块框架

DDPG 结合了 DQN 和 DPG，DQN 用于高维输入离散动作空间，DPG 用于低维输入连续动作空间，是一个离线策略算法。为了解决不稳定性，DDPG 给出了在 DPG 基础上的解决方法：

- 经验重放（离线策略）

- 目标网络

- 在动作输入前批标准化 Q 网络

- 添加连续噪声：N_t 是探索噪声（如高斯噪声），避免参数陷入局部解，产生探索性动作 a_t = μ(s_t; θ^μ) + N_t。

DDPG 模块框架图包含四个网络：

1. Actor 当前网络：a = π_θ(s)，根据当前状态 s 选择当前执行的确定性动作 a，用于和环境交互生成 s', r。

2. Critic 当前网络：估计当前 Q 值 Q_w(s, a)。

3. Critic 目标网络：估计 target Q 值 r + γ Q_{w^-}(s', a')。

4. Actor 目标网络：a' = π_{θ^-}(s')，根据经验回放池中采样的下一状态 s' 选择动作 a'，用于估计 target Q 值。

DDPG通过引入经验回放、目标网络、批标准化和连续噪声，成功将DQN的思想扩展到连续动作空间的确定性策略梯度中，解决了原DPG算法的不稳定性问题。

参考答案DDPG通过引入经验重放（离线策略）、目标网络、在动作输入前批标准化Q网络以及添加连续噪声来解决不稳定性问题。

信赖域策略优化 (TRPO, Trust Region Policy Optimization)

策略梯度的缺点 必考

策略梯度方法存在步长不好确定的缺陷。如果步长过大，学习算法的性能可能会突然大幅下降；如果步长太小，学习过程会太保守而非常缓慢。不做限制的梯度上升法很可能由于“步子太大”而越过局部最优。可信任区域限制的梯度上升法能有效降低“踩空落崖”的风险。

易错：策略梯度中步长的选择至关重要，不加限制的梯度上升极易导致性能崩溃。

信任区域

在信任区域上更新策略时能够得到某种策略性能的安全性保证。当前策略为 $\pi_\theta$，需要找更优的 $\theta'$，使得 $J(\theta') \ge J(\theta)$。

新旧策略目标函数差距可表示为：$J(\theta') - J(\theta) = \mathbb{E}_{s \sim \rho_{\pi_{\theta'}}, a \sim \pi_{\theta'}}[A_{\pi_\theta}(s, a)]$。将时序差分残差定义为优势函数：$A_{\pi}(s, a) = Q_\pi(s, a) - V_\pi(s)$。

如果能找到新策略使得期望优势函数 $\mathbb{E}[A_{\pi_\theta}(s, a)] \ge 0$，就能保证策略性能单调递增。

TRPO 优化公式 重点

忽略状态访问分布变化，直接采用旧策略的状态分布，定义替代优化目标。由于无法直接从新策略采样，使用重要性采样处理动作分布。

TRPO 使用KL散度衡量策略之间的距离，约束条件定义了策略空间中的一个 KL球，即信任区域。在这个区域中，可以认为当前学习策略和环境交互的状态分布与上一轮策略最后采样的状态分布一致。

TRPO 的近似求解

TRPO 在具体实现中做了一步近似操作来快速求解：$\theta' = \theta + \alpha \cdot H^{-1} g$。其中 $g$ 表示目标函数的梯度，$H$ 表示策略之间平均 KL 距离的 Hessian 矩阵（即 Fisher 信息矩阵）。

优化目标变为二次规划问题，可以用卡罗需-库恩-塔克（KKT）条件直接导出解。

TRPO 算法（On-Policy）伪代码

1. 初始化策略参数 $\theta$，值函数参数 $\phi$。

2. 循环迭代：运行当前策略采样轨迹，计算优势函数估计，估计策略梯度 $g$ 和 Fisher 信息矩阵 $H$。

3. 用共轭梯度法计算搜索方向 $x \leftarrow H^{-1} g$，进行线搜索找到满足 KL 约束的最大步长 $\alpha$，更新 $\theta$ 和 $\phi$。

深度确定性策略梯度 (DDPG)

算法概述 必考

DDPG 结合了 DQN（适用于高维输入、离散动作空间）和 DPG（适用于低维输入、连续动作空间），是融合两者优势的离线策略算法。

网络结构与功能

DDPG 采用 Actor-Critic 架构，包含四个神经网络：

1. Actor当前网络：根据当前状态选择确定性动作与环境交互。

2. Critic当前网络：估计当前Q值 $Q_w(s,a)$。

3. Critic目标网络：估计目标Q值 $r+\gamma Q_{w^-}(s',a')$。

4. Actor目标网络：根据下一状态选择动作用于估计目标Q值。

DQN与DDPG目标函数对比 重点

DQN目标Q值计算使用 $\max_{a'} Q_{w^-}(s',a')$，而DDPG使用 $Q_{w^-}(s',\pi_{\theta^-}(s'))$。

易错：DDPG在计算目标Q值时，使用 Actor目标网络 输出的确定性动作替代DQN中的 max 操作，从而适应连续动作空间。

模块框架与伪代码

模式为 Off-policy，使用经验回放池存储 $(s, a, r, s')$。损失函数为 $L = \mathbb{E}[(r + \gamma Q(a') - Q(a))^2]$。目标网络采用软更新：$\theta^{Q'} \leftarrow \tau \theta^Q + (1 - \tau) \theta^{Q'}$。

近端策略优化（PPO, Proximal Policy Optimization）

TRPO的不足与PPO概述 高频

TRPO 存在重要性比例带来大方差、求解约束优化困难、二阶共轭梯度复杂且近似有误差等问题。PPO 优化目标与 TRPO 相同，但用更简单的方法求解，分为 PPO-惩罚 和 PPO-截断 两种形式。

PPO-惩罚

用拉格朗日乘数法将 KL 散度的限制放进目标函数中，变成无约束优化问题。在迭代过程中根据约束违反程度动态调整系数 $\beta$：若 $d_k < \delta/1.5$ 则减半，若 $d_k > \delta \times 1.5$ 则加倍。

PPO-截断 必考

在目标函数中进行限制，使用 clip 函数保证新的参数和旧的参数的差距不会太大。超参数 $\epsilon$ 表示截断的范围。

PPO-截断通过限制重要性采样的比例范围，构建优化目标的下界，进一步保证优化的稳定效果。

近似算法演进关系

基于价值的近似算法

Q学习 $\rightarrow$ DQN $\rightarrow$ Double DQN (解决过估计) $\rightarrow$ Dueling DQN (分解V和A) 等，引入了经验回放和目标网络等技术。

基于策略的近似算法

策略梯度 (PG) $\rightarrow$ AC $\rightarrow$ A3C/A2C $\rightarrow$ TRPO $\rightarrow$ PPO $\rightarrow$ DPG $\rightarrow$ DDPG 等。

第三章节总结

深度强化学习使算法能够以端到端的方式解决复杂问题。Actor-Critic框架同时学习了价值函数和策略。DDPG结合了DQN和DPG。TRPO通过KL散度限制策略差距，PPO在TRPO基础上通过限制importance ratio的range保证稳定。

模仿学习

行为克隆 必考

行为克隆：在无需奖励函数的情况下，学习从状态/上下文关系到轨迹/动作的直接映射。

有一个以 $\theta$ 参数化和 $s$ 为输入状态的初始策略 $\pi_\theta$，其输出的确定性动作为 $\pi_\theta(s)$：

$$\min_\theta \sum_{(s_i, a_i) \sim \mathcal{D}} \|a_i - \pi_\theta(s_i)\|_2^2$$

专家生成的示范数据集：

$$\mathcal{D} = \{(s_i, a_i)|i = 1, \cdots, N\}$$

模仿学习的整体目标就是增加从当前策略采样得到的 $\{(s, a)\}$ 分布和示范数据中分布的相似度，同时考虑到策略参数上的一些限制。

数据集聚合 重点

数据集聚合（Ross et al., 2011）是一种更先进的基于BC方法的从示范中模仿学习的算法，它是一种无悔迭代算法。

易错：DAgger的缺陷是它需要不断地与专家交互，而这在现实应用中通常是一种苛求。

算法 1: DAgger

1. 初始化 $\mathcal{D} \leftarrow \emptyset$
2. 初始化策略 $\hat{\pi}_1$ 为策略集 $\Pi$ 中任意策略
3. for $i = 1, 2, \cdots, N$ do
4. $\quad \pi_i \leftarrow \beta_i \pi^* + (1 - \beta_i) \hat{\pi}_i$
5. $\quad$ 用 $\pi_i$ 采样几个 $T$ 步的轨迹
6. $\quad$ 得到由 $\pi_i$ 访问的状态和专家给出的动作组成的数据集 $\mathcal{D}_i = \{(s, \pi^*(s))\}$
7. $\quad$ 聚合数据集：$\mathcal{D} \leftarrow \mathcal{D} \cup \mathcal{D}_i$
8. $\quad$ 在 $\mathcal{D}$ 上训练策略 $\hat{\pi}_{i+1}$
9. end for
10. 返回策略 $\hat{\pi}_{N+1}$

逆向强化学习

IRL定义 必考

找到能够使专家策略比任何其他策略更优的奖励函数。IRL可以归结为解决从观察到的最优行为中提取奖励函数，这些最优行为也可以表示为专家策略 $\pi_E$。

IRL方法结构 高频

基于IRL的方法反复地在两个过程中交替：

  1. 使用示范来推断一个隐藏的奖励或代价函数
  2. 使用强化学习基于推断的奖励函数来学习一个模仿策略

强化学习与逆向强化学习的区别 重点

IRL选择奖励函数 $R$ 来最优化策略，并且使得任何脱离于 $\pi_E$ 的单步选择尽可能产生更大损失。其中 $\pi_E$ 是专家（最优的）动作。

最大因果熵逆强化学习：IRL($\pi_E$) 学习一个奖励函数来最大化专家策略和强化学习策略间的奖励值差异，并且由于Q值是对奖励的估计。RL($R$) 是熵正则化正向强化学习，而其奖励函数 $R$ 是 IRL($\pi_E$) 中学到的。熵 $H(\pi(\cdot|s))$ 是给定状态下的策略分布的熵函数。

找到一个代价函数 $c$ 使得专家策略产生较低代价，而其他策略会产生较高的代价。代价函数定义（在强化学习的过程中被最小化）：

  • 代价函数 $c(s, a)$ 常用作当前策略 $\pi$ 的分布和示范数据间相似度的度量
  • 熵 $H(\pi)$ 可以被视作实现最优解的唯一性的正则化项

综合以上式子得到，IRL的目标表示成 max-min 的形式：其中 $\pi_E$ 表示生成专家示范的专家策略，而 $\pi$ 是强化学习过程训练的策略。所学的代价函数将给专家策略分配较高的熵而给其他策略较低的熵。

IRL的局限性 了解

  • IRL计算量比较大，需要反复求解马尔可夫决策过程（MDP）
  • 奖励函数存在非唯一性
  • IRL需要训练出一个良好的代价函数，再训练出一个基于上述代价函数的策略以接近专家策略，结构类似GAN

生成对抗模仿学习

由 Ho et al. (2016) 提出，通过生成对抗网络（Goodfellow et al., 2014）的方式自动学习一个好的奖励函数。相关算法可以被想成是企图引入一个对模仿者的状态-动作占用率的度量，使之与示范者的相关特性类似。

判别器结构 高频

使用一个GAN中的判别器来给出基于示范数据的动作-价值函数估计（0~1）。动作-价值可以通过一种生成式方法来从示范中得到：

  • 迭代次数为 $i$ 时探索的样本集合
  • 来自判别器的输出值
  • 判别器参数
  • Q值是在更新了一步判别器的参数过后再估计的

判别器的损失函数定义为一般形式，其中分别是来自探索和专家示范的样本集合。

GAIL的特点 重点

  • 通过GAIL方法，策略可以通过由示范数据泛化得到的样本进行学习
  • 相比于使用IRL的方法有较低的计算消耗
  • 不需要在训练中跟专家进行交互

GAIL的核心思想 必考

模仿学习的本质就是通过更新策略使其占用度量尽量靠近专家的占用度量，而这正是GAIL的训练目标。由于一旦策略改变，其占用度量就会改变，因此为了训练好最新的判别器，策略需要不断和环境做交互，采样出最新的状态动作对样本。

离线强化学习

动机 了解

在真实环境中从零开始训练一个强化学习智能体往往不可取：

  • 风险较高：例如无人驾驶、智能医疗等
  • 十分昂贵：例如机器人控制、推荐系统等

离线强化学习定义 必考

在一个给定的离线数据集上直接训练出智能体策略，训练过程中，智能体不和环境做交互。离线强化学习有潜力大大扩宽强化学习落地范围。

在线/离线（策略）强化学习的区别 重点

  • 训练的过程中与环境交互：在线策略学习与离线策略学习的智能体可以和环境交互；离线强化学习的智能体不得和环境做交互。
  • 训练数据是否来自别的策略交互：如果是，则是离线强化学习和离线策略学习；如果不是，则是在线策略强化学习。

离线强化学习的优势 高频

  • 基于一个已有经验数据集，预训练一个强化学习策略
  • 基于一个已有经验数据集，经验性地评测一个策略的好坏

离线强化学习的挑战 必考

离线强化学习面临的最重要的挑战是外延误差，也即是处理分布外问题。智能体如果涉足到了从没有见过的数据集的状态动作对，怎么办？外延误差会随时序差分公式传播到非OOD数据上的Q值估计。

外延误差主要是由于数据集分布和当前策略的占用度量不一致导致的。

易错：外延误差会随时序差分(TD)公式传播到非OOD数据上的Q值估计，导致整体估值偏差。

方法分类 了解

离线强化学习分为无模型的方法和基于模型的方法。

逆强化学习与模仿学习

逆强化学习 (IRL)

IRL概述

逆强化学习的目标是找到能够使专家策略比任何其他策略更优的奖励函数。IRL 可以归结为从观察到的最优行为中提取奖励函数的问题，这些最优行为也可以表示为专家策略 $\pi_E$。

强化学习与逆强化学习的区别

正向强化学习 逆强化学习
给定：
• 状态 $s \in S$
• 动作 $a \in A$
• 奖励函数 $r(s, a)$
• 可能给出状态转移 $p(s'|s, a)$		 给定：
• 状态 $s \in S$
• 动作 $a \in A$
• 可能给出状态转移 $p(s'|s, a)$
• 按照专家策略 $\pi^*(a|s)$ 采样得到的轨迹 $\{\tau_i\}$
学习目标：最优策略 $\pi^*(a|s)$ 学习目标：奖励函数 $r_\psi(s, a)$，并使用它学习最优策略 $\pi^*(a|s)$

基于 IRL 的方法反复在两个过程中交替：

  1. 使用示范来推断一个隐藏的奖励或代价函数；
  2. 使用强化学习基于推断的奖励函数来学习一个模仿策略。

IRL 选择奖励函数 $R$ 来最优化策略，并且使得任何脱离于 $\pi_E$ 的单步选择尽可能产生更大损失：

$$R^* = \arg \max_R \sum_{s \in S} (Q^\pi(s, a_E) - \max_{a \in A \setminus a_E} Q^\pi(s, a))$$

其中 $a_E = \pi_E(s)$ 或 $a_E \sim \pi(\cdot|s)$ 是专家（最优的）动作。

最大因果熵逆强化学习

最大因果熵逆强化学习的数学表达：

$$\text{IRL}(\pi_E) = \arg \max_R \mathbb{E}_{\pi_E}[R(s, a)] - \text{RL}(R)$$

$$\text{RL}(R) = \max_\pi H(\pi(\cdot|s)) + \mathbb{E}_\pi[R(s, a)]$$

其中：

  • $\text{IRL}(\pi_E)$ 学习一个奖励函数来最大化专家策略和强化学习策略间的奖励值差异；
  • 由于 $Q$ 值是对奖励的估计，$\text{RL}(R)$ 是熵正则化的正向强化学习，其奖励函数 $R$ 是 $\text{IRL}(\pi_E)$ 中学到的；
  • 熵 $H(\pi(\cdot|s))$ 是给定状态下策略分布的熵函数。

在最大因果熵框架下，也可寻找一个代价函数 $c$，使专家策略产生较低代价而其他策略产生较高的代价。代价函数定义：

$$c(s, a) = -R(s, a)$$

该代价函数在强化学习的过程中被最小化：

$$\text{RL}(c) = \arg \min_\pi -H(\pi) + \mathbb{E}_\pi[c(s, a)]$$

其中：

  • 代价函数 $c(s, a)$ 常用作当前策略 $\pi$ 的分布和示范数据间相似度的度量；
  • 熵 $H(\pi)$ 可以被视为实现最优解的唯一性的正则化项。

综合以上式子，IRL 的目标可以表示成 max-min 的形式：

$$\max_c (\min_\pi -\mathbb{E}_\pi[-\log \pi(a|s)] + \mathbb{E}_\pi[c(s, a)]) - \mathbb{E}_{\pi_E}[c(s, a)]$$

其中 $\pi_E$ 表示生成专家示范的专家策略，而 $\pi$ 是强化学习过程训练的策略。所学的代价函数将给专家策略分配较高的熵，而给其他策略较低的熵。

IRL 的局限性

  1. IRL 训练出一个良好的代价函数，进而训练出基于该代价函数的策略以接近专家策略，过程类似于 GAN；
  2. IRL 的计算量比较大，需要反复求解马尔可夫决策过程（MDP）；
  3. 奖励函数具有非唯一性。

生成对抗模仿学习 (GAIL)

GAIL概述

生成对抗模仿学习 (Generative Adversarial Imitation Learning, GAIL, Ho et al., 2016) 通过生成对抗网络 (Goodfellow et al., 2014) 的方式自动学习一个好的奖励函数。相关算法可以被理解为：引入一个对模仿者的状态-动作占用度量的度量，使之与示范者的相关特性类似。

GAIL的优化目标

GAIL 的目标是拉近两个占用度量的距离：专家占用度量与智能体占用度量。

使用一个 GAN 中的判别器来给出基于示范数据的动作-价值函数估计（0~1）。动作-价值可以通过一种生成式方法来从示范中得到：

$$r(s, a) = -\log D(s, a)$$

$$Q(s, a) = \mathbb{E}_{\mathcal{T}_i}[\log(D_{\omega_{i+1}}(s, a))]$$

其中：

  • $\mathcal{T}_i$ 是迭代次数为 $i$ 时探索的样本集合；
  • $D_{\omega_{i+1}}(s, a)$ 是来自判别器的输出值；
  • 判别器参数 $\omega_{i+1}$ 表示 $Q$ 值是在更新了一步判别器的参数过后再估计的。

判别器的损失函数定义为一般形式：

$$\text{Loss} = \mathbb{E}_{\mathcal{T}_i}[\nabla_\omega \log(D_\omega(s, a))] + \mathbb{E}_{\mathcal{T}_E}[\nabla_\omega \log(1 - D_\omega(s, a))]$$

其中 $\mathcal{T}_i$ 和 $\mathcal{T}_E$ 分别是来自探索和专家示范的样本集合。

GAIL的结构与训练

GAIL 的结构包含以下流程：

  1. 专家采集样本（状态, 动作, 奖励）
  2. 新手（智能体）采集样本（状态, 动作, 奖励）
  3. 专家与新手混合观测数据（状态）
  4. 将状态、动作输入给判别器
  5. 判别器输出奖励
  6. 基于奖励进行策略优化

模仿学习的本质就是通过更新策略使其占用度量尽量靠近专家的占用度量，而这正是 GAIL 的训练目标。由于一旦策略改变，其占用度量就会改变，因此为了训练好最新的判别器，策略需要不断和环境做交互，采样出最新的状态动作对样本。

GAIL的优点

  • 策略可以通过由示范数据泛化得到的样本进行学习；
  • 相比于使用 IRL 的方法有较低的计算消耗；
  • 不需要在训练中与专家进行交互。

离线强化学习

动机

在真实环境中从零开始训练一个强化学习智能体往往不可取，原因包括：

  • 风险较高：例如无人驾驶控制、智能医疗等场景；
  • 十分昂贵：例如机器人控制、推荐系统等场景。

定义

离线强化学习：在给定的离线数据集上直接训练出智能体策略，训练过程中智能体不与环境做交互。离线强化学习有潜力大大扩宽强化学习落地的范围。

流程：离线数据集 $\xrightarrow{\text{训练}}$ 策略 $\pi$ $\xrightarrow{\text{测试}}$ 真实环境

在线/离线强化学习的区别

在线策略学习：

  • 智能体与环境交互产生 rollout data $\{(s_i, a_i, s'_i, r_i)\}$
  • 使用当前策略 $\pi_k$ 采样，更新得到 $\pi_{k+1}$

离线策略学习：

  • 智能体与环境交互产生 rollout data $\{(s_i, a_i, s'_i, r_i)\}$
  • 将数据存入经验回放池 buffer $\mathcal{D}$
  • 使用当前策略 $\pi_k$ 从 buffer 中采样，更新得到 $\pi_{k+1}$

离线强化学习：

  • 使用任意策略 $\pi_\beta$ 一次性收集数据 $\{(s_i, a_i, s'_i, r_i)\}$ 存入 buffer $\mathcal{D}$
  • 训练阶段不与环境交互，直接从 buffer 中学习策略 $\pi$
  • 训练完成后部署到真实环境

区别总结：

  • 训练过程中是否与环境交互：在线策略学习与离线策略学习的智能体可以与环境交互；离线强化学习的智能体不得与环境做交互。
  • 训练数据是否来自其他策略交互：如果是，则是离线强化学习和离线策略学习；如果不是，则是在线策略强化学习。

优势

  • 基于已有经验数据集，预训练一个强化学习策略；
  • 基于已有经验数据集，经验性地评测一个策略的好坏。

与有监督学习的对比：

  • 离线强化学习：训练数据集 $\rightarrow$ 策略 $\pi \rightarrow$ 测试环境
  • 有监督学习：训练数据集 $\rightarrow$ 模型 $f \rightarrow$ 测试数据

挑战：外延误差

离线强化学习面临的最重要挑战是外延误差，即处理分布外（OOD）问题。智能体如果涉足到了从没有见过的数据集的状态动作对，外延误差会随时序差分（TD）公式传播到非 OOD 数据上的 Q 值估计：

$$Q(s, a) \leftarrow (1 - \alpha)Q(s, a) + \alpha(r + \gamma \max_{a'} Q(s', a'))$$

如果 $a'$ 是一个分布外的动作，该动作会被用于 backups，导致 $\rho^\pi \neq \rho^\mu$。

外延误差的来源： 外延误差主要是由于数据集分布和当前策略的占用度量不一致导致的。

  • 数据收集策略 $\mu$ 通过交互采样产生数据集 $\{(s, a, r, s')\}$
  • 离线强化学习学习策略 $\pi$
  • $\mu$ 的占用度量 $\rho^\mu(s, a)$ 与 $\pi$ 的占用度量 $\rho^\pi(s, a)$ 不一致，即 $\rho^\pi \neq \rho^\mu$

方法分类

离线强化学习分为无模型的方法和基于模型的方法：

无模型的方法：

  • 显式限制的方法：
    • BCQ
    • BEAR
    • BRAC
    • CQL
  • 隐式限制的方法：
    • AWR
    • REM
    • BAIL
    • ...

基于模型的方法：

  • 使用学习的模型估计不确定性：
    • MOReL
    • MOPO
    • COMBO
    • ...

离线强化学习：BCQ与CQL算法详解

批量限制Q学习（BCQ） 必考

问题背景

离线强化学习面临 OOD问题，由此产生外延误差。具体而言，某些 state-action 对在离线数据集 $\mathcal{B}$ 中不存在时，该动作的 Q 值就无法得到有效更新。

策略约束思想

核心思路：通过限制策略选择的 state-action 对与离线数据集 $\mathcal{B}$ 中存在的数据保持相似，从而使动作的值估计更加准确。
  • 最小化所选择的动作与数据集中存在的动作之间的距离
  • 使智能体能够转移到与数据集中状态相似的状态
  • 最大化值函数
  • 仅使用在数据集支撑上的目标 Q 值进行时序差分（TD）计算

Q值更新公式如下：

$$Q(s, a) \leftarrow (1 - \alpha)Q(s, a) + \alpha\left(r + \gamma \max_{a' \text{ s.t. } (s', a') \in \mathcal{B}} Q(s', a')\right)$$

原本会被使用的 OOD 数据将不再考虑使用，仅仅考虑在数据集支撑上的 $(s', a')$。

BCQ算法机制

对于给定的状态，BCQ 利用生成模型生成与数据集 $\mathcal{B}$ 相似的动作集合，并通过 Q 网络选择价值最高的动作。对价值估计过程增加了对未来稀有状态的惩罚。

关键组件：

  1. 生成模型：使用变分自动编码器（VAE）生成距离数据集较近的 state-action 对

    $$\pi(s) = \underset{a_i + \xi_\phi(s, a_i, \Phi)}{\operatorname{argmax}} Q_\theta(s, a_i + \xi_\phi(s, a_i, \Phi))$$

    其中 $\{a_i \sim G_\omega(s)\}_{i=1}^n$，$G_\omega$ 为生成模型（如 VAE）。

  2. 扰动模型：为提高生成动作的多样性，引入扰动模型，对动作 $a$ 的扰动范围限制在 $[-\Phi, \Phi]$ 内：

    $$\xi_\phi(s, a_i, \Phi)$$

    其中 $n$ 表示生成模型生成 $n$ 个可行的动作。

模仿学习与强化学习的权衡：

  • $n$ 和 $\Phi$ 越小，越接近模仿学习，但策略性能可能不佳
  • $n$ 和 $\Phi$ 越大，越接近强化学习，但容易出现 OOD 问题
易错：BCQ中 $n$ 和 $\Phi$ 越大，越接近强化学习，但容易出现 OOD 问题；越小则越接近模仿学习。

扰动模型更新

扰动模型更新公式：

$$\phi \leftarrow \underset{\phi}{\operatorname{argmax}} \sum_{(s, a) \in \mathcal{B}} Q_\theta(s, a + \xi_\phi(s, a, \Phi))$$

为了对未来不常见的状态进行惩罚，采用 Clipped Double Q-learning 算法对动作值 Q 进行估计，即训练两个动作值网络，在乐观估计与保守估计之间取得均衡：

$$r + \gamma \max_{a_i} \left[ \lambda \min_{j=1,2} Q_{\theta_j'}(s', a_i) + (1 - \lambda) \max_{j=1,2} Q_{\theta_j'}(s', a_i) \right]$$

BCQ算法伪代码

Algorithm 1: BCQ

Input: 批量数据 $\mathcal{B}$，horizon $T$，目标网络更新率 $\tau$，mini-batch 大小 $N$，最大扰动 $\Phi$，采样动作数 $n$，最小权重 $\lambda$。

初始化 Q 网络 $Q_{\theta_1}, Q_{\theta_2}$，扰动网络 $\xi_\phi$，以及 VAE $G_\omega = \{E_{\omega_1}, D_{\omega_2}\}$，参数为 $\theta_1, \theta_2, \phi, \omega$，以及目标网络 $Q_{\theta_1'}, Q_{\theta_2'}, \xi_{\phi'}$，其中 $\theta_1' \leftarrow \theta_1, \theta_2' \leftarrow \theta_2, \phi' \leftarrow \phi$。

for t = 1 to T do
    # 1. VAE 训练（模仿学习）
    Sample mini-batch of N transitions (s, a, r, s') from B
    mu, sigma = E_{w1}(s, a), a_tilde = D_{w2}(s, z), z ~ N(mu, sigma)
    w <- argmin_w sum (a - a_tilde)^2 + D_KL(N(mu, sigma) || N(0, 1))
    
    # 2. 采样并扰动动作
    Sample n actions: {a_i ~ G_w(s')}_{i=1}^n
    Perturb each action: {a_i = a_i + xi_phi(s', a_i, Phi)}_{i=1}^n
    
    # 3. 计算目标值（双动作值网络，乐观与保守之间均衡）
    Set value target y = r + gamma * max_i [lambda * min_{j=1,2} Q_{theta_j'}(s', a_i) 
                        + (1 - lambda) * max_{j=1,2} Q_{theta_j'}(s', a_i)]
    
    # 4. 更新 Q 网络
    theta <- argmin_theta sum (y - Q_theta(s, a))^2
    
    # 5. 更新扰动网络
    phi <- argmax_phi sum Q_{theta1}(s, a + xi_phi(s, a, Phi)), a ~ G_w(s)
    
    # 6. 更新目标网络
    theta_i' <- tau * theta + (1 - tau) * theta_i'
    phi' <- tau * phi + (1 - tau) * phi'
end for

保守Q学习（CQL） 重点

问题背景

离线强化学习中解决外延误差问题的传统思路是：将待优化策略的动作选择限制在离线数据集的动作分布上，从而避免分布外的动作出现 Q 值的过估计问题，进而减少未知动作在策略训练学习过程中的影响。这种方法被称为

策略提升与保守策略评估 必考

策略提升

策略提升的目标是最大化期望价值：$$\hat{\pi}^{k+1} \leftarrow \underset{\pi}{\operatorname{argmax}} \mathbb{E}_{s \sim \mathcal{D}, a \sim \pi^k(a|s)} \left[ \hat{Q}^{k+1}(s, a) \right]$$

保守策略评估 重点

保守策略评估通过引入惩罚项来避免高估分布外动作的Q值：$$\hat{Q}^{k+1} \leftarrow \underset{Q}{\operatorname{argmin}} \alpha \mathbb{E}_{s \sim \mathcal{D}, a \sim \mu(a|s)} [Q(s, a)] + \frac{1}{2} \mathbb{E}_{s, a \sim \mathcal{D}} \left[ \left( Q(s, a) - \hat{\mathcal{B}}^{\pi} \hat{Q}^k(s, a) \right)^2 \right]$$

当 $\alpha$ 足够大时，$\hat{Q}^{\pi}(s, a) \leq Q^{\pi}(s, a)$，即得到 Q 值的下界估计。

改进的保守策略评估 高频

考虑到数据集 $\mathcal{D}$ 中的 Q 值不建议打压，得到改进的保守策略评估公式。通过引入最大最小博弈，并加入KL散度正则化项 $\mathcal{R}(\mu)$，令 $\rho = \text{Unif}(a)$，就得到 CQL($\mathcal{H}$) 算法。

CQL($\mathcal{H}$) 的目标函数为：$$\min_{Q} \alpha \mathbb{E}_{s \sim \mathcal{D}} \left[ \log \sum_{a} \exp(Q(s, a)) - \mathbb{E}_{a \sim \hat{\pi}_{\beta}(a|s)} [Q(s, a)] \right] + \frac{1}{2} \mathbb{E}_{s, a, s' \sim \mathcal{D}} \left[ \left( Q - \hat{\mathcal{B}}^{\pi_k} \hat{Q}^k \right)^2 \right]$$

CQL算法伪代码 了解

1. 初始化 Q 函数 $Q_\theta$，可选地初始化策略 $\pi_\phi$。

2. 循环执行 $N$ 步：

a. 使用 $G_Q$ 个梯度步长训练 Q 函数（Q-learning 使用 $\mathcal{B}^*$，actor-critic 使用 $\mathcal{B}^{\pi_\phi}$）。

b. （仅 actor-critic）使用 $G_\pi$ 个梯度步长，以 SAC 风格熵正则化改进策略 $\pi_\phi$。

实验效果：在多个 Gym 环境和不同的数据集采样设置下，CQL 几乎都能取得最好的策略性能。

应用案例 Case 1: 光传送强化学习算路 高频

问题背景与动机

光传送算路时，路径需要考虑多维权重。原有方法是通过专家指定权重参数，强化学习方案则根据历史算路结果学习该权重系数。

方法优劣
专家制定系数系数大小关系正确，但具体值不准确；大小关系可能存在冲突；不能根据实际下发算路结果正确修正系数
根据历史路径学习学习专家制定的系数大小关系，且保证大小关系不冲突；可依据实际下发的算路结果（修正后）学习

问题分析

该问题提供了有监督数据，借鉴逆强化学习的思路推导奖励函数。策略部分直接采用规划的方式得出确定性最优解，不涉及策略的学习，不对价值函数或策略建模。奖励函数为可解释性设计为线性函数，训练过程可采用梯度下降求解。

问题建模

State（状态）：当前所在节点的信息

Action（动作）：有向图的节点转移

Policy（策略）：Dijkstra 算法，输入状态，输出动作序列（直接输出 Trajectory）

Reward（奖励）：设计为线性函数 $R_E = A \cdot W_E$。求解时利用一条 trajectory 的奖励 R 更新函数

目标函数：$\arg\min_A \sum_{i=1}^{n} \left( Reward_{path_i} - Reward_{path_i}^* \right)^2$

求解过程

输入：拓扑图、历史计算路径、学习率 $\alpha$、训练轮数 $m$

Step1：初始化奖励函数的系数 A，打乱历史路径切分为 batch

Step2：循环执行：随机获取一个 batch 历史路径，记录源宿节点；调用策略模型获得算路结果；比较历史路径和策略模型获得的奖励，根据奖励差异梯度更新 A：$A' = A + \alpha\nabla R(A)$

停止：直到训练 m 轮

业务示例：OTN业务权重 $(w_1, ..., w_9)$

1. 时延（数据库 telink）

2. 跳数（每次跳数=1）

3. Distance（数据库获取）

4. 带宽占用率（1 - max_res/max）

5. 角色是否为平衡边（用角色+边界点判断：角色缺失时引入边界点）

6-9. 管道破坏情况（用 max 和 max_res 计算）

奖励公式：$$Reward_{traj1} = -\sum_{i=1}^{m_1} A W_i$$

关键技术1：CH算法加速 重点

CH（Contraction Hierarchies）算法是最短路径问题中的一种搜索加速技术，通过在预处理阶段创建"捷径"（Short-Cut），在查询时利用这些捷径跳过大量"不重要"的顶点，大幅加速查询。

算法步骤：

Step1（确定节点收缩重要性）：让重要点的层次更高、不重要点的层次更低，先收缩不重要的点。强化学习方案根据历史查询结果学习节点重要性。

Step2（层次收缩）：从不重要的点开始收缩，收缩某点即删除该点后在它的邻居间插入捷径。

Step3（查询）：从重要性由小到大（正向）和由大到小（反向）的顺序，对收缩后的拓扑进行双向 Dijkstra 搜索。

启发式节点重要性指标包括：Edge Difference（边的差分）、Uniformity（均匀度）、Cost of contraction（收缩成本）。

关键技术2：强化学习优化CH算法 重点

问题建模：

State：层次收缩后的节点 embedding（节点度、边差分、均匀度、收缩成本等）

Action：节点重要性调整，离散动作（如 +1, -1, +2, -2 等）

Reward：与层次收缩前后最短路计算次数的差正相关：$r \propto (CountSearch_{before} - CountSearch_{after})$

环境 step：$step(s, a) \rightarrow s'$，根据 $a$ 调整节点重要性后执行 CH 算法 Step2，重新计算采样拓扑中的节点 embedding。

求解过程使用 PPO2 算法对参数更新幅度进行约束，建模为单步马尔科夫过程。网络规模增长 10 倍或以上时，改造后的 CH 算法较原光传送算路算法效率提升 80%。

应用案例 Case 2: WLAN AI漫游 高频

背景

WLAN 802.11 标准规定漫游由终端自主决策，终端厂商能力及使用习惯的差异导致漫游性能和用户体验差异显著。引入 802.11v 协议后，网络具备了引导终端漫游的能力，但由于终端行为的差异性，无差别引导策略效果较差。

漫游过程

AS-IS（终端自主漫游方案）：漫游不及时，漫游时信号差。终端在信号强度降低到阈值门限时才开始扫描并选择新AP。

TO-BE（网络主动引导漫游方案）：网络主动检测终端运动状态，触发邻居扫描并指定漫游目标 AP，及时触发终端漫游，提升信号体验。

问题分析与建模

由于新上线终端及终端厂商 OS 版本的变化是未知的，需要在环境交互中获取终端的行为样本，优选强化学习方案。

状态空间 S：网络环境中终端的四维信息集合 {终端识别信息、终端运动状态、关联 AP、邻居 AP、11v 协议参数组合}

动作空间 A：是否引导到目标 AP

及时奖励 R：引导成功或者失败

Q 值：动作价值函数，通过神经网络来近似拟合更新 Q 值

问题求解

Step 1：初始化 Q 值 = 1。

Step 2：循环执行：按照状态约束 + Epsilon-greedy 策略决定是否向终端发送 11V 报文，存储经验 `<S, A, R, S′>`；从经验池取出 Batch 数据，计算 Target Q 值和预测 Q 值，使用 SGD 更新 Q 神经网络参数 θ；定期更新 Target Q 神经网络参数 θ′。

应用案例 Case 3: 4T波束优化 高频

背景与挑战

多 T 小区通过调整天线相位，能产生不同形状的波束，达到不同的覆盖效果。现网中小区间用户分布存在差异，相同相位值无法差异化获取最大小区容量。利用强化学习可以自适应调整天线相位值，独立寻优出最优的相位值。

系统架构与波束赋形

信号处理流程：BBU (Original Signal) → Phase Adjust → RRU → PA → Antenna。通过调整相位参数产生不同的波束赋形效果。

问题建模

4T 波束优化中调整天线权值不会改变小区的状态信息，状态只有一个，不存在状态迁移，可以用多臂老虎机问题模型求解。

Action：调整的天线相位值，如 `(0°, 45°, 90°, 45°)`

Reward：调整后获得的小区容量 R

易错：4T波束优化问题中状态不发生迁移，因此不能用马尔科夫决策过程（MDP）建模，而应使用多臂老虎机模型。

求解过程

Step 1：初始尝试每个相位值，获得初始值 $Q_0(a)$

Step 2：循环执行：获取最优相位值 $A_t = \arg \max_{a \in A} Q_t(a)$；依据策略函数选择出执行的相位值 $a$（Epsilon-greedy策略）；获得反馈 $R_{t+1}$，刷新 $a$ 的值函数 $Q_{t+1}(a) = Q_t(a) + \alpha [R_{t+1} - Q_t(a)]$。

应用案例 Case 4: 基于深度强化学习的复杂移动网络参数优化 重点

问题背景与技术挑战

需根据用户需求分布、无线覆盖环境特征差异化调优网络参数，实现无线网络资源与业务流量需求的深度协同。

调整参数：AAU 机械倾角/方向角、AAU 数字倾角/方向角、AAU 波束 Pattern 权值、发射功率。

优化目标：覆盖质量（RSRP）、干扰（SINR）、用户体验（谱效、速率等）。

技术挑战：网络环境部分可观察，基于地理化位置信息的系统建模难度大；网络拓扑场景多样、多小区协同耦合、优化参数维度高、多目标均衡难度大。

基于DRL的大规模复杂网络参数优化

核心思路：基于强化学习架构，通过优化求解器与网络仿真器多次交互，以 Model-Free 方式学习并生成最优网络调整策略。网络结构采用 Policy Network (CNN) 处理 Image-like 44D State Tensor，输出离散动作。

问题建模

离线优化模式可建模为 Contextual-Bandit RL 问题，在线调优模式可建模为多阶段强化学习架构。

State：无线网络“环境”张量（用户上报主服 & 邻区 RSRP/SINR、工参信息）

Action：基于当前网络配置，各维度参数相对调整量

Reward：多个网络性能指标与对应目标值的差值，差值越小，reward 越大。

求解过程

Step 1：初始化网络、epsilon-greedy 初始随机数。

Step 2：循环执行：基于网络仿真器生成 State 张量；基于 State，依一定概率选择专家经验动作、随机动作和网络生成动作；动作执行，生成对应 reward 和状态转移态；样本池足够情况下，以 `<S, A, R, S'>` 刷新网络参数 θ。

核心逻辑：专家经验 → State → 深度强化学习网络 → Action；价值评估：$Q(s,a;\theta) \approx Q^*(s,a)$；Loss ~ F (Gain)。
