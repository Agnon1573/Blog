AI算法目标定义 高频 如何将一个需求的描述转化为AI算法的定义是至关重要的一步。需求描述的是功能、性能、输入、输出等信息。 Why：是否需要用AI解决？评估传统算法与AI算法的代价、效果等。 What：需要做到什么样的程度？算法目标的定义包括：评价方式、准确率目标、性能目标、算力目标等。 How：如何达成，通过什么样的模型和算法解决？ 易错：数据数量不属于算法目标，算法目标包括评价方式、准确率目标、性能目标等。 计算加速与通信优化算法 重点 稀疏化与低秩分解 稀疏化（深度扩增）：训练结构"类似"的小模型，再通过技术手段扩增到原模型。根据扩增方向不同，可具体分为深度扩增、广度扩增以及梯度冻结。 低秩分解：维度较大的 dense 层可以用维度较小的两个 dense 层的乘积近似表示。 低精度训练 计算时采用 fp16、int8 等低精度方案。fp16 计算乘法的理论速度是 fp32 的 4 倍，NPU 的 AI Core 硬件亲和 fp16。 低精度训练的问题：由于 fp16 表示范围不及 fp32，因此难以表达很小的 gradient，引起 underflow。 解决办法：loss scaling，NVIDIA 提出了 Automatic Mixed Precision (AMP)，自动判断应该把梯度扩大多少倍以避免 underflow。 易错：PyTorch 1.6+ 已通过 torch.amp 支持 fp16 低精度训练，且支持 Automatic Mixed Precision (AMP)。昇腾Ascend310P NPU的AI Core支持FP16和INT8两种数值类型。 通信优化算法 计算和通信重叠：反向传播完第 i 层，即可 all-reduce 其梯度，同时计算 i-1 层的梯度。通过将计算和通信重叠，能显著减少训练时间，尤其是在大模型训练的情况下。 带宽更小情况的进一步优化： 1. LocalSGD：每个 NPU 独自更新模型 K iterations，随后所有模型同步。减少了 K-1 次通信。 2. 梯度压缩：通过压缩梯度，减少通信传输的 bits。常见的压缩方案包括：Sign、Sign + Norm、Top K、Random K、Random Block、Low-rank 等。 易错：DeepSpeed 是基于 PyTorch 的分布式训练框架，而非 DBA算法与DTW对齐 必考

动态时间规整 (Dynamic Time Warping, DTW) 算法主要用于解决序列长短不一或时间步不对齐时难以有效计算相似度的问题。该算法对时间序列进行线性放缩，达到更好的对齐效果，允许一对多mapping，适用于复杂时间序列。

DTW算法步骤如下：

1. 计算两个序列各个点之间的距离矩阵。

2. 寻找一条从矩阵左上角到右下角的路径，使得路径上的元素和最小。

矩阵从左上角到右下角的路径长度有以下性质：当前路径长度 = 前一步的路径长度 + 当前元素的大小；路径上的某个元素 $(i, j)$，它的前一个元素只可能为左边的相邻元素 $(i, j-1)$、上面的相邻元素 $(i-1, j)$ 或左上方的相邻元素 $(i-1, j-1)$。

DTW的核心是通过动态规划寻找一条累积距离最小的路径，从而实现对齐并计算相似度。
易错：计算DTW距离时，需构建距离矩阵并严格按照左、上、左上三个方向寻找最短路径，不能随意跳跃。

Embedding function 和 Recovery function： 采用Embedding方法降低特征维度，简化GAN网络复杂度，用更低维度的 $h_s$ 表示静态特征 $s$，$h_t$ 表示时态特征 $x_t$。时态特征考虑静态特征 $h_s$ 和上一时刻时态特征 $h_{t-1}$。通过Recovery函数复原出原来的特征。

Sequence Generator 和 Discriminator： 生成器通过随机向量生成特征，判别器识别真实数据与生成数据，对于时态特征，判别器使用双向RNN判断两个方向的输出结果。

Time GAN通过Embedding和Recovery降低维度，结合生成器和判别器进行时序数据生成，重点关注Reconstruction Loss、Unsupervised Loss和Supervised Loss的含义。

AI分布式训练加速算法

并行方式与内存优化 必考

分布式训练的优势包括加速训练、克服单卡内存不足、适配大batch优化器等，但不能提高训练结果的精度。

主要的并行模式包括：

- 数据并行：每个NPU上拷贝一份模型，把数据分散到不同NPU上。

- 模型并行：几个NPU共同维护一份模型，包括流水线并行和Tensor并行。流水线并行通过人为引入microbatch来增加资源利用率，可以提高模型并行的效率。

- 优化器并行：将优化器状态分布到不同NPU上以通过通信换取内存。

- 混合和自动并行：混合多种并行策略，或通过构建通信、计算模型自动进行切分。

重计算 是一种内存优化算法，通过丢弃部分activation的方式节约显存，被丢弃的activation会在反向传播时重新计算，即通过计算换内存。大约保留 $O(\sqrt{N})$ 的activation能较好地平衡内存与计算时间。

流水线并行可以提高模型并行的效率；数据并行和模型并行可以同时使用。盘古大模型训练中采用了数据并行、重计算、流水线并行和优化器并行。
易错：DeepSpeed是基于PyTorch的分布式训练框架，不是TensorFlow。

在通信方式中，属于多对多通信的有AllReduce、AllGather、AlltoAll。Broadcast属于一对多通信。

AI模型压缩算法

量化、剪枝与蒸馏 必考

量化 分为量化感知训练（QAT）和训练后量化（PTQ）。

量化感知训练 (QAT)：通过伪量化与微调训练更新模型权重参数，使模型对量化更为友好。通常权重采用per-channel量化，激活采用per-tensor量化。前向计算涉及round取整与clip截断，反向计算引入梯度估计（如STE方法）。

训练后量化 (PTQ)：针对推理部署场景，仅依赖少量无标注数据集或无数据集的校准。分为静态量化（离线计算好量化参数）和动态量化（在线执行）。静态PTQ分为离线校准和在线量化推理两个阶段。

剪枝：通过滤波器剪枝得到的模型在常规CPU中推理时，既能压缩模型大小又能缩短模型推理时间。细粒度剪枝、向量剪枝、组合剪枝无法达到此效果。

蒸馏：主要包括多教师蒸馏、助教蒸馏、自蒸馏和Data-free蒸馏。

NAS中的权值共享：主要目的是提升搜索效率，避免训练大量模型。

量化分辨率影响量化精度，对于数值分布集中的区域，需要设置较大的量化分辨率。混合比特量化需要为不同group设置不同的量化比特数。
易错：QAT在训练微调期间，模型权重参数通常是可训练的，并非冻结不予以更新。

随机梯度优化算法

凸优化与下降法 重点

凸函数：$f(x) = x^2$、$f(x) = e^x$、$f(x) = |x|$ 是凸函数，而 $f(x) = x^3$ 不是凸函数。

下降法：梯度下降和牛顿法在每次迭代中会让函数值严格减少一定数值。在梯度不为0时，每次迭代严格减少函数的值的方法是梯度下降。

在大规模机器学习中的凸优化问题中，SAG、SVRG、SAGA可以有线性收敛率，而Mini-batch SGD不能有线性收敛率。

适应性随机梯度方法：会让每个参数拥有自己的学习率，如Adam、RMSProp、Adagrad。SGD不属于适应性方法。

深度神经网络中加速训练改善泛化的经典trick包括：权重初始化、数据增强、学习率调节方法、学习率Warmup。

随机平均梯度（SAG）迭代过程

在内存中保留所有样本函数最近一次计算的梯度值。有放回地随机选择一个样本索引，迭代更新公式为维护一个包含n个历史梯度的表，每次迭代只更新被选中样本对应的梯度，其余保持不变，然后取平均值作为梯度估计。

随机梯度方法线性收敛原理——方差减少

核心原理：通过引入另一个已知期望的随机变量Y的样本，来减少原随机变量X的样本方差。定义新的随机变量Z = α(X - Y) + EY。当α=1时为无偏估计；当α<1时存在潜在偏差，但方差会减小。

超参数是在模型开始学习之前设置的参数，而不是通过训练得到的参数数据。它们控制模型的学习过程，而非从数据中学习。在训练过程中，参数会更新，而超参数往往是恒定的。

通过计算换取内存

题目17：以下方法中，通过计算换取内存的是（）。A. CPU offloading B. 重计算 C. 梯度压缩 D. 低秩分解。正确答案：B。

内存优化算法

为什么要优化内存：减少内存占用可以用来增大batch size；使用模型并行时，可以在相同卡数的情况下支撑更大的模型。

  • 重计算：后向传播时需要保留的activation会占用内存。重计算通过丢弃部分activation的方式节约显存，被丢弃的activation会在反向传播时重新计算，即通过计算换内存。
  • CPU offloading/paging：将额外的activation暂时存于CPU，需要时再从CPU取回，通过NPU-CPU通信换取内存。
  • ZeRO-offload：将优化器状态由NPU上传至CPU的一种节约内存的方法。
  • 模型优化：Inplace GELU和inplace LayerNorm可以减少activation所需内存。

计算加速与通信优化小结

  • 计算加速：低精度训练、稀疏化训练、低秩训练。
  • 内存优化：重计算、CPU offloading、ZeRO offloading。
  • 通信优化及分布式优化器：基础通信优化（通信与计算overlap）、梯度压缩、Error feedback分布式优化器。

数学优化简介

优化是从变量的约束条件所限定的集合中找到使某个目标函数最小/最大的解的过程。

三部曲：完整的优化过程包括根据实际问题建模得到一个数学优化问题，明确该优化问题解的最优性条件、存在性、唯一性等理论关切，和设计优化算法求解该优化问题等三个步骤。

超参数优化 重点

随机搜索

随机搜索定义：在超参数搜索空间中随机搜索，即从指定的分布中采样固定数量的超参数组合，并进行测试，选择最优超参数。如果随机样本集足够大，也可以找到全局的最大或最小值，或它们的近似值。

优点：简单，易于实现，速度较快，能并行。缺点：优化结果无法保证，无法利用之前的执行结果。

贝叶斯优化

贝叶斯优化（BO算法）是一种黑盒优化算法，用于求解表达式未知的函数的极值问题。由于目标函数无法/不太好优化，那我们找一个代理函数来优化，为了找到当前目标函数的合适代理函数，赋予了代理函数概率分布，然后根据当前已有的先验知识，使用采集函数来评估如何选择新的采样点，获得新的采样点之后更新先验知识，然后继续迭代找到最合适的代理函数，最终求得全局最优解。

算法流程：

1. Augment sample：Sample -> Aug0, Aug1, Aug2 ... AugN-1, AugN

2. Evaluate and calculate loss：Augmented samples -> Neural Network -> o0, o1, o2 ... oN-1, oN -> l0, l1, l2 ... lN-1, lN

3. Rank and trim：l1, lN, l0 ... l2, lN-1 -> AugN, Aug0 ... Aug2

标注不完备场景下的建模问题 - 主动学习 高频

整体过程

1. 从未标注样本中选择部分样本，由专家进行标注。

2. 专家完成标注，生成已标注样本。

3. 基于已标注样本训练算法模型。

4. 算法模型对未标注数据进行预测，并且按照某种原则选择未标注样本给专家进行标注。

5. 专家完成标注，更新已标注样本。

6. 重新更新模型，重复上述过程。

易错：主动学习不是随机选择未标注样本给专家进行标注，而是按照某种原则（如不确定性等）选择高价值样本。

选择待标注高价值样本的策略

1. Margin sampling（边缘采样）

2. Least confident（最小置信度）

3. Entropy（熵）

实际业务问题中应用主动学习的限制

1. 现实的业务数据集可能有大量的噪声，并且领域专家也难以标注，因此主动学习的实际应用有很大的限制。

2. 现在深度学习需要的样本数量庞大，并且训练的轮次很多，因此主动学习的迭代过程代价随之增加。

3. 传统的主动学习都是 task specific，而缺乏更加普适性的方法，有大量新的研究在寻求更加通用的 loss 评价等方法上进行努力。

4. 主动学习将数据工程和模型训练过程变成一种迭代式的方法，在工业界应用存在一定的障碍。

计算加速与通信优化算法 重点

稀疏化与低秩分解

稀疏化（深度扩增）：训练结构"类似"的小模型，再通过技术手段扩增到原模型。根据扩增方向不同，可具体分为深度扩增、广度扩增以及梯度冻结。

低秩分解：维度较大的 dense 层可以用维度较小的两个 dense 层的乘积近似表示。

低精度训练

计算时采用 fp16、int8 等低精度方案。fp16 计算乘法的理论速度是 fp32 的 4 倍，NPU 的 AI Core 硬件亲和 fp16。

低精度训练的问题：由于 fp16 表示范围不及 fp32，因此难以表达很小的 gradient，引起 underflow。

解决办法：loss scaling，NVIDIA 提出了 Automatic Mixed Precision (AMP)，自动判断应该把梯度扩大多少倍以避免 underflow。

易错：PyTorch 1.6+ 已通过 torch.amp 支持 fp16 低精度训练，且支持 Automatic Mixed Precision (AMP)。昇腾Ascend310P NPU的AI Core支持FP16和INT8两种数值类型。

通信优化算法

计算和通信重叠：反向传播完第 i 层，即可 all-reduce 其梯度，同时计算 i-1 层的梯度。通过将计算和通信重叠，能显著减少训练时间，尤其是在大模型训练的情况下。

带宽更小情况的进一步优化：

1. LocalSGD：每个 NPU 独自更新模型 K iterations，随后所有模型同步。减少了 K-1 次通信。

2. 梯度压缩：通过压缩梯度，减少通信传输的 bits。常见的压缩方案包括：Sign、Sign + Norm、Top K、Random K、Random Block、Low-rank 等。

易错：DeepSpeed 是基于 PyTorch 的分布式训练框架，而非 TensorFlow。
通信优化的收益最大的场景：大模型训练，卡间带宽有限。

算法差异与优化基础

PSO与GA算法差异 重点

根据个体的适配信息进行搜索，因此不受函数约束条件的限制，如连续性、可导性等；但对高维复杂问题，往往会遇到早熟收敛和收敛性能差的缺点，都无法保证收敛到最优点。

PSO与GA的主要差异如下：

- PSO有记忆，所有粒子都保存好的解的知识，而GA无记忆性，以前的知识随着种群的改变而改变。

- PSO中的粒子仅仅通过当前搜索到最优点进行共享信息，所以很大程度上这是一种单共享项信息机制，而GA中，染色体之间相互共享信息，使得整个种群都向最优区域移动。

- GA的编码技术和遗传操作比较简单，而PSO相对于GA没有交叉和变异操作，粒子只是通过内部速度进行更新，因此原理更简单、参数更少、实现更容易。

PSO有记忆且单共享项信息机制，无交叉变异；GA无记忆，染色体间共享信息，有交叉变异。

模型剪枝评估准则

针对场景的剪枝评估准则 重点

某神经网络模型能够适用于多个场景，可以针对每个场景对模型单独进行剪枝的评估准则包括：

1. 利用子空间聚类的思想对滤波器产生的特征层进行聚类来消除滤波器的冗余。

2. 将滤波器经过激活层后输出的特征层当中数值为0所占百分比作为该滤波器重要性的评估依据，值为0所占百分比越多则该滤波器重要性越低。

3. 对于每一层滤波器输出的特征层，先将特征层进行池化输出为向量，而后对各个特征向量进行PCA分析，去掉信息含量少的特征层对应的滤波器来达到剪枝目的。

易错：只单独考虑深度网络某一层或相邻两层滤波器的重要性并裁剪掉看似不重要的滤波器，可能会对后续层甚至更深层的响应输出产生影响，而且误差会逐层累积。

参数驱动与数据驱动的评估准则 了解

参数驱动的评估准则：谱聚类：利用谱聚类的思想，先对各层滤波器进行谱聚类，聚类之后根据滤波器的贡献进行排序，贡献小的滤波器会被剪枝。

数据驱动的评估准则：特征层面：

- APoZ：将滤波器经过激活层后输出的特征层当中数值为0所占百分比作为该滤波器重要性的评估依据。

- HRank：单个滤波器生成的特征层的平均秩越低，对精度的贡献越小，修剪掉这些生成低秩特征层的滤波器。

- 特征层聚类：利用子空间聚类的思想对滤波器产生的特征层进行聚类来消除滤波器的冗余。

- PFA：将主成分分析 (PCA) 用于特征分析中，去掉信息含量少的特征层对应的滤波器。

分布式训练基础

同步训练和异步训练 必考

假设其余条件一致，相同epochs，异步训练花费时间少，但精度可能会低于同步训练。原因是异步训练的梯度存在延时问题，即更新模型时用到的是老旧的梯度，而非当前模型的梯度。

解决异步训练中的梯度延时问题的方法：从算法层面对延时梯度进行处理（如delay compensation）；采用半异步训练，通过在异步训练中适当的同步以减小延时梯度的影响。

流水线并行（模型并行） 重点

流水线并行是纵向模型并行的提升版，在解决大模型训练的内存问题的同时，提高了NPU的资源利用率，加速了训练。大部分流水线并行都是通过把mini-batch细分为micro-batches人为制造pipeline的可能性。

以GPipe为例，假设共M个micro-batch，N个设备，并假设每个NPU前向传播需要1单位时间，GPipe前向传播时间总体为N+M-1，其中每个NPU工作时间为M，因此资源利用率为M/(N+M-1)。反向传播效率计算方法类似，总体效率仍为M/(N+M-1)。

粒子群算法步骤：不包含将选择、交叉和突变的遗传因子应用到种群中（这是GA的步骤）。

半监督和自监督：流形假设是半监督学习的典型假设。自监督学习通过设计辅助任务来挖掘数据自身的表征特性作为监督信息。

相关性蒸馏：更加关注不同数据样本之间的关系。

多选题考点 高频

基于搜索的剪枝算法：Network Adjustment、ABCPruner、MetaPruning、DMCP。ABCPruner使用人工蜂群算法寻找每层通道数量；MetaPruning使用元学习搜索通道数量；DMCP将剪枝建模成可微分的马尔可夫过程。

解决异步训练中梯度延时：delay compensation等相关算法、半异步训练。

多对多通信：AlltoAll、AllReduce、AllGather。Broadcast是一对多。

多保真优化算法：Hyperband、BOHB、Halving。用于加快评估速度，思想是只使用一部分资源来训练模型，综合运用高保真和低保真。

CPU offloading：用于缓解大模型训练NPU显存不足的问题，GPU V100训练ResNet18一般无需CPU Offloading。不正确的是将优化器状态放到CPU上（实际是放CPU）、通过计算换通信（实际是通信换内存）。

深度生成模型与TimeGAN 重点

深度生成模型（Deep Generative Models, DGM）能生成高维数据，在图像领域数据增强有广泛应用，典型代表为生成对抗网络（Generative Adversarial Networks, GAN）。在时间序列数据领域，DGM同样可以合成时间序列样本，如循环GAN和循环条件GAN，产生真实的实值多维时间序列数据。

这些方法考虑到了时序数据的每个时间步的相互影响（时态特征），但没有考虑静态特征针对时序数据，因此提出了TimeGAN。TimeGAN提出时序数据应该有两种特征：

  • 静态特征S：不会因为时间而改变的特征，例如性别。
  • 时态特征X：随时间而改变的特征，例如生命特征（包括脉搏、呼吸、体温、血压等数据）。

随后让模型学习真实训练数据的分布，随机输入一个向量，经过模型输出一个数据，这个数据的分布 $\hat{p}\left(S, X_{1: T}\right)$ 与真实数据的分布 $p\left(S, X_{1: T}\right)$ 相似，这样就可以让生成数据与真实数据非常相像。

内存优化概述 高频

在大模型训练中，内存优化是关键技术，主要包括以下几种方式：

  • 重计算：重新计算部分 activation 以节约内存。
  • CPU offloading：将 activation 从 NPU 移动到 CPU 以节约内存。
  • ZeRO offloading：将优化器状态从 NPU 移动到 CPU 以节约内存。
CPU offloading 是减少 activation（激活值）所需显存的另一种方式。将额外的 activation 暂时存放于 CPU，需要时再从 CPU 取回。通过 NPU-CPU 通信换取内存空间，即以通信换内存。CPU-offloading 可以与重计算技术共同使用，进一步提升显存利用率。
易错：CPU Offloading 是“以通信换内存”，而不是“以计算换通信”。将优化器状态放到CPU上属于ZeRO offloading，而不是CPU offloading。

模型量化算法：训练后量化（PTQ） 重点

Data-free 训练后量化

不依赖真实数据，对模型进行量化参数的离线校准，包括：

  • 基于假设分布与统计：为模型输入随机数据，根据 Activation 的假设分布与统计，计算量化参数。假设激活分布服从正态分布（如 BN 层输出），采用 3σ 统计确定量化的饱和截断区间。
  • 基于伪样本生成：借助预训练模型提供的内蕴信息与预测信息，构建并训练样本生成模型（如基于 GAN），以生成用于离线校准的伪样本。伪样本合成质量影响量化效果，并存在一定的时间成本；模型量化参数的微调可与生成模型的训练一同进行。

Label-free 训练后量化

依赖少量无标注数据，对模型进行量化参数的离线校准。校准数据集可以选取一部分训练数据，或者其他与场景域一致或相关的数据。常见算法包括 Absmax 算法、Min-Max EMA 算法、KL 算法等。

时序数据自动增强 必考

问题背景

自动数据增强按数据集探索最优策略，所有样本采用相同增强策略，忽略了样本间的差异性。

α剪枝自动增强

α剪枝自动增强：时序数据增强的千人千面，样本级增强，为每个时序样本选择最合适的增强策略。

流程步骤：

  1. Augment sample（增强样本）
  2. Evaluate and calculate loss（评估并计算 loss）
  3. Rank and trim（排序和修剪，筛选 Top α loss 样本和 Bottom α loss 样本）
  4. 增强样本汇总
易错：对 MLP 模型而言，loss 较小样本对模型更新信息小，loss 较大样本对模型更新贡献度大，然而这样会导致更新后的模型在容易样本上性能受损。

时序数据增强方法概览

高阶时序数据增强：

  • 基于统计生成模型：核心思想是用统计学方法模拟时序数据（基于时序数据的自相关性，给初始点一个扰动，后续数据点随之扰动）。方法包括 MAR（mixture of autoregressive models）。
  • 基于分解的时序数据增强：核心思想是把时序数据分解为某些成分，再对每个成分设计增强方法。方法包括 STL 算法（分解为 trend/seasonality/residual，调整基础、趋势和季节性的权重，重构确定性部分，对 residual 进行随机性调整）。
  • 基于学习方法的时序数据增强：核心思想是从数据中学得数据增强方式。方法包括 GAN / Automated Data Augmentation / Embedding Space（在 encoding space 上增加扰动）。

强化学习基础 高频

基础的强化学习本质上是一个马尔可夫决策过程（MDP），再叠加机器学习成为一个具备学习能力的 MDP 过程。

强化学习的核心要素： Reinforcement（Re：重复，Inforce：强化，增强），模拟的是人和动物的学习过程，类似仿生学的过程。

强化学习本质：1. 强化学习马尔科夫决策过程；2. 迭代式过程；3. 解决探索-利用之间的矛盾。

强化学习的适用范围： 智能体、状态、奖赏、动作、环境。理论上只要能够形成反馈的环境都适合使用强化学习方法。

不适用的场景：

  1. 智能体本身一般是模型本身，所以是否成立的关键是环境，环境无法给出反馈或者无法及时给出反馈，则很难使用强化学习方法。
  2. 反馈的状态错误或者不准确。
  3. 环境快速变化，需要能够快速获得准确的应对。
  4. 试错成本高的场景。

附录：关键知识点详解 重点

BO-SMAC 算法

SMAC 全称 Sequential Model-Based Optimization for General Algorithm Configuration，算法在 2011 年被 Hutter 等人提出。该算法的提出即解决高斯回归过程中参数类型不能为离散的情况。

定义：

  • 以随机森林为代理函数：用每棵子树的输出计算均值，方差作为代理模型的输出。
  • 采用 EI（expected improvement） 作为其采集函数生成新的采样点。
  • 采集函数会根据代理模型选取均值小或方差大的点进行采样。

随机森林：

  • 由多个随机生成的决策树组成的决策模型。
  • 不同树的不同决策结果可反映输出结果的随机分布。
  • 适合处理高维输入参数、同时适合离散和连续输入参数、训练快、易实现、不易过拟合。
方法特性：随机森林擅长处理离散值输入，因此 SMAC 对离散值多的优化问题比较擅长。随机森林的子树有非常大的多样性，对于探索次数较少的点会产生较大的方差，使得 SMAC 具有较优的探索能力。
BO-SMAC算法的代理函数是什么？它擅长处理什么类型的输入参数？
参考答案BO-SMAC算法的代理函数是随机森林。它擅长处理高维输入参数，同时适合离散和连续输入参数，尤其对离散值多的优化问题比较擅长。
