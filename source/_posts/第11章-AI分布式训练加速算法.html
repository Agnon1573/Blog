2.3 时域时序数据增强典型算法_DBA算法

必考 动态时间规整 (DTW) 算法：因序列长短不一或时间步不对齐时，难以有效计算相似度，DTW 算法对时间序列线性放缩，达到更好的对齐效果，可以存在一对多 mapping 的情况。

DTW 算法步骤：1. 计算两个序列各个点之间的距离矩阵。2. 寻找一条从矩阵左上角到右下角的路径，使得路径上的元素和最小。

易错：路径上的某个元素 (i, j)，它的前一个元素只可能为左边的相邻元素、上面的相邻元素或左上方的相邻元素。重点考察 DTW 计算。

2.4 常用的平滑优化方法一：下降法

梯度下降：对凸函数有亚线性收敛率 O(1/t)，对强凸函数有线性收敛率。每次迭代会让函数值严格减少一定数值。

牛顿法：具有平方收敛率。

机器学习优化的关键视角：过低的优化误差没有必要；成本函数是简单函数的平均；测试误差比训练误差更为重要。

自蒸馏算法

自蒸馏算法是指使用模型深层特征作为Teacher模型来蒸馏模型浅层特征的算法。在不同深度的 resblock 块后增加 Bottlenecks、FC Layers、Softmax 层作为独立的预测输出模块，蒸馏时可以使用深层特征来对浅层输出特征进行蒸馏（如：Softmax1 学习 Softmax2，Softmax2 学习 Softmax3）。

核心要点：自蒸馏方式相较于非自蒸馏的方式抗噪能力更强，且收敛效果更好；同时能够一定程度上缓解梯度消失的问题。
易错：自蒸馏策略并非在所有场景都具有优势，不能绝对化。

随机平均梯度方法（SAG） 必考

SAG迭代过程

随机平均梯度方法（SAG）是改进版的随机梯度方法，其重要特征是能线性收敛。在内存中保留所有样本函数最近一次计算的梯度值，有放回地随机选择一个样本索引，每次迭代只更新被选中样本对应的梯度，其余保持不变，然后取平均值作为梯度估计。这被称为 "Lazy" 梯度评估。

目标函数为 $g(\theta) = \frac{1}{n} \sum_{i=1}^n f_i(\theta)$，梯度估计为 $\frac{1}{n} \sum_{i=1}^n y_i^t$。

随机梯度方法线性收敛原理——方差减少 重点

核心原理是通过引入另一个已知期望的随机变量 $Y$ 的样本，来减少原随机变量 $X$ 的样本方差。定义新的随机变量 $Z_{\alpha} = \alpha(X - Y) + \mathbb{E}Y$。当 $\alpha=1$ 时为无偏估计；当 $\alpha<1$ 时存在潜在偏差，但方差会减小。

SVRG（随机方差减少梯度）：无偏更新，两层循环（外层更新快照点，内层迭代优化），不需要存储所有梯度。利用快照点梯度修正。

SAG（随机平均梯度）：有偏更新，一层循环，需要存储梯度。利用历史梯度平均。

SAGA（随机平均梯度改进版）：无偏更新，一层循环，需要存储梯度。利用历史梯度+无偏修正。

易错：并非所有减少方差的方法都是无偏的，SAG就是有偏更新，其关于随机选择样本的期望并不等于完整梯度；而SVRG和SAGA是无偏的。需要存储梯度的方法（如SAG、SAGA）一般只需一层循环，不需要存储梯度的方法（如SVRG）需要两层循环。

算法差异 重点

根据个体的适配信息进行搜索，因此不受函数约束条件的限制，如连续性、可导性等；对高维复杂问题，往往会遇到早熟收敛和收敛性能差的缺点，都无法保证收敛到最优点。

PSO与GA的算法差异

PSO有记忆，所有粒子都保存好的解的知识，而GA无记忆性，以前的知识随着种群的改变而改变；

PSO中的粒子仅仅通过当前搜索到最优点进行共享信息，所以很大程度上这是一种单共享项信息机制，而GA中，染色体之间相互共享信息，使得整个种群都向最优区域移动；

GA的编码技术和遗传操作比较简单，而PSO相对于GA没有交叉和变异操作，粒子只是通过内部速度进行更新，因此原理更简单、参数更少、实现更容易。

1.1 同步训练和异步训练

同步训练和异步训练性能比较

假设其余条件一致，相同epochs，异步训练花费时间少，但精度可能会低于同步训练。原因是异步训练的梯度存在延时问题，即更新模型时用到的是老旧的梯度，而非当前模型的梯度。

Global Model： w_t → w_{t+1} ... → w_{t+τ} → w_{t+τ+1}

Worker(m)： (x_t, y_t) → w_t → g_t ... → w_{t+τ+1}

Worker(m')： (x_{t+1}, y_{t+1}) → w_{t+1} → g_{t+1} ...

如何解决异步训练中的梯度延时问题

从算法层面对延时梯度进行处理，如 delay compensation。

采用半异步训练，通过在异步训练中适当的同步以减小延时梯度的影响。

1.3 流水线并行（模型并行）

流水线并行是纵向模型并行的提升版，在解决大模型训练的内存问题的同时，提高了NPU的资源利用率，加速了训练。

流水线并行有多种实现形式，如GPipe、PipeDream等。但大部分流水线并行都是通过把mini-batch（如256个数据）细分为micro-batches（如4份64个数据，每64个数据即为一个micro-batch）人为制造pipeline的可能性。不同的流水线并行采用不同的pipeline模式，这里以GPipe为例简要介绍。

前向传播效率：假设共M个micro-batch，N个设备，并假设每个NPU前向传播需要1单位时间，GPipe前向传播时间总体为N+M-1，其中每个NPU工作时间为M，因此资源利用率为M/(N+M-1)。

反向传播效率：计算方法与前向传播效率类似，资源利用率仍然为M/(N+M-1)。

总体效率：M/(N+M-1)。

3 TimeGAN 概述

深度生成模型与TimeGAN

深度生成模型（Deep Generative Models, DGM）能生成高维数据，在图像领域数据增强有广泛应用，典型代表为生成对抗网络（GAN）。在时间序列数据领域，DGM同样可以合成时间序列样本，如循环GAN和循环条件GAN，产生真实的实值多维时间序列数据。

这些方法考虑到了时序数据的每个时间步的相互影响（时态特征），没有考虑静态特征针对时序数据，因此提出了TimeGAN。TimeGAN提出时序数据应该有两种特征：第一个是静态特征S，不会因为时间而改变的特征，例如性别；第二个是时态特征X，该特征随时间而改变，例如生命特征（包括脉搏、呼吸、体温、血压等数据）。

TimeGAN让模型学习真实训练数据的分布，随机输入一个向量，经过模型输出一个数据，这个数据的分布与真实数据的分布相似，从而让生成数据与真实数据非常相像。

内存优化与CPU Offloading

内存优化概述

内存优化主要包括：重计算（重新计算部分activation以节约内存）、CPU offloading（将activation从NPU移动到CPU以节约内存）、ZeRO offloading（将优化器状态从NPU移动到CPU以节约内存）。

CPU Offloading / Paging 高频

CPU offloading 是减少 activation（激活值）所需显存的另一种方式。将额外的 activation 暂时存放于 CPU，需要时再从 CPU 取回。通过 NPU-CPU 通信换取内存空间，即以通信换内存。CPU-offloading 可以与重计算技术共同使用，进一步提升显存利用率。

易错：CPU Offloading 是“以通信换内存”，而不是“以计算换通信”。将优化器状态放到CPU上属于ZeRO offloading，而不是CPU offloading。
关于CPU Offloading不正确的是？

模型量化算法：训练后量化（PTQ）

Data-free 训练后量化 重点

不依赖真实数据，对模型进行量化参数的离线校准，包括：

基于假设分布与统计：为模型输入随机数据，根据 Activation 的假设分布与统计，计算量化参数。假设激活分布服从正态分布（如 BN 层输出），采用 3σ 统计确定量化的饱和截断区间。

基于伪样本生成：借助预训练模型提供的内蕴信息与预测信息，构建并训练样本生成模型（如基于 GAN），以生成用于离线校准的伪样本。伪样本合成质量影响量化效果，并存在一定的时间成本；模型量化参数的微调可与生成模型的训练一同进行。

Label-free 训练后量化 重点

依赖少量无标注数据，对模型进行量化参数的离线校准。校准数据集可以选取一部分训练数据，或者其他与场景域一致或相关的数据。常见算法包括 Absmax 算法、Min-Max EMA 算法、KL 算法等。

时序数据自动增强

问题背景

自动数据增强按数据集探索最优策略，所有样本采用相同增强策略，忽略了样本间的差异性。

α剪枝自动增强 必考

α剪枝自动增强：时序数据增强的千人千面，样本级增强，为每个时序样本选择最合适的增强策略。

流程步骤：1. Augment sample（增强样本）；2. Evaluate and calculate loss（评估并计算 loss）；3. Rank and trim（排序和修剪，筛选 Top α loss 样本和 Bottom α loss 样本）；4. 增强样本汇总。

易错：对 MLP 模型而言，loss 较小样本对模型更新信息小，loss 较大样本对模型更新贡献度大，然而这样会导致更新后的模型在容易样本上性能受损。

时序数据增强方法概览 高频

基于统计生成模型：核心思想是用统计学方法模拟时序数据（基于时序数据的自相关性，给初始点一个扰动，后续数据点随之扰动）。方法包括MAR（mixture of autoregressive models）。

基于分解的时序数据增强：核心思想是把时序数据分解为某些成分，再对每个成分设计增强方法。方法包括STL 算法（分解为 trend/seasonality/residual，调整基础、趋势和季节性的权重，重构确定性部分，对 residual 进行随机性调整）。

基于学习方法的时序数据增强：核心思想是从数据中学得数据增强方式。方法包括 GAN / Automated Data Augmentation / Embedding Space（在 encoding space 上增加扰动）。

强化学习基础

基础的强化学习本质上是一个马尔可夫决策过程（MDP），再叠加机器学习成为一个具备学习能力的 MDP 过程。模拟的是人和动物的学习过程，类似仿生学的过程。

BO-SMAC 算法 重点

SMAC 全称 Sequential Model-Based Optimization for General Algorithm Configuration，算法在 2011 年被 Hutter 等人提出。该算法的提出即解决高斯回归过程中参数类型不能为离散的情况。

定义：以随机森林为代理函数：用每棵子树的输出计算均值，方差作为代理模型的输出。采用 EI（expected improvement） 作为其采集函数生成新的采样点。采集函数会根据代理模型选取均值小或方差大的点进行采样。

随机森林：由多个随机生成的决策树组成的决策模型。不同树的不同决策结果可反映输出结果的随机分布。适合处理高维输入参数、同时适合离散和连续输入参数、训练快、易实现、不易过拟合。

SMAC方法特性：随机森林擅长处理离散值输入，因此 SMAC 对离散值多的优化问题比较擅长。随机森林的子树有非常大的多样性，对于探索次数较少的点会产生较大的方差，使得 SMAC 具有较优的探索能力。

参考答案ABCD。A适合处理高维输入参数、同时适合离散和连续输入参数；B探索能力强；C不易过拟合；D训练快、易实现。
