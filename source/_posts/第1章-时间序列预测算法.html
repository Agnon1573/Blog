时间序列预测算法

时间序列预测简介

基本概念

时间序列：指按照时间先后顺序排列的数据序列。

时间序列预测：指根据历史时间序列数据提取规律、特征，建立模型对该序列未来变化趋势进行预测的过程，也即时间序列回归预测，可分为单步预测或者多步预测。

时间序列分解

一个时间序列一般可以分解为由趋势项、季节项、残差项等成分：

  • 趋势项：指时间序列在较长一段时间内呈现出来的持续向上或者持续向下的变动。
  • 季节项：指时间序列在一年内重复出现的周期性波动，如气候条件、生产条件、节假日等。
  • 残差项：也称为不规则波动，指除去趋势、季节性、周期性外的随机波动。

时间序列平稳性

时间序列（弱）平稳：序列中任意时刻数据的期望、方差和协方差不随时间而变。并不是所有的时间序列都是可预测的，而当一个时间序列的变化特征维持稳定，数据的历史分布和未来分布就会趋于一致，这时我们就可以根据历史数据对未来作出预测。

易错：“不是弱平稳的时间序列无法进行时间序列预测”该说法是错误的。

时间序列（弱）平稳性检验方法：当一个时间序列的滞后算子多项式方程存在单位根时，我们认为该时间序列是非平稳的；反之，当该方程不存在单位根时，我们认为该时间序列是平稳的。常见的单位根检验方法有DF检验、ADF检验和PP检验。重点

时间序列预测的评估方法

数据集划分：时间序列的数据集划分为训练集和测试集时，要确保测试集的时间戳要晚于训练集时间戳，否则容易数据泄露和无法实际应用。

划分方法：常见方法有简单划分方法和时间序列K-Fold交叉验证划分方法。

时间序列预测的评价指标

必考 点预测评价指标

  • 预测偏差：$e_{T+h}=y_{T+h}-\hat{y}_{T+h|T}$
  • 平均绝对误差（MAE）：$\mathrm{MAE}=\operatorname{mean}\left(\left|e_{t}\right|\right)$
  • 均方根误差（RMSE）：$\mathrm{RMSE}=\sqrt{\operatorname{mean}\left(e_{t}^{2}\right)}$
  • 绝对百分比误差（APE）：$APE_{t}=100\left|y_{t}-\hat{y}_{t}\right| / y_{t}$
  • 平均绝对百分比误差（MAPE）：$\mathrm{MAPE}=\operatorname{mean}\left(APE_{t}\right)$
  • 分位数绝对百分比误差：$APE_{p}=\operatorname{quantile}_{p}(APE)$，比如95%的绝对百分比误差小于10%。
  • 对称平均绝对百分比误差：$\mathrm{sMAPE}=\operatorname{mean}\left(200\left|y_{t}-\hat{y}_{t}\right| /\left(y_{t}+\hat{y}_{t}\right)\right)$

高频 概率预测评价指标

  • 分位数预测：未来t时刻的p分位数 $f_{p, t}$
  • 分位数预测偏差： $$Q_{p, t}=\left\{\begin{array}{ll}2(1-p)\left(f_{p, t}-y_{t}\right), & \text { if } y_{t}<f_{p, t} \\ 2 p\left(y_{t}-f_{p, t}\right), & \text { if } y_{t} \geq f_{p, t}\end{array}\right.$$
  • 区间预测：未来t时刻的 $100(1-\alpha) \%$ 置信度的区间 $\left[\ell_{\alpha, t}, u_{\alpha, t}\right]$
  • 区间预测偏差： $$W_{\alpha, t}=\left\{\begin{array}{ll}\left(u_{\alpha, t}-\ell_{\alpha, t}\right)+\frac{2}{\alpha}\left(\ell_{\alpha, t}-y_{t}\right) & \text { if } y_{t}<\ell_{\alpha, t} \\ \left(u_{\alpha, t}-\ell_{\alpha, t}\right) & \text { if } \ell_{\alpha, t} \leq y_{t} \leq u_{\alpha, t} \\ \left(u_{\alpha, t}-\ell_{\alpha, t}\right)+\frac{2}{\alpha}\left(y_{t}-u_{\alpha, t}\right) & \text { if } y_{t}>u_{\alpha, t} \end{array}\right.$$

传统时间序列预测方法

简单规则法

包括朴素预测法、简单平均法。

  • 优点：在较少数据的情况下即可进行预测。
  • 缺点：预测精度不高。

基于时间序列分解的方法

对时间序列进行分解后，若发现分解时序项存在明显的可预测性，可以通过对分解时序项分别预测，然后再组合各预测分项即可获得原始时间序列的预测。一个时间序列往往由长期趋势（Trend，T）、季节性、随机波动组成，部分场景下可能包含相对季节性更细粒度的周期性。

  • 加法模型：$Y_{t}=T_{t}+S_{t}+C_{t}+I_{t}$
  • 乘法模型：$Y_{t}=T_{t} \times S_{t} \times C_{t} \times I_{t}$

Facebook Prophet 时序预测算法

Prophet针对一维时间序列进行建模，将时间序列分为趋势、季节、节日三部分特征，是自动特征提取的线性回归模型。适用于少特征、规律性高、单维度的时间序列场景，同时能够考虑外部特征数据。

$$y(t)=g(t)+s(t)+h(t)+\epsilon_{t}$$

其中，$g(t)$为趋势项，$s(t)$为季节项，$h(t)$为节日项，$\epsilon_{t}$为随机项。

基于经典统计学的方法

重点 指数平滑

预测值使用加权平均值进行计算，其中权重随观测时间的久远程度呈指数型下降——最早的观察值被赋予最小的权值。

Holt-Winters 季节性方法

Holt（1957）和 Winters（1960）将Holt方法进行拓展用来捕获季节因素，包括预测方差和三个平滑方程（一个用于水平，一个用于趋势，另一个用于季节性分量）。

必考 ARIMA 类预测算法

ARIMA模型旨在描绘数据的自回归性，其包括AR、MA、ARMA、ARIMA、SARIMA、SARIMAX等多种成分和变种。

  • 自回归模型 AR(p)：基于目标变量历史数据的组合对目标变量进行预测。 $$y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_t$$
  • 移动平均模型 MA(q)：利用历史预测误差来建立一个类似回归的模型。 $$y_t = c + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q}$$
  • 非季节性 ARIMA(p,d,q)：将差分自回归模型以及移动平均模型结合起来（p-自回归模型，d-差分模型，q-移动平均模型）。 $$y_t' = c + \phi_1 y_{t-1}' + \cdots + \phi_p y_{t-p}' + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q} + \varepsilon_t$$
  • 季节性 SARIMA(p,d,q,s,P,D,Q)：在ARIMA模型多项式中引入了季节性的项。 $$y_t = u_t + \eta_t$$ $$\phi_p(L) \tilde{\phi}_P(L^s) \Delta^d \Delta_s^D u_t = A(t) + \theta_q(L) \tilde{\theta}_Q(L^s) \zeta_t$$
  • 带外生变量的季节性 SARIMAX：在SARIMA模型多项式中引入外生变量的影响。 $$y_t = \beta_t x_t + u_t$$ $$\phi_p(L) \tilde{\phi}_P(L^s) \Delta^d \Delta_s^D u_t = A(t) + \theta_q(L) \tilde{\theta}_Q(L^s) \zeta_t$$

基于特征工程+机器学习的时间序列预测方法

基本思路

基于时间序列的特征工程，可将时间序列预测问题转化为回归预测问题，然后采用机器学习回归算法解决。

时间序列特征工程常用特征

日期时间特征、节假日特征、滞后特征、滑窗/扩展窗特征、同期值特征、交叉特征、业务域特征。

交叉特征

  • 类别特征间组合：构成新特征，比如星期和小时组合为 `Mon_10`（星期一的十点）。
  • 类别特征和连续特征：
    1. 连续特征分桶后进行笛卡尔积；
    2. 基于类别特征进行 groupby 操作构造的统计特征。
  • 连续特征和连续特征：
    1. 同比和环比（一阶差分）；
    2. 二阶差分：反应变化趋势；
    3. 比值。

基于支持向量回归机的方法（SVR）

支持向量机回归算法（SVR）是一种常见的多元拟合算法，也可以用于时间序列预测。

基本原理：给定容忍偏差 $\varepsilon$，给定训练集 $\{(x_1, y_1), (x_2, y_2), \cdots, (x_m, y_m)\}$，希望学习到拟合模型 $f(x) = w^T x + b$，使训练集中所有样本点尽可能在 $f(x) \pm \varepsilon$ 的间隔带内。

Loss 定义：对于带内样本点，误差在容忍范围内，无需统计loss；对于带外样本点，误差需要扣除容忍偏差 $\varepsilon$。 $$loss = \min_w \frac{1}{2} \|w\|^2 + C \sum_{i=1}^m L_\varepsilon(f(x_i) - y_i)$$ 其中： $$L_\varepsilon(z) = \begin{cases} 0, & |z| \le \varepsilon \\ |z| - \varepsilon, & \text{otherwise} \end{cases}$$

支持向量：支持向量是离分隔超平面最近的那些点。超平面方程为 $w^T x + b = 0$，间隔 $\gamma = \frac{2}{\|w\|}$。

支持向量回归机求解：通过引入松弛变量和损失函数最小化问题求解，得到支持向量机回归（SVR）解模型： $$f(x) = \sum_{i=1}^{n} (\alpha_i - \alpha_i^*) x_i^T x + b$$ 其中，$x_i$为训练样本的向量，$x_i^T$为训练样本向量的转置，$\alpha_i - \alpha_i^*$为训练样本的系数，$b$为偏置（以上参数根据训练集计算得到）。

  • 对于 $x_i$ 间隔带内的样本，$\alpha_i - \alpha_i^* = 0$；
  • 对于 $x_i$ 间隔带外的样本，$\alpha_i - \alpha_i^* \neq 0$，这些样本称为支持向量（即支持向量是训练集的子集）。

支持向量回归机核化：SVR解模型只应用到 $x$ 空间中，即 $x, y$ 在该空间中线性相关。根据 $x, y$ 内在联系的不同，也可以将 $x_i^T x$ 替换为其它核函数，即 $x, y$ 在其它特征空间中实现线性相关。常见核函数如下表所示：

名称 表达式 参数
线性核 $x_i^T x$ 无
多项式核 $(x_i^T x)^d$ $d \geq 1$为多项式的次数
高斯核 $\exp\left(-\frac{\|x - x_i\|^2}{2\sigma^2}\right)$ $\sigma > 0$为高斯核的带宽
拉普拉斯核 $\exp\left(-\frac{\|x - x_i\|}{\sigma}\right)$ $\sigma > 0$
Sigmoid核 $\tanh(\beta x_i^T x + \theta)$ $\tanh$为双曲正切函数，$\beta > 0, \theta < 0$
易错：核函数选择是SVR的最大变数，若核函数选择不当，则样本可能映射到不合适的特征空间，很可能导致性能不佳。

基于随机森林回归的方法

随机森林回归算法是决策树回归的组合算法，将许多回归决策树组合到一起，以降低过拟合的风险，是一种典型的 bagging 集成算法。

随机森林构建过程主要有两类随机：

  1. 在随机森林的每棵树构建时的样本都是由训练集经过有放回抽样（即 bootstrap sample，自助式采样法）得来的，采样包括对样本和特征的随机采样。
  2. 在构建树的过程中进行结点分割时，选择的分割点是所有特征的最佳分割点，或特征的大小为 `max_features` 的随机子集的最佳分割。

优点：算法简单、易于并行执行、可以减小预测方差。
缺点：可解释性差、模型计算量大。

基于梯度提升回归树的方法

梯度提升回归树是弱预测模型的集成，如采用典型的决策树作为弱预测模型，这时则为梯度提升树（GBT或GBDT），用于解决回归问题。像其他提升方法一样，它以分阶段的方式构建模型，但它通过允许对任意可微分损失函数进行优化作为对一般提升方法的推广，应用广泛。

常见梯度提升回归树算法有：GBDT、XGBoost、LightGBM、CatBoost。

在数据量和计算机配置够的情况下，CatBoost 是精度最好的梯度提升算法开源框架。

基于 Stacking/Blending 集成学习的方法

Stacking 和 Blending 模型都是一种层次模型集成框架。与 bagging 和 boosting 方法不同（后两者建立在相同算法（通常是CART）的基本模型上），Stacking 和 Blending 的基础模型和元模型可以是任何机器学习算法，如决策树、随机森林、支持向量机等。

Stacking 集成学习：Stacking 模型通过结合各种分类器或回归器来提高建模精度。最简单的堆叠模型通常包含2个层次：

  • 第一层：由基本模型组成，依靠不同种类的算法从原始数据集中学习生成元特征数据集。
  • 第二层：元学习器，应用元特征数据集学习获得最终结果。第二层模型可以实现对第一层模型的线性或者非线性映射学习，比多模型结果平均方法可以进一步提升模型精度。

关键要点：

  • Stacking 集成时，第二层模型的训练是在第一层模型的 K-Folder 交叉验证的元特征上学习训练的。
  • 优点：保证了所有训练集数据参与模型训练。
  • 缺点：训练计算量大。
  • 两个阶段：① 在训练集上训练多个基础模型；② 将基础模型的预测结果作为新的特征输入到一个元模型中进行训练和预测。

Blending 集成学习：Blending 集成时，第二层模型的训练是在第一层模型通过 leave-out 方法留出一部分训练数据集（通常为10%或20%）作为验证集的元特征上学习训练的。

关键要点：

  • 优点：比传统 Stacking 模型简单、计算快。
  • 缺点：非全部训练集参与第一层模型训练。

基于循环神经网络的时间序列预测方法

循环神经网络（RNN），该算法是一种常见的神经网络类算法，常用于序列预测。

  • RNN 由传统全连接神经网络演化而来，主要变化点为隐含层中引入了前一时刻的隐含层信息，该改进有效地处理了序列中输入的前后联系。
  • 当用于时间序列预测时，RNN 的输入输出相同，但输出提前一帧，即当前帧+前期积累信息→下一帧。

传统 RNN 存在的问题：

  1. 传统 RNN 中，当前帧输出值只跟当前帧输入值、前一帧隐含层相关；显然，RNN 只有短期记忆能力，无法处理较长的输入序列。
  2. 由于 RNN 的递归结构，训练过程中容易出现梯度消失和梯度爆炸，从而导致模型训练困难。

长短期记忆（LSTM）该算法是传统 RNN 的一种改进。

模型 状态位 记忆能力
传统 RNN 仅状态位 H 前后帧之间只能传递短期记忆
LSTM 状态位 H、C 前后帧之间既能传递短期记忆，又能传递长期记忆

优势：能够有选择性地保留、遗忘部分信息，能够处理有效的长期信息。

缺点：能够缓解梯度消失和梯度爆炸，但网络结构更为复杂，待训练参数增加，导致复杂度上升。由于递归迭代的网络结构，难以通过并行化实现效率提升（RNN 类算法通病）。

基于卷积神经网络的时间序列预测方法

卷积神经网络（CNN），该算法是一种常见的神经网络类算法，常用于二维数据（如图像）处理与分析。

CNN 一般由卷积层和池化层交错叠加，并在最后拼接全连接层而成，其中：

  • 卷积层：将卷积算子在输入矩阵中滑动卷积，依次计算卷积和形成新矩阵。
  • 池化层：在输入矩阵中滑动小窗，并在小窗内求最大值或其它池化操作，形成新矩阵。
  • 全连接层：将输入矩阵一维化，并以全连接的方式映射到下一层。

CNN 也可以用于时间序列预测，一般需要将一维的时间序列二维化，例如：将历史数据按天、周等周期切段后拼接在一起形成“图像”。

相对于 RNN，CNN 的主要优势在于：

  1. 平移不变性，在特征提取时不会破坏信号频谱。
  2. 能够较好地处理信号的历史同比信息。
  3. 方便通过并行化提升训练、推理效率。

基于 Transformer 的时间序列预测方法

Encoder-Decoder 之间唯一的联系是一个固定长度的语境向量，Encoder 要将整个序列的信息压缩进一个固定长度的向量中。这样做存在两个弊端：

  1. 语境向量可能无法完全表示整个序列的信息。
  2. 先输入到网络的内容携带的信息会被后输入的信息覆盖掉，输入序列越长，这个现象就越严重。

Attention Model：Attention 机制是一种能够学习输入序列间、输出序列间的关联关系的机制。

Attention model 虽然解决了输入序列仅有一个 context vector 的缺点，但依旧存在问题：

  1. Context Vector 计算的是输入序列、目标状态的关联，却忽略了输入序列间的关联，和目标序列间的关联性。
  2. 不管是 Seq2seq 或是 Attention model，其中使用的都是 RNN，RNN 的缺点就是无法并行化处理，导致模型训练的时间很长。
  3. 仍然无法解决序列间长距离的依赖性。

基于随机森林回归的方法

随机森林回归算法是决策树回归的组合算法，将许多回归决策树组合到一起，以降低过拟合的风险，是一种典型的Bagging集成算法。

构建过程的两类随机性：

  1. 在随机森林的每棵树构建时的样本都是由训练集经过有放回抽样（如Bootstrap sample 自助式采样法）得来的，采样包括对样本和特征的随机采样。
  2. 在构建树的过程中进行结点分割时，选择的分割点是所有特征的最佳分割点，或特征大小为 `max_features` 的随机子集的最佳分割点。

原理分析：

  • 单个决策树通常表现出很高的方差，并且往往会过拟合。
  • 在森林中引入随机性产生的决策树具有一定的解耦预测误差。
  • 通过取这些预测的平均值，可以抵消掉一些误差。随机森林通过结合不同预测来减少方差，有时以增加一点偏差为代价。
  • 在现实中，方差减少通常是值得关注的，因此产生了一个整体更好的模型。

优缺点：

  • 优点：算法简单、易于并行执行、可以减小预测方差。
  • 缺点：可解释性差、模型计算量大。

基于梯度提升回归树的方法

梯度提升回归树是弱预测模型的集成，如采用典型的决策树作为弱预测模型，这时则为梯度提升树（GBT或GBDT），用于解决回归问题。像其他提升方法一样，它以分阶段的方式构建模型，但它通过允许对任意可微分损失函数进行优化作为对一般提升方法的推广，应用广泛。

常见算法： GBDT、XGBoost、LightGBM和CatBoost等。整体来说，在数据量和计算机配置足够的情况下，CatBoost是精度最好的梯度提升算法开源框架。

模型结构与预测过程：

输入： $$ \left[\begin{array}{c} x \text { predictors } \\ y \text { target } \end{array}\right] $$

回归树迭代过程： $$ \begin{aligned} & \left[x_{i}, y-\hat{y}^{(0)}\right] \rightarrow\left[x_{i}, y-\hat{y}^{(1)}\right] \rightarrow \cdots \rightarrow\left[x_{i}, y-\hat{y}^{(T-1)}\right] \\ & f_{1}\left(x ; \Theta_{1}\right) \quad f_{2}\left(x ; \Theta_{2}\right) \quad f_{T}\left(x ; \Theta_{T}\right) \\ & \hat{y}^{(0)}+v f_{1}\left(x ; \Theta_{1}\right) \quad \hat{y}^{(1)}+v f_{2}\left(x ; \Theta_{2}\right) \quad \hat{y}^{(T-1)}+v f_{T}\left(x ; \Theta_{T}\right) \end{aligned} $$

模型预测：$\hat{y}^{(0)}=0 \rightarrow \hat{y}^{(1)} \rightarrow \hat{y}^{(2)} \rightarrow \cdots \rightarrow \hat{y}^{(T)}$

    点预测+统计学习的方法——时间序列区间预测 重点

    基于训练或者验证集误差的区间估计法：首先建立时间序列预测的点预测模型，然后假设误差服从正态分布，估计出置信度对应的误差的上下限，再把它们加入到时间序列点预测的值或者序列中，即获得了时间序列的区间预测。

    分位数损失函数法——时间序列分位数预测 必考

    分位数损失函数法通过设定不同的分位数q来获取预测区间：

    q=0.95：预测值尽可能大于真实值，预测区间的上限。
    q=0.5：退化为 MAE（平均绝对误差）。
    q=0.05：预测值尽可能小于真实值，预测区间的下限。

    易错：GBDT 也可以使用分位数损失函数，像 LightGBM 和 XGBoost 的 objective 里面也都有 quantile 这个选项，也都可以输出区间预测。

    1. 时间序列预测简介

    1.1 时间序列预测的基本概念 必考

    时间序列：是指按照时间先后顺序排列的数据序列。时序预测：是指根据历史时间序列数据提取规律、特征，建立模型对该序列未来变化趋势进行预测的过程，也即时间序列回归预测，可分为单步预测或者多步预测。

    一个时间序列一般可以分解为由趋势项、季节项、残差项等成分：
    趋势项：指时间序列在较长一段时间内呈现出来的持续向上或者持续向下的变动；
    季节项：指时间序列在一年内重复出现的周期性波动；
    残差项：也称为不规则波动，指除去趋势、季节性、周期性外的随机波动。只含有随机波动的序列也称为平稳序列。

    时间序列（弱）平稳性 重点

    时间序列（弱）平稳：序列中任意时刻数据的期望、方差和协方差不随时间而变。当一个时间序列的变化特征维持稳定，数据的历史分布和未来分布就会趋于一致，这时我们就可以根据历史数据对未来作出预测。

    时间序列（弱）平稳性检验方法 高频

    当一个时间序列的滞后算子多项式方程存在单位根时，我们认为该时间序列是非平稳的；反之，当该方程不存在单位根时，我们认为该时间序列是平稳的。常见的单位根检验方法有：DF检验、ADF检验和PP检验。

    1.2 时间序列预测的挑战 了解

    时间序列具有连续性、随机性以及周期性。考虑到不同领域差异性，存在以下一系列挑战：不同领域时间序列复杂度、影响因素、时间粒度差异巨大；数据多寡和完整性差异巨大；消耗的资源和时间容忍度差异巨大；可预测性差异性大；期望预测精度差异巨大；数据漂移现象；人才稀缺。

    1.3 时间序列预测的评估方法 必考

    时间序列的数据集划分为训练集和测试集时，要确保测试集的时间戳要晚于训练集时间戳，否则容易数据泄露和无法实际应用。常见方法包括简单划分方法和时间序列k-folder交叉验证划分方法。

    常用点预测评价指标包括：预测偏差、平均绝对误差（MAE）、均方根误差（RMSE）、绝对百分比误差（APE）、平均绝对百分比误差（MAPE）、分位数绝对百分比误差、对称平均绝对百分比误差。

    常用概率预测评价指标包括：分位数预测偏差、区间预测偏差。

    易错：时间序列划分数据集时，测试集的时间戳必须晚于训练集时间戳，不能随机打乱。

    2. 传统时间序列预测方法

    2.1 & 2.2 简单规则法 了解

    朴素预测法：$y_{t+1} = y_t$，将前一天的曲线平移一个周期作为预测曲线。求平均预测法：$y_{t+1} = \text{过去一段时间} y \text{的均值}$，将过去n天同期数据求平均作为预测曲线。

    2.3 基于时间序列分解的方法 重点

    时间序列往往由长期趋势、季节性、随机波动、周期性组成。可以通过两类主要模型形成时间序列：
    加法模型：$Y_t = T_t + S_t + C_t + I_t$
    乘法模型：$Y_t = T_t \times S_t \times C_t \times I_t$

    Facebook Prophet时序预测算法：针对一维时间序列进行建模，将时间序列分为趋势、季节、节日三部分特征，是一种自动特征提取的线性回归模型。公式为：$y(t) = g(t) + s(t) + h(t) + \varepsilon_t$。

    2.4 基于经典统计学的方法 必考

    简单的指数平滑：预测值使用加权平均值进行计算，其中权重随观测时间的久远程度呈指数型下降。

    Holt-Winters季节性方法：将Holt方法进行拓展用来捕获季节因素，包括预测方差和三个平滑方程（一个用于水平，一个用于趋势，另一个用于季节性分量）。

    ARIMA类预测算法：旨在描绘数据的自回归性，其包括AR、MA、ARIMA、SARIMA、SARIMAX等多种成分和变种。
    自回归模型 AR(p)：基于目标变量历史数据的组合对目标变量进行预测。
    移动平均模型 MA(q)：利用历史预测误差来建立一个类似回归的模型。
    非季节性 ARIMA(p,d,q)：将差分、自回归模型以及移动平均模型结合起来。
    季节性 SARIMA(p,d,q,s,P,D,Q)：在ARIMA模型多项式中引入季节性的项。
    带外生变量的季节性 SARIMAX：在SARIMA模型多项式中引入外生变量的影响。

    3. 基于特征工程+机器学习的时间序列预测方法

    特征工程概述 重点

    基于时间序列的特征工程，可将时间序列预测问题转化为回归预测问题，然后采用机器学习回归算法解决。输入特征主要包括：日期时间相关特征、滞后特征、滑窗/扩展窗特征、同期值特征、交叉特征、业务域特征、节假日特征。

    3.1 基于支持向量回归机（SVR）的时间序列预测方法 高频

    支持向量机回归机（SVR）是一种常见的多元拟合算法。给定容忍偏差 $\epsilon$，希望学习到拟合模型 $f(\mathbf{x}) = \mathbf{w}^T\mathbf{x} + b$，使训练集中所有样本点尽可能在 $f(\mathbf{x}) \pm \epsilon$ 的间隔带内。

    SVR损失函数定义：对于间隔带内的样本点，误差在容忍范围内，无需统计loss；对于间隔带外的样本点，误差需要扣除容忍偏差 $\epsilon$。优化目标为：$\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^{m} l_\epsilon(f(\mathbf{x}_i) - y_i)$。

    基于特征工程+机器学习的时间序列预测方法

    基于支持向量机回归机的时间序列预测方法 重点

    SVR通过引入拉格朗日函数对loss函数最小化问题求解，得到SVR解模型：$$f(\mathbf{x}) = \sum_{i=1}^{m} (\hat{\alpha}_i - \alpha_i) \mathbf{x}_i^T \mathbf{x} + b$$。其中，$\mathbf{x}$ 为待预测样本的特征向量，$\mathbf{x}_i$ 为训练集样本的特征向量；$\hat{\alpha}_i - \alpha_i$ 为各训练集样本的系数，$b$ 为截距。

    对于 $\epsilon$-间隔带内样本，$\hat{\alpha}_i - \alpha_i = 0$；对于 $\epsilon$-间隔带外样本，$\hat{\alpha}_i - \alpha_i \neq 0$，这些样本称为支持向量（即支持向量是训练集的子集）。

    SVR解模型将 $\mathbf{x}$ 投影到 $\mathbf{x}_i^T\mathbf{x}$ 空间中，使 $\mathbf{x}$-$y$ 在该空间中线性相关。根据 $\mathbf{x}$-$y$ 内在联系的不同，也可以将 $\mathbf{x}_i^T\mathbf{x}$ 替换为其它核函数，使 $\mathbf{x}$-$y$ 在其它特征空间中实现线性相关。常见核函数包括：线性核、多项式核、高斯核、拉普拉斯核、Sigmoid核。

    易错：核函数选择是SVR的最大变数，若核函数选择不当，则样本可能映射到不合适的特征空间，很可能导致性能不佳。
    核心要点：SVR的解仅依赖于支持向量（间隔带外样本），通过核函数可以将数据映射到高维特征空间实现线性回归。
    SVR中的支持向量是指什么？
    参考答案支持向量是指位于 $\epsilon$-间隔带外的训练集样本，它们的系数 $\hat{\alpha}_i - \alpha_i \neq 0$，是决定SVR模型的关键样本。

    基于随机森林回归的方法 高频

    随机森林回归算法是决策树回归的组合算法，将许多回归决策树组合到一起，以降低过拟合的风险，是一种典型的Bagging集成算法。

    随机森林构建过程主要有两类随机：

    1. 样本随机采样：在随机森林的每棵树构建时的样本都是由训练集经过有放回抽样（如 Bootstrap Sample 自助式采样法）得来的，采样包括对样本和特征的随机采样。

    2. 特征随机选择：在构建树的过程中进行结点分割时，选择的分割点是所有特征的最佳分割点，或特征的大小为 max_features 的随机子集的最佳分割。

    单个决策树通常表现出很高的方差并且往往会过拟合。在森林中注入随机性产生的决策树具有一定的解耦预测误差。通过取这些预测的平均值，可以抵消掉一些误差。随机森林通过组合不同的树来减少方差，有时以增加一点点偏差为代价。

    核心要点：随机森林通过样本随机采样和特征随机选择构建多棵决策树，并通过平均预测结果来降低方差，减少过拟合风险。
    随机森林构建过程中的两类随机是什么？
    参考答案样本随机采样（有放回抽样）和特征随机选择（节点分割时选择随机子集）。

    基于梯度提升回归树的方法 必考

    梯度提升回归树是弱预测模型的集成，如采用典型的决策树作为弱预测模型，这时则为梯度提升树（GBT或GBDT），用于解决回归问题。它以分阶段的方式构建模型，通过允许对任意可微分损失函数进行优化，作为对一般提升方法的推广。

    常见梯度提升回归树算法有：GBDT、XGBoost、LightGBM、CatBoost等。

    模型预测过程：ŷ⁽⁰⁾ = 0 → ŷ⁽¹⁾ → ŷ⁽²⁾ → … → ŷ⁽ᵀ⁾。每一棵树拟合前一棵树的残差。

    核心要点：在数据量和计算机配置足够的情况下，CatBoost是精度最好的梯度提升算法开源框架。

    基于Stacking/Blending集成学习的方法 重点

    Stacking和Blending模型都是一种层次模型集成框架，与Bagging和Boosting方法不同，它们建立在相同算法（通常是CART）的基本模型上。

    Stacking模型最简单的堆叠模型通常包含2个层次：第一层由基本模型组成，依靠不同种类的算法从原始数据集中学习生成元特征数据集；第二层包含元学习器，应用元特征数据集学习获得最终结果。第二层模型的训练是在第一层模型的 k-fold交叉验证 的元特征上学习训练的。优点是保证了所有训练集数据参与模型训练，缺点是训练计算量大。

    Blending集成第二层模型的训练是在第一层模型的通过 leave-out方法 留出一部分训练数据集（通常为10%或20%）作为验证集的元特征上学习训练的。优点是比传统Stacking模型简单、计算快，缺点是非全部训练集参与第一层模型训练。

    核心要点：Stacking使用k-fold交叉验证生成元特征，Blending使用留出法生成元特征。
    Stacking和Blending在生成第二层训练数据时有何区别？
    参考答案Stacking使用第一层模型的k-fold交叉验证的元特征，而Blending使用leave-out方法留出部分训练数据作为验证集的元特征。

    基于深度学习的时间序列预测方法

    基于循环神经网络的时间序列预测方法 必考

    循环神经网络（RNN）由传统全连接神经网络演化而来，主要变化点为隐含层中引入了前一时刻的隐含层信息，该改进有效地处理了序列中输入的前后联系。当用于时间序列预测时，RNN的输入输出相同，但输出提前一帧，即：当前帧 + 前期积累信息 → 下一帧。

    RNN计算公式：$$H_t = f(U \cdot X_t + W \cdot H_{t-1})$$，$$Y_t = g(V \cdot H_t)$$。其中：U、W、V为待训练参数。

    传统RNN存在的问题：当前帧输出值只跟当前帧输入值、前一帧隐含层相关，只有短期记忆能力，无法处理较长的输入序列。由于RNN的递归结构，训练过程中容易出现梯度消失和梯度爆炸，从而导致模型训练困难。

    LSTM（长短期记忆网络）是传统RNN的一种改进。传统RNN中只包含状态位H，前后帧之间只能传递短期记忆。LSTM中包含状态位H和C，前后帧之间既能传递短期记忆，又能传递长期记忆。C变化缓慢，H变化较快。

    LSTM网络模型底层是 z, zᵢ, z_f, z_o 四个状态位：

    - z_f 为遗忘门控：控制长期记忆状态位 c_(t-1) 中哪些信息需要被遗忘。

    - zᵢ 为记忆门控：控制当前输入 x_t 和前一帧状态位 h_(t-1) 中哪些信息需要被记忆。

    - z_o 为输出门控：控制哪些信息需要被输出到状态位 h_t 和 y_t。

    LSTM上层主要根据这四个状态位更新状态位 h_t 和 c_t，并形成网络输出 y_t。

    核心要点：LSTM通过引入遗忘门、记忆门和输出门，能够有选择性地保留、遗忘部分信息，处理有效的长期信息，缓解了梯度消失和梯度爆炸问题。
    易错：LSTM能够缓解梯度消失和梯度爆炸，但网络结构更为复杂，待训练参数增加；且由于递归迭代的网络结构，难以通过并行化实现效率提升（RNN类算法通病）。
    LSTM中的三个门控分别是什么？各自的作用是什么？
    参考答案三个门控是遗忘门控（控制长期记忆的遗忘）、记忆门控（控制当前输入和前一帧状态的记忆）、输出门控（控制输出到状态位和网络输出的信息）。

    基于卷积神经网络的时间序列预测方法 高频

    卷积神经网络（CNN）一般由卷积层和池化层交错叠加，并在最后拼接全连接层而成。卷积层将卷积算子在输入矩阵中滑动卷积，依次计算卷积和形成新矩阵；池化层在输入矩阵中滑动小窗，并在小窗内求最大值或其它池化操作，形成新矩阵；全连接层将输入矩阵一维化，并以全连接的方式映射到下一层。

    CNN也可以用于时间序列预测，一般需要将一维的时间序列二维化。例如，将历史数据按天、周等周期切段后拼接在一起形成"图像"。

    相对于RNN，CNN的主要优势在于：

    1. 平移不变性：在特征提取时不会破坏信号频谱。

    2. 周期性信息提取：能够较好地处理信号的历史同比信息。

    3. 并行化效率高：方便通过并行化提升训练、推理效率。

    CNN时间序列预测流程：历史数据按周期切段，拼接后形成"图像" → 输入CNN进行特征提取 → 结合辅助信息，输出预测结果（长期预测）。一般CNN迭代流程包含水平通道和垂直通道的特征提取，并结合辅助信息进行预测。

    核心要点：CNN用于时间序列预测时需将一维数据二维化，其优势在于平移不变性、周期性信息提取和并行化效率高。

    基于Transformer的时间序列预测方法 重点

    传统Seq2Seq模型中，Encoder-Decoder之间唯一的联系是一个固定长度的语境向量。Encoder要将整个序列的信息压缩进一个固定长度的向量中，存在两个弊端：

    1. 语境向量可能无法完全表示整个序列的信息。

    2. 先输入到网络的内容携带的信息会被后输入的信息覆盖掉，输入序列越长，这个现象就越严重。

    深度学习中的Attention机制借鉴了人类的注意力思维方式。人类视觉能够在众多干扰信息中专注于某些需要重点关注的目标区域，然后对这一区域投入更多的注意力资源，以获取更多所需要关注目标的细节信息。

    核心要点：传统Seq2Seq模型受限于固定长度的语境向量，Attention机制通过动态分配注意力资源解决了长序列信息丢失和覆盖的问题。
    传统Seq2Seq模型使用固定长度语境向量存在哪些弊端？
    参考答案1. 语境向量可能无法完全表示整个序列的信息；2. 先输入的信息容易被后输入的信息覆盖，输入序列越长现象越严重。

    Global Attention 与 Local Attention

    Global Attention：计算目标状态与所有输入序列状态的关联，得到全局对齐权重。

    Local Attention：计算目标状态与局部输入序列状态的关联，得到局部对齐权重和位置。

    相关公式：

    $$\tilde{h}_t = \tanh(W_c[h_t, c_t])$$

    $$c_t = \sum_{i=1}^n \alpha_{t,i} \overline{h_i}$$

    $$\alpha_{t,i} = \text{align}(y_t, x_i) = \frac{\exp(score(h_t, \overline{h_i}))}{\sum_{j=1}^n \exp(score(h_t, \overline{h_j}))}$$

    Attention模型仍存在的问题

    Attention model虽然解决了输入序列仅有一个context vector的缺点，但依旧存在问题：

    1. 关联信息缺失：Context Vector计算的是输入序列、目标状态的关联，却忽略了输入序列间的关联，以及目标序列间的关联性。

    2. 无法并行化：不管是Seq2seq或是Attention model，其中使用的都是RNN，RNN的缺点就是无法并行化处理，导致模型训练的时间很长。

    3. 长距离依赖问题：仍然无法解决序列间长距离的依赖性。

    Attention模型虽然解决了单一上下文向量问题，但仍存在关联信息缺失、无法并行化和长距离依赖问题。

    Attention函数的本质

    Attention函数的本质可以被描述为一个查询（Query）到一系列（键Key-值Value）对的映射。给定Target中的某个元素Query，通过计算Query和各个Key的相似性或者相关性，得到每个Key对应Value的权重系数，然后对Value进行加权求和，即得到了最终的Attention数值。

    $$\text{Attention}(Query, Source) = \sum_{i=1}^{n} \text{Similarity}(Query, Key_i) \cdot Value_i$$

    Attention函数的本质是什么？
    参考答案Attention函数的本质可以被描述为一个查询到一系列（键-值）对的映射，通过计算Query和各个Key的相似性得到Value的权重系数并加权求和。

    Transformer网络结构

    Transformer网络结构出自Google 2017年论文《Attention Is All You Need》。必考

    核心特点

    Encoder-Decoder结构：采用"搭积木"方式堆叠

    残差连接：缓解深层网络梯度消失问题

    LayerNorm：层归一化，加速训练

    时序位置信息：引入位置编码，捕捉序列顺序信息

    Encoder结构

    结构流程：Inputs → Input Embedding + Positional Encoding → [Multi-Head Attention → Add & Norm → Feed Forward → Add & Norm] × Nx

    具体包含：多头注意力机制、残差连接、LayerNorm、前馈神经网络。

    Decoder结构

    结构流程：Outputs (shifted right) → Output Embedding + Positional Encoding → [Masked Multi-Head Attention → Add & Norm → Multi-Head Attention → Add & Norm → Feed Forward → Add & Norm] × Nx → Linear → Softmax → Output Probabilities

    Mask的作用：在训练的时候，保证解码器无法看到预测时刻之后的数据，与模型预测时保持一致。

    易错：Decoder中的Masked Multi-Head Attention是为了在训练时防止看到未来信息，保证与预测时的一致性。

    Scaled Dot-Product Attention

    结构：MatMul (Q, K) → Scale → Mask (opt.) → SoftMax → MatMul (with V)

    使用内积计算相似度。

    公式：

    $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

    Multi-Head Attention

    模拟卷积神经网络，多通道输出，学习多种模式；投影到低维空间，降低计算复杂度；增加模型的可学习参数。

    结构：将Q, K, V通过Linear层分头计算Scaled Dot-Product Attention，然后Concat并乘以权重矩阵$W^O$输出。

    公式：

    $$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

    $$\text{where head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

    Multi-Head Attention通过将Q,K,V投影到低维空间分头计算，再拼接输出，模拟CNN多通道效果，降低计算复杂度并增加可学习参数。

    Transformer改进版

    Adversarial Sparse Transformer

    判别器：最小化交叉熵损失函数，将输入序列分类为预测值或真实值。

    生成器：最小化预测序列和真实数据之间的分位数损失。

    互补机制：分位数损失和对抗性损失可以互补。一方面，分位数损失帮助生成器捕获时间序列的整体模式并给出对应真实值的预测，可以防止判别器快速收敛到局部最优；另一方面，判别器从全局角度对预测进行正则化。

    Informer

    ProbSparse Self-attention mechanism：时间和空间复杂度为O(L log L)。

    Self-attention distilling：通过减半级联层输入，强化主导注意力元素，增强长序预测能力。

    Generative style decoder（生成式解码器）：通过一次前向传播预测，相比于传统迭代预测，大幅提升推理效率。

    基于图神经网络的时间序列预测方法

    图的基础知识

    Vertex (or node) embedding：节点嵌入

    Edge (or link) attributes and embedding：边属性及边嵌入

    Global (or master node) embedding：全局嵌入

    图神经网络（GNN）

    定义：图神经网络可以对图上所有属性（节点、边、全局信息）进行优化变化，同时保持住图的对称信息。使用信息传递的框架，输入是图，输出也是图。

    GNN层结构示例：Layer N (graph in): $U_n$, $V_n$, $E_n$；Update functions: $f_{U_n}$, $f_{V_n}$, $f_{E_n}$；Layer N+1 (graph out): $U_{n+1}$, $V_{n+1}$, $E_{n+1}$；Graph Independent Layer: update function $f = \dots$

    将图与神经网络结合

    图数据表示示例：Nodes: [0, 1, 1, 0, 0, 1, 1, 1]；Edges: [2, 1, 1, 1, 2, 1, 1]；Adjacency List: [[1, 0], [2, 0], [4, 3], [6, 2], [7, 3], [7, 4], [7, 5]]；Global: 0

    最简单的实现及其局限：流程为Input Graph → GNN blocks → Transformed Graph → Classification layer → Prediction (node, edge, or global predictions) $Y$。这是一个端到端的预测任务。

    易错：最简单的GNN实现没有使用图的连接信息，并未把整个图的信息更新进顶点、边的属性里，没有充分利用图的信息。

    图连接信息的利用与优化

    信息传递机制：1. 不同顶点汇聚操作；2. 从相邻节点汇聚信息；3. 变换信息；4. 用新信息更新图。

    Graph Nets Layer 结构与 Weave Layer 结构均包含更新函数和池化函数。

    节点更新过程涉及相邻节点嵌入、相邻边嵌入、全局嵌入、节点嵌入，通过条件函数（如Concatenation, Linear Layer and Add, FiLM Layer等）和更新函数得到更新后的节点嵌入。

    大规模图的处理：如果图比较大，连接比较稀疏，信息传递需要比较长的时间。此时，全局变量可以看作一个master node（主节点），可以和所有的顶点相连，可以和所有的边相连，从而加速信息传播。

    图卷积神经网络 (GCN)

    GCN 包含输入层、隐藏层和输出层，其前向传播公式如下：

    $$H^{(l+1)} = \sigma(\tilde{D}^{-\frac{1}{2}}\tilde{A}\tilde{D}^{-\frac{1}{2}}H^{(l)}W^{(l)})$$

    简化形式为：

    $$H^{(l+1)} = \sigma(\tilde{A}H^{(l)}W^{(l)})$$

    矩阵计算示例中，加入自连接的邻接矩阵 $\tilde{A}$ 将自身的节点信息考虑进来，将节点本身和邻居的信息都考虑进来，对节点进行归一化。

    路网构建：道路作为节点，道路连接作为边，构成图 $G = (V, E)$。节点信息包括交通速度、交通流量、交通密度等。

    实验设置：XX地区156条

    事件分类与节假日预测模型 重点

    在时间序列预测中，事件通常分为以下几类：周期性事件（依据已知周期发生的时间，如周末、节假日、月末周六等）、非周期性事件（未知确切发生时间但过去已有类似事件发生，如两会、周年事件等）、全局事件（所有节点均会发生的事件）和局部事件（局部节点发生的事件）。

    基于统一编码的节假日预测模型结合了Scalar Projection和Local Time Stamp Position Embeddings（$E_0 \dots E_7$）。Global Time Stamp包含Week Embeddings、Month Embeddings、Holiday Embeddings（$H_1, H_2$ 等）。

    6.2 时间序列预测案例——整网流量负载预测 必考

    6.2.1 OBP立项关键竞争力指标

    在主动预防专题中，流量预测算法准确率提升，在节假日场景下提前30天预测准确率由82%提升到95%。

    6.2.2 数据集

    数据集包含A、B、C、D 4个局点，10个站点，每天峰值采样。数据量跨度从2016年11月到2019年9月不等。

    6.2.3 算法评估指标

    提前30天预测过节期间流量，计算预测值的SMAPE误差。$y_{true}$ 为过节期间真实流量，$y_{predict}$ 为过节期间流量预测值（大长假 $n=7$，小长假 $n=3$）。

    公式：$$SMAPE = \frac{1}{n} \times \sum_{i=1}^{n} \frac{\left| y_{true} - y_{predict} \right|}{\left( y_{true} + y_{predict} \right) / 2}$$

    6.2.4 现有技术与短板场景

    产品现有方法采用Prophet开源工具，对时间序列的趋势分量、周期分量、节假日效应回归建模，预测每项成分相加得到整体预测，在A局点数据上平均准确率82%（平时）。

    易错：Prophet在非节假日预测较准，但在特定短板场景下误差极大。C局点因未知原因流量下滑导致预测误差42%；D局点因用户行为模式改变导致预测误差33%。

    6.2.5 算法方案对比 高频

    一、Prophet（现有技术）：基于STL分解考虑趋势项、周期项、节假日效应。包含饱和增长模型和分段线性模型的趋势模型，基于傅里叶级数的周期模型，以及节假日及突发事件模型。

    二、ARIMA：需要根据ACF和PACF确定超参 $(p, d, q)$。能精细刻画平稳序列的波动，对短期预测较准确，但未对季节性、节假日建模。

    三、线性回归：简单、稳健，通过拟合趋势外推给出预测结果，适合短期趋势预测，需要与历史节假日波动量融合形成更准确的预测。

    四、Sequence2Sequence模型：提供一种嵌入相关影响因素（如用户数、天气、日期、节假日等）的方法，解决多特征输入问题，可以预测未来一段时间的数据。

    6.2.6 实验对比与结果分析

    分别使用线性回归、ARIMA、Sequence-to-Sequence模型在4个局点的10个站点数据上进行测试，与产品现有技术做性能（SMAPE）对比。ARIMA模型各局点基于预测前全量历史数据的自相关和偏相关性确定超参 p/d/q；线性回归和Seq2Seq模型各局点超参一致。

    结果分析：当前使用ARIMA模型趋势外延+春节波动量比例放大（MIRAI算法）的方法，在部分规律性较强的6个站点上（A2、A3、A4、B3、C、D），准确率达95%以上。受套餐发放、突发月末效应、未知原因用户数降低等因素影响，A1、B1、B2、B4 4个站点的准确率有待进一步提升。
